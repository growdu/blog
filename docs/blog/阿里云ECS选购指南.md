# 阿里云 ECS 选购指南

> 一篇给程序员的实操指引。读完你会知道：买一台 ECS 应该看哪几个参数、不同预算下怎么选最划算、以及那些最容易踩的坑（特别是安全组）。

## 一、为什么你需要一台 ECS

云服务器（Elastic Compute Service，简称 ECS）是云厂商卖给你的虚拟服务器。和传统物理机相比，它的好处是：

- **按需付费** —— 跑一个月付一个月钱，不用一次性掏几千块买机器
- **弹性伸缩** —— 双十一要扛流量，临时加机器；平时砍掉
- **快照备份** —— 出问题 5 秒回滚
- **全球机房** —— 想在哪个机房就在哪个机房

对个人开发者来说，最常见的几个用途：

- **跑个人博客 / 个人网站** —— 你正在看的这个 `growdu.cn` 就是
- **跑学习用的 Linux 环境** —— 比装双系统干净
- **跑爬虫 / 脚本 / 定时任务** —— 比自己的笔记本省电、稳定
- **跑小型 API 后端** —— 1-2 个用户的玩具项目也能跑

本文不讨论云厂商之间的比较（每家都差不多，新用户哪家便宜用哪家），就以**阿里云 ECS** 为例，把"怎么买、怎么选、怎么避免踩坑"讲清楚。其它云厂商（腾讯云、华为云、AWS）流程大同小异。

# 三、购买流程（10 分钟）

完整流程一句话：**注册账号 → 实名认证 → 选购页填参数 → 下单付款 → 控制台重置密码 → SSH 连进去**。

## 3.1 注册 + 实名

- 阿里云账号注册需要手机号 + 实名认证（身份证或企业认证）
- 个人开发者用身份证认证即可，5 分钟搞定

实名认证后才能买 ECS（云厂商法定要求）。

## 3.2 进入选购页

三种入口：

1. 活动页（如 [推广链接](https://www.aliyun.com/minisite/goods?userCode=nq9hpgvj) 里的活动专区）—— 通常是新手优惠套餐
2. 产品页 → 云服务器 ECS → 立即购买
3. 控制台 → 云服务器 ECS → 创建实例

推荐**前两种**，因为有折扣。第三种是给老用户续费或临时扩容用的。

## 3.3 选购页要填的字段（按页面从上到下）

1. 计费方式：包年包月 / 按量付费 / 抢占式
2. 地域：华北 2（北京）/ 华东 1（杭州）/ 华南 1（深圳）……
3. 实例规格：哪个套餐（"经济型 e"、"通用型 g7"、"计算型 c7"……）
4. 镜像：公共镜像 → CentOS / Ubuntu / Debian 选一个
5. 系统盘：40G ESSD 云盘
6. 公网带宽：1M / 3M / 5M / 按使用流量
7. 安全组：默认 / 新建 / 选已有
8. 登录凭证：密钥对 / 自定义密码
9. 实例名称、主机名
10. 购买时长（包年包月才有）

# 四、实例规格怎么选（最关键）

实例规格 = CPU + 内存 + 网络性能 + 配套云盘 IO 性能的套餐组合**。规格名字看起来花里胡哨（"经济型 e"、"通用型 g7"、"计算型 c7"），记住一个原则就够了：

> **个人项目 / 博客 / 学习：通用型 g 系列，2 核 4G 起步。**
> **跑模型 / 跑密集计算：计算型 c 系列，按需加 CPU。**
> **跑数据库 / 缓存：内存型 r 系列，内存大。**

## 4.1 三种典型场景的推荐配置

| 场景 | 推荐规格 | CPU | 内存 | 大概月费（2026 价） |
|---|---|---|---|---|
| **个人博客 / 小网站** | 通用型 g7 / 经济型 e | 2 核 | 2-4G | 几十到一百多 |
| **中型应用 / API 后端** | 通用型 g7 | 2-4 核 | 4-8G | 一两百到三四百 |
| **跑大模型 / 训练** | 计算型 c7 / GPU 实例 | 8+ 核 / V100 | 16G+ | 几千到几万 |

对绝大多数个人开发者来说，**2 核 2G 或 2 核 4G 是黄金配置**，日常博客、爬虫、API 后端、学习 Linux 都够用。**不要买 1 核 1G** —— 现在的 Web 应用栈（Node.js、Java、Go）起步就要 1G 以上内存，1G 跑两个进程就 OOM。

## 4.2 经济型 e vs 通用型 g7 的区别

| 系列 | CPU | 网络 | 价格 | 适合 |
|---|---|---|---|---|
| 经济型 e | 共享 CPU（突发性能） | 1G 左右 | 便宜 | 流量小、不持续 |
| 通用型 g7 | 固定 CPU | 5-10G | 中等 | 持续运行、中等流量 |
| 计算型 c7 | 高主频 CPU | 5-10G | 中等偏贵 | 计算密集 |

经济型 e 的"共享 CPU"听着吓人，但实际是：**有积分（CPU credit）的时候跑满 CPU，没积分时降到基线**。对个人博客这种"平时没流量、偶尔有人访问"的场景，**经济型 e 是性价比之选**。但如果你的应用是持续跑 CPU 密集任务（比如编译、长连接服务），就老老实实用 g 系列。

## 4.3 我的实际经验

我自己跑博客用的是 **2 核 2G 的经济型 e**（活动期间买的一年期），**真实运行一年多，平均 CPU 使用率 < 5%**，内存使用稳定在 1G 以内。如果你和我一样只是跑博客，**2 核 2G 足够**。但如果你打算跑数据库 + 后端 + 前端 + 监控全家桶，**直接上 2 核 4G**，别让自己将来后悔。

# 五、操作系统镜像怎么选

三个候选：

- **CentOS Stream 9**（曾经的 CentOS 8 之后的延续）/ **Rocky Linux** / **AlmaLinux** —— 这些是 RHEL 系
- **Ubuntu 22.04 LTS / 24.04 LTS** —— 社区最活跃，新软件优先支持
- **Debian 12** —— 稳定老牌，Docker 官方推荐

## 怎么选

| 你的背景 | 推荐 |
|---|---|
| 完全没接触过 Linux | **Ubuntu 22.04 LTS** —— 网上教程最多 |
| 跑生产服务、追求稳 | **Debian 12** —— 极其稳定 |
| 公司用 RHEL 习惯了 | **CentOS Stream 9 / Rocky** —— 兼容性最好 |
| 跑 Docker | **Ubuntu 22.04 / Debian 12** —— 都行 |

**避免选 Windows Server** —— 贵、性能差、对个人项目没必要。Linux 是云服务器的主流选择。

镜像选完后，**不要勾"安装监控 agent"以外的额外组件**（云监控、Cloud Assistant 等可以保留，但"安全加固"之类需要看清楚）。

# 六、公网带宽怎么选

这是新手最容易选错的一项。先理解带宽的含义：**1M 带宽 = 128 KB/s 的下载速度**（注意是 bit，不是 byte）。

| 带宽 | 下载速度 | 适合 |
|---|---|---|
| 1M | 128 KB/s | 只跑 API、博客基本不可用 |
| 3M | 384 KB/s | 小博客勉强够，首屏图片慢 |
| 5M | 640 KB/s | 博客 / 小网站舒服 |
| 10M | 1.28 MB/s | 中型网站 / App 后端 |
| 按流量计费 | 不限速，按 GB 收费 | 不确定流量大小、怕浪费 |

## 我的建议

- **个人博客** → **5M 固定带宽**。一年多 100 块不到，体验比 3M 明显好（首屏加载会差几秒）
- **API 后端 / 小程序后端** → **按使用流量**，因为不知道并发峰值
- **流量大的应用** → 10M 起步 + CDN 分流

## 按带宽 vs 按流量的区别

- **按固定带宽**：买了 5M 就给你 5M 用，不管你用没用完。**适合流量稳定可预估**
- **按使用流量**：不限速，按 GB 收费（通常 0.8 元/GB）。**适合流量波动大、怕买多了浪费**

新手推荐按固定带宽，省心。

# 七、磁盘怎么选

磁盘分两类：**系统盘**（装系统的）和**数据盘**（额外挂的）。

## 7.1 系统盘

- **40G ESSD 云盘** 是当前推荐配置，价格便宜，性能足够
- ESSD（Enhanced SSD）是阿里云的优化版 SSD，比普通 SSD 更快、更稳
- 不要选"普通云盘"——那是机械盘时代的遗产，现在已经过时

## 7.2 数据盘

按需加。常见的场景：

- **跑 MySQL / Redis** → 加 100-200G 数据盘，分离系统盘
- **跑静态文件 / 视频** → 加 500G+
- **个人博客** → 不需要单独数据盘，40G 系统盘够用

如果不勾数据盘，所有东西都装在系统盘，**默认就行，别加**。

## 7.3 快照（重要）

磁盘配置完之后，**强烈建议在控制台"创建快照"备份一下**。ECS 改配置、重装系统、误操作前，先打个快照，5 秒就能回滚。这是云服务器最值钱的功能之一。

# 八、安全组（最容易踩的坑）

这是新手 90% 会栽跟头的地方。

## 8.1 安全组是什么

**安全组 = ECS 的"防火墙规则表"**，决定哪些端口对外开放、哪些 IP 能连进来。新买的 ECS 默认安全组只开 22（SSH）和 3389（Windows 远程桌面），**其它端口全关**。

这意味着：

- 你装了 nginx，但**80 / 443 没开**，网站外网访问不到
- 你装了 MySQL，**3306 没开**，远程连不上
- 你装了 Redis，**6379 没开**，同 VPC 内网也连不上

## 8.2 推荐配置

入门级推荐（个人博客场景）：

| 端口 | 协议 | 来源 | 用途 |
|---|---|---|---|
| 22 | TCP | 0.0.0.0/0（或限定你的 IP） | SSH |
| 80 | TCP | 0.0.0.0/0 | HTTP |
| 443 | TCP | 0.0.0.0/0 | HTTPS |
| ICMP | - | 0.0.0.0/0 | ping 测试 |

**MySQL（3306）、Redis（6379）等数据库端口千万别开 0.0.0.0/0**，应该限定到固定 IP 或只开内网。

## 8.3 常见踩坑

- **网站部署了但外网访问不到** → 99% 是安全组没开 80/443
- **SSH 连不上** → 检查 22 端口是否放开，以及 ECS 本身的"防火墙"（CentOS 的 firewalld、Ubuntu 的 ufw）
- **改了安全组规则没生效** → 安全组规则有"入方向"和"出方向"，**入方向**控制别人能不能连你，**出方向**控制你能不能连别人。新手只关心入方向就行。

## 8.4 系统内防火墙

即使安全组开了端口，**ECS 内部的操作系统防火墙还要再开一次**：

```bash
# CentOS Stream 9 / RHEL 系列
sudo firewall-cmd --permanent --add-port=80/tcp
sudo firewall-cmd --reload

# Ubuntu / Debian
sudo ufw allow 80/tcp
sudo ufw reload
```

安全组是"门卫"，系统防火墙是"屋里的锁"，**两层都要开**。

# 九、登录方式：密钥对 vs 密码

两种登录方式：

| 方式 | 优点 | 缺点 |
|---|---|---|
| **密码** | 简单，记一个密码就行 | 不安全，容易被爆破 |
| **密钥对**（推荐） | 极难被破解 | 第一次配置稍麻烦，丢了密钥 ECS 就登不上 |

## 9.1 推荐做法：密钥对 + 控制台一键登录

1. 创建 ECS 时选"密钥对" → "新建密钥对" → 下载 `.pem` 文件
2. **`.pem` 文件是登录凭证，丢了就登不上，备份到密码管理器**
3. 本地 SSH：
   ```bash
   chmod 600 ~/Downloads/my-key.pem
   ssh -i ~/Downloads/my-key.pem root@<你的ECS公网IP>
   ```

## 9.2 进阶：在 `~/.ssh/config` 配置免密

```bash
# ~/.ssh/config
Host myserver
    HostName <你的ECS公网IP>
    User root
    IdentityFile ~/Downloads/my-key.pem
```

之后直接 `ssh myserver` 就能连。

## 9.3 千万不要做的事

- 不要用 22 端口 + 密码 + 0.0.0.0/0 开放 SSH —— 30 秒内会被全球扫描爆破
- 不要把 `.pem` 提交到 Git 仓库
- 不要给 root 用户弱密码

# 十、计费方式怎么选

| 计费方式 | 价格 | 灵活性 | 适合 |
|---|---|---|---|
| **包年包月** | 最便宜（年付可省 30%+） | 低，关机也计费 | 长期项目 |
| **按量付费** | 较贵（按小时） | 高，随时释放 | 短期 / 弹性场景 |
| **抢占式实例** | 极便宜（最高便宜 90%） | 极低，可能被回收 | 可中断任务（爬虫、批处理） |

## 推荐

- **个人博客** → **包年包月**（便宜、关不关机无影响）
- **临时测试 / 学习** → **按量付费**（用完就释放）
- **CI 构建 / 爬虫** → **抢占式实例**（便宜到白菜价，但可能被中断）

活动期间的"学生套餐"、"新用户套餐"通常都是**包年包月**，算下来一天几毛钱。

# 十二、避坑指南（实战总结）

## 12.1 选购阶段

- ❌ 不要买 1 核 1G → ✅ 2 核 2G 起步
- ❌ 不要买普通云盘 → ✅ ESSD 云盘
- ❌ 不要勾自动续费（除非你确定长期用）→ 不然忘了取消扣款一两年
- ❌ 不要买 Windows Server（贵、性能差）→ Linux

## 12.2 买完之后

- ❌ 不要 22 端口 + 密码 + 全网开放 → 用密钥对 + 限定 IP
- ❌ 不要 root 密码设为 `123456` → 用密钥对或随机密码
- ❌ 不要部署完就不管 → 第一件事是创建快照 + 设置自动备份策略

## 12.3 运行时

- ❌ 不要把所有服务都开公网端口 → 数据库只开内网
- ❌ 不要长期 root 登录 → 新建普通用户 + sudo
- ❌ 不要忘了系统更新 → 每周 `apt update && apt upgrade` 或用云监控补丁

# 十三、买完 ECS 后还要做什么（清单）

下面是我买完 ECS 必做的 10 件事清单，按顺序执行大概 30 分钟：

1. **创建快照**（备份初始状态）
2. **重置 root 密码 / 配置密钥对**（密钥对的话跳过）
3. **SSH 连上 ECS**（验证登录正常）
4. **更新系统**：
   ```bash
   # Ubuntu / Debian
   sudo apt update && sudo apt upgrade -y
   # CentOS Stream / RHEL
   sudo dnf update -y
   ```
5. **创建普通用户 + sudo**（不用 root 日常登录）
6. **配置 SSH 免密**（公钥放上去）
7. **改 SSH 端口**（安全加固，可选）
8. **开防火墙**（firewalld / ufw）
9. **安装 docker / nginx / 你的应用栈**
10. **创建域名解析 + 申请 SSL 证书**

做完这 10 件事，你就有了一台"能放心用"的云服务器。
