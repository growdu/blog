# 内容模型

一个内容单元由哪些字段组成：哪些是白名单、哪些是推导出来的、哪些不许出现。

这一系列回答一个问题：**同一份内容，怎么变成五个平台上的东西？**

答案的骨架是三层：**母稿**（作者写的那份）、**内容单元**（构建产物）、
**平台产物**（公众号里的那篇推文）。三层之间靠一份**内容契约**对齐。

契约不是形式主义。它决定了「一篇新文章发布到公众号时，摘要从哪来、
标题超长怎么办、哪些字段算作者说了算、哪些算机器说了算」——
这些问题如果没有一份写下来的契约，每加一个平台就会重新吵一遍。
