# 视频生产线

文章写完之后，同一份内容还想变成一条视频。这条线要解决的是：
**怎么让「做出一条片子」变成「半年后换台机器还能再做出一条一样的片子」。**

这两句话差着十万八千里。后者要求每个中间产物要么入库、要么能被精确重建，
而且重建的方式必须写在仓库里，不能靠某个人脑子里的记忆。
