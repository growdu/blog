# 信息架构

分类树怎么长出来、分类与学习路径为什么是两条轴、物理目录怎么排。

一个站有两百篇文章的时候，「分类」就不再是导航了，它只是一个检索框。

读者从搜索引擎落在一篇文章上，看完想接着读什么——
站点如果不给答案，他就走了。这一系列讲的是：
**怎么给一个内容堆得越来越大的个人站设计一条能读下去的路。**

## 本系列文章

- [分类不是导航，学习路径才是](./category-restructure-and-learning-path.md) —
  开工时那三十九个平铺分类，和它们怎么变成几条赛道；
  物理目录怎么排、中文分类名怎么长出来、
  以及「分类是检索用的，学习路径才是导航用的」这条分界
- [把 `docs/` 的目录重排成学习路径的镜像](./docs-tree-to-learning-path-mirror.md) —
  590 篇文章的目录怎么搬成 11 条赛道 × 48 个阶段，
  规则表里那 29 条正则为什么必须一条不剩，
  以及重定向、日期固化、审校台账这三样为什么跟着一起动
- [把 592 篇文章排成一条线](./journey-path-growth-order.md) —
  成长路线这条第二根轴怎么来的：五期主线加一段选修，
  按走过的顺序而不是按学科排，
  以及分期表怎么跟固化下来的提交日期逐年对账
