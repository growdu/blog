# 多平台分发

同一个内容单元，发到公众号、头条号、抖音、视频号、B 站，
每个平台的形态、限额、自动化程度都不一样。

这一系列要讲的是：怎么把这些差异**从代码里抽出来变成数据**，
怎么保证「重复跑一遍不会发两遍」，以及为什么这套系统的自动化
**故意停在半路**。
