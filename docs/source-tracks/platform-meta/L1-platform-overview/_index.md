# 平台总览

先说清楚一件事：growdu.cn 表面上是个博客，实际上是一个**内容工厂**。

博客只是它三条产线里最简单的那条。文章写完之后，同样的内容还要变成视频、
变成公众号推文、变成头条稿、变成抖音投稿包、变成 B 站投稿包。
如果每条产线各写一遍内容，
五百多篇文章乘以五个平台就是将近三千份稿件，改一次标题要改五处——
这套东西活不过第三个月。

所以这个系列的第一篇先讲整体：有哪些部件、部件之间怎么连、
以及**为什么不是用现成方案拼出来的**。
