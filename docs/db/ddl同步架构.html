核心特性
  • 统一架构：基于逻辑复制，零侵入改造内核
  • 双向过滤：发布端+订阅端双重规则过滤
  • 多方言适配：一套 DDL 语句，自动转换为目标数据库语法
  • 灵活规则：支持类型、Schema、正则、插件等多维度规则配置

分层架构优势
  • 职责分离：各层专注自身职责，便于维护和扩展
  • 标准接口：层间通过标准接口通信，解耦设计
  • 插件式适配器：新增数据库支持只需实现新适配器
  • 可测试性：各层可独立测试，保证质量

Replay Engine 职责
  • 语法转换：将 PG DDL 转换为目标数据库语法
  • 对象映射：Schema、Table、Column 名称映射
  • 类型转换：数据类型方言差异处理
  • 执行调度：DDL 语句的并行/串行执行控制

双重过滤机制
  • 发布端过滤：控制哪些 DDL 需要同步，支持类型/Schema/正则/插件规则
  • 订阅端过滤：安全校验、对象存在性检查、冲突检测

  • 回放：适配器转换并执行 DDL 到目标库
