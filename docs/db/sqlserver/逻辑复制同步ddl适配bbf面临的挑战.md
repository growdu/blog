# 逻辑复制同步ddl适配bbf面临的挑战

1.当前产品面向比亚迪现场，现场需要sqlserver模式，当前sqlserver模式下的逻辑复制能力范围边界尚不清楚；（从产品和架构层面出发评估）
   当前默认和PG的能力一致，但是实际的测试结果发现，有一些能力不满足，比如copy data；
2. 当前逻辑复制支持ddl主要适配的是PG模式，PG模式当前功能测试已验证完成；
3. 当前PG模式和sqlserver模式是按照一个需求来做的，但由于sqlserver模式当前有能力不满足，需要考虑单独拆分需求；
   这里面隐含了一个需求：sqlserver模式适配逻辑复制，适配完成后才能考虑sqlserver模式适配逻辑复制同步ddl。
