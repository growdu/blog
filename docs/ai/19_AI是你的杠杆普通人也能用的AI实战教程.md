# AI 是你的杠杆 —— 普通人也能用的 AI 实战教程

> 这是一篇给"不写代码的普通人"的 AI 入门教程。看完就能上手,直接照抄 10 个 prompt 模板,马上见效。

## 一句话破除焦虑

> **AI 不会取代你,但会用 AI 的人会取代你。**

不是吓你 —— 是事实。这不是程序员才要面对的事,而是每一个会用电脑、会用手机、会用 Office 的人,都会被卷入的浪潮。

幸运的是:**用 AI 真的不难**。不需要写代码、不需要懂技术、也不需要花一分钱。这篇文章会用最生活化的场景,手把手带你用上 AI。

读完这篇,你会有:
- **6 个马上能用的场景**(工作 / 学习 / 生活 / 创作 / 翻译 / 决策)
- **10 个可以直接复制的 prompt 模板**(英文好的同学可以拿去用英文)
- **3 个让 AI 回答得更好的万能公式**
- **1 个绝对不会被骗的避坑清单**

全程不超过一杯咖啡的时间。

## 一、先选一个 AI 工具

不要纠结选哪个 —— **先用起来,等你熟悉了再换**。

| 工具 | 优势 | 适合谁 | 价格 |
| --- | --- | --- | --- |
| **ChatGPT**(OpenAI) | 综合最强、生态成熟 | 通用首选 | 有免费版 |
| **Claude**(Anthropic) | 长文分析、写作细腻 | 阅读 / 写作 / 编程 | 有免费版 |

不用注册一堆 —— **先选 1 个,用 1 周**,再考虑换。

## 二、3 个万能 Prompt 公式

你给 AI 的问题决定它的回答质量。掌握这 3 个公式,AI 立刻好用 10 倍。

### 公式 1:角色 + 任务 + 背景

```text
请你扮演 [角色],
帮我 [做什么],
背景是 [你的具体情况]。
```

**例子**:

```
请你扮演一个资深 HR,
帮我修改这份求职信,
背景是我想应聘一个互联网公司的产品经理岗位,有 3 年数据分析经验。
```

### 公式 2:举例 + 模板

```text
请按这个格式给我 [几个例子]。

格式:[你的格式]
```

**例子**:

```
请给我 5 个朋友圈文案的备选,主题是周末爬山。

格式:不超过 30 字,带 1-2 个 emoji,口语化
```

### 公式 3:分步 + 约束

```text
请一步步 [做某事]。
要求:
- [要求 1]
- [要求 2]
- [要求 3]
```

**例子**:

```
请一步步帮我规划国庆 7 天云南旅行。
要求:
- 总预算 8000 元/人(双成人)
- 不去丽江、大理这种热门地,要小众
- 包含交通、住宿、必玩景点清单
```

## 三、6 大实战场景(直接照抄)

### 场景 1:写工作邮件 / 周报

#### 痛点

- 每周要交周报,每次都不知道怎么写
- 跟同事/老板沟通,要"既不卑微又不得罪"
- 邮件主题怎么写?开头怎么寒暄?

#### Prompt 模板

```text
请你扮演一个职场沟通专家,
帮我写一封 [邮件类型:通知/请求/道歉/感谢] 邮件,
背景是 [你的具体场景],
语气要求 [正式/半正式/轻松],
接收人是 [谁,如:我的直属领导,40 岁男性,性格直接],
请给我 3 个版本让我挑选。
```

#### 实战例子

```
请你扮演一个职场沟通专家,
帮我写一封请假邮件,
背景是我请 3 天病假(重感冒),手上有一个紧急项目要交接给同事小王,
语气要求半正式,
接收人是我的直属领导,40 岁男性,性格直接、注重效率,
请给我 3 个版本让我挑选。
```

#### AI 输出(示例)

```text
版本一(简洁版):
主题:请假申请 - [你的名字]
正文:
王总好,
因重感冒医生建议休息,申请 9/10-9/12 共 3 天病假。
手上紧急项目已与同事小王交接,期间可通过微信联系我处理紧急事项。
请批准。
[你的名字]

版本二(细致版):
主题:请假申请(3 天病假)+ 项目交接安排
正文:
王总好,
非常抱歉临时请假。
9/10-9/12 共 3 天,因持续发烧,医生建议在家休息。
项目交接:
1. 紧急事项 → 小王(微信:xxx)
3. 关键截止 9/15 的客户报告 → 已写到 80%,小王可继续
烦请批准。
[你的名字]
```

### 场景 2:总结长文 / 会议纪要

#### 痛点

- 老板发个 10 页 PDF,让你"看一下"
- 会议开了 2 小时,你要写会议纪要
- 看一堆英文资料,只想知道重点

#### Prompt 模板(长文总结)

```text
请你扮演一个资深编辑,
帮我总结这篇 [文章/报告/对话]:
[粘贴内容,或写"粘贴在下方"]。

要求:
- 提取 5 个最核心的观点
- 每个观点用 1-2 句话说明
- 用我 5 分钟能读完的篇幅
- 保留关键数据/案例
```

#### Prompt 模板(会议纪要)

```text
请你扮演一个专业秘书,
帮我把下面这段会议录音/笔记转成会议纪要:
[粘贴内容]。

要求:
- 按"会议主题 / 参与人员 / 讨论要点 / 行动项(谁、做什么、截止日期)"格式输出
- 用客观陈述,不要加个人评价
- 行动项用表格
```

#### 实战例子

```
请你扮演一个专业秘书,
帮我把下面的会议笔记转成会议纪要:
"周一上午产品组讨论,小李、小张、小王参加。
主要讨论了 Q4 的产品规划,小李说要做新功能 A,B 优先级被
推到 Q1,小张反对,认为会影响用户满意度。最后决定 A
功能 9/30 上线,小李负责方案,小张负责用户调研,
小王负责运营支持,截止 9/15。"

要求按"会议主题 / 参与人员 / 讨论要点 / 行动项"格式输出。
```

#### AI 输出(示例)

```text
会议主题:Q4 产品规划讨论
参与人员:小李、小张、小王
日期:周一上午

讨论要点:
- Q4 新功能 A 的规划
- 小张担心影响用户满意度
- 最终决定 A 功能 9/30 上线

行动项:
| 负责人 | 任务 | 截止日期 |
| --- | --- | --- |
| 小李 | 出具 A 功能方案 | 9/15 |
| 小张 | 用户调研 | 9/15 |
| 小王 | 运营支持 | 9/30 上线前 |
```

### 场景 3:学习新东西

#### 痛点

- 想学一个新领域,不知道从哪开始
- 看到一个概念,看不懂
- 想系统学习,但没时间看书/上课

#### Prompt 模板

```text
我想学 [主题/技能],但我是完全的初学者。
请你:
1. 用 100 字告诉我这是什么
2. 列出 5 个最核心的概念(每个一句话)
3. 推荐 3 个最适合我这种小白的入门资源(书/视频/网站)
4. 给我一个 7 天学习计划(每天 1-2 小时)
```

#### 实战例子

```
我想学股票投资,但我是完全的初学者,之前只买过余额宝。
请你:
1. 用 100 字告诉我 A 股 / 港股 / 美股 区别
2. 列出 5 个最核心的概念
3. 推荐 3 个最适合我这种小白的入门资源
4. 给我一个 7 天学习计划(每天 1-2 小时)
```

### 场景 4:翻译 + 改写

#### 痛点

- 看英文邮件/文章/合同,中文翻译不准确
- 想写一段英文但语法不对
- 把一篇技术文章翻译给非技术同事

#### Prompt 模板(精准翻译)

```text
请你扮演一个专业翻译,
帮我把下面这段 [中文/英文] 翻译成 [目标语言]:
[粘贴内容]

要求:
- 信、达、雅,优先"达"(意思准确)
- 保留专业术语,首次出现给出中英对照
- 语气 [正式/口语/学术]
```

#### Prompt 模板(改写语气)

```text
请你帮我把下面这段话改写成 [目标语气],
保留原意,但让 [目标受众] 更容易接受:
[粘贴内容]

要求:
- 字数 [增减范围]
- 关键信息不能丢
- 给 2 个版本让我选
```

#### 实战例子

```
请你帮我把下面这段技术说明改写成产品文案,
保留原意,但让不懂技术的普通用户更容易接受:

"本系统采用分布式事务一致性协议 (Raft) 实现高可用,
通过 WAL 写入保证数据零丢失,支持主从自动切换 (RTO < 30s)。"

要求:字数不超过 80 字,给 2 个版本让我选。
```

### 场景 5:头脑风暴 / 创意

#### 痛点

- 想给孩子起名/写口号/想活动策划
- 没有灵感,卡壳
- 想突破思维定式

#### Prompt 模板

```text
请你扮演一个创意总监,
帮我想 [多少] 个 [什么],
要求 [约束条件]。

约束:
- 风格:[活泼/优雅/科技/复古]
- 长度:[多少字]
- 受众:[谁]
- 必须避开:[敏感词/竞品名/...]
```

#### 实战例子

```
请你扮演一个创意总监,
帮我想 10 个咖啡店的名字,
风格要文艺、有故事感、容易记,
避开"猫""鹿""茶"这种已经被用烂的字眼,
最好能有典故。
```

### 场景 6:生活决策 / 消费决策

#### 痛点

- 想买 [手机/电脑/保险/课程],不知道选哪个
- 想装修/旅游,纠结方案
- 想给小孩选兴趣班

#### Prompt 模板

```text
我想 [做某事],预算 [多少钱],时间 [什么时候],
需求是 [1,2,3],
请你:
1. 帮我列 3-5 个候选方案
2. 列出每个方案的优势/劣势/适合谁
3. 给出你的推荐 + 推荐理由
4. 提醒我需要注意的坑
```

#### 实战例子

```
我想给家里换一台扫地机器人,预算 2000-3000,
家里有宠物(猫),100 平,
需求是:
1. 能清理宠物毛
2. 拖地功能不错
3. 不要太吵(家里有老人)

请你帮我列 3-5 个候选方案,推荐 + 理由 + 提醒坑。
```

> 📌 **使用方法**:把方括号 `[...]` 替换成具体内容,直接发给 AI。

## 五、绝对不要信 AI 的 3 件事

AI 很强,但**有几个雷区千万别踩**。

### 雷区 1:不要让它查事实

```text
❌ "谁是 2024 年奥运会的冠军?"
❌ "XX 公司去年营收多少?"
❌ "Python 3.13 有什么新特性?"

```

AI 经常**编造事实**(俗称"AI 幻觉")。重要的事实请用:
- 搜索引擎(百度/谷歌)
- 专门的 AI 搜索(秘塔 AI / Perplexity)
- 官方文档

### 雷区 2:不要把敏感信息发给 AI

```text
❌ 身份证号 / 银行卡号 / 密码
❌ 公司机密文件
❌ 别人的隐私(姓名/电话/病历)
```

**默认任何发给 AI 的内容都可能被记录、被用于训练**。重要的事情不要让 AI 知道。

### 雷区 3:不要让 AI 替你做决定

```text
❌ "我该不该离婚?"
❌ "我应该买哪只股票?"
❌ "这个合同该不该签?"

```

AI 缺乏:
- 你的真实感受
- 现场信息
- 法律责任

**重大决定,问真人**。AI 可以帮你整理思路,但不能替你签字。

### 进阶版避坑清单

| 场景 | AI 适合 | AI 不适合 |
| --- | --- | --- |
| **查资料** | 找思路、整理框架 | 引用具体数字/年份 |
| **写代码** | 写样板、写注释、改 bug | 上线前的关键逻辑 |
| **写作** | 起稿、改写、找灵感 | 最终定稿(自己 review) |
| **学习** | 解释概念、列学习路径 | 替代真正动手练习 |
| **决策** | 列方案、比较优劣 | 替你的"最终拍板" |
| **医疗 / 法律 / 财务** | 解释概念、整理资料 | 替代专业人士 |

## 六、AI 杠杆的两层:自用 + 复制

最后,也是最重要的一点 —— AI 真正的杠杆,其实有**两层**。大多数人只用了第一层,忽略了更值钱的第二层。

### 6.1 第一层杠杆:把"已会的重复"交给 AI

```mermaid
flowchart LR
    A[你懂 / 会做]::: root --> B[重复的部分]::: warm --> C[交给 AI]::: hot --> D[10x 效率]::: hot
    classDef root fill:#dcfce7,stroke:#15803d
    classDef warm fill:#fed7aa,stroke:#ea580c
    classDef hot fill:#fee2e2,stroke:#dc2626
```

**这是大多数人理解的"AI 杠杆"** —— 把你**已经掌握**的工作流里那些**重复的、可信息化的**环节,交给 AI。

| 你的输入 | AI 替你的重复部分 | 你省下来的精力 |
| --- | --- | --- |
| 你懂的英语语法 | 翻译、润色、改写 | 专注写作思路 |
| 你会的代码 | 样板代码、bug 排查 | 专注架构设计 |
| 你会的 HR 面试经验 | 生成面试问题清单 | 专注识别候选人潜力 |
| 你会的销售话术 | 写跟进邮件、客户回复 | 专注客户关系 |

**关键洞察**:**前提是你自己得会**。你不会的东西,AI 给了你也不知道对不对。

**第一层杠杆的天花板**:你的时间还是 24 小时 —— **AI 让你"一个人干得更快",但你仍然只能"卖给一家公司 / 服务一个客户"**。

### 6.2 第二层杠杆:把你的经验"复制"给别人

```mermaid
flowchart LR
    A[你的独特经验]::: root --> B[结构化 / SOP / 知识库]::: warm --> C[通过 AI 分发]::: hot --> D[无限次复用]::: hot
    classDef root fill:#dcfce7,stroke:#15803d
    classDef warm fill:#fed7aa,stroke:#ea580c
    classDef hot fill:#fee2e2,stroke:#dc2626
```

**这是更值钱的杠杆** —— 把你**独有的经验、行业 know-how、人生阅历**,通过 AI 沉淀下来,服务**无数人**,而不只是你自己。

| 你的经验 | 沉淀成 | AI 帮你服务 |
| --- | --- | --- |
| 老医生 30 年的诊疗经验 | 知识库 + AI 助手 | 给基层医生做实时辅助 |
| 资深 HR 5000+ 次面试经验 | 提问清单 + 评分模型 | 给新人 HR 做教练 |
| 销售冠军的客户沟通话术 | 沟通框架 + AI 模拟器 | 给新人做陪练 |
| 老母亲 20 年育儿心得 | 场景应对手册 | 给年轻妈妈当顾问 |
| 老员工踩过的所有坑 | 新人 onboarding 手册 | 给新员工做入职导航 |

**核心洞察**:**第一层放大的是"你的产能",第二层放大的是"你的价值"**。这两层叠加,杠杆率才真的大。

### 6.3 什么经验值得通过 AI 放大?

不是所有经验都值得 —— 通用知识(比如"勾股定理")不需要你,网上一搜就有。

**值得放大的经验有 3 类**:

#### 类型 1:行业专属经验

```text
✅ 值得放大:
- 医生:罕见病的诊疗思路、并发症处理
- 律师:合同常见坑、谈判技巧
- 老师:某学科的难点突破、学生常见误区
- 设计师:品牌视觉的判断直觉
- 工程师:特定业务场景的代码模式

❌ 不值得放大:
- "如何在 Word 里打字"(太通用)
- "1+1=2"(人人都懂)
```

#### 类型 2:工作方法论

```text
✅ 值得放大:
- 怎么开高效的会议
- 怎么带新员工上手
- 怎么写一份让人想读的报告
- 怎么谈加薪不被拒

❌ 不值得放大:
- "怎么发邮件"(基础操作)
- "怎么用 Excel 打开"(基础操作)
```

#### 类型 3:人生阅历

```text
✅ 值得放大:
- 怎么跟难相处的老板相处
- 怎么在 30 岁前存下第一个 100 万
- 怎么跟叛逆期的孩子沟通
- 怎么在婚姻里保持独立

❌ 不值得放大:
- 过分隐私 / 只适用你自己的事
```

### 6.4 怎么把经验沉淀给 AI?(4 步法)

#### Step 1:把"脑子里的东西"写出来

```text
模板:"我每次做 XXX 的时候,脑子里在想什么?"

例如:
- "我每次跟客户谈价格,脑子里在想什么?" → 5 个原则
- "我每次帮新人 debug,脑子里在想什么?" → 6 个排查顺序
- "我每次给孩子选兴趣班,脑子里在想什么?" → 3 个筛选标准
```

#### Step 2:结构化成 SOP

把零散想法变成**可重复的步骤**:

```text
模板:
1. 第一步:看 [X]
2. 第二步:如果 [Y],做 [A];如果 [Z],做 [B]
3. 第三步:检查 [W]
4. 常见坑:[坑 1, 坑 2]
```

#### Step 3:喂给 AI(让 AI 学会你的风格)

```text
"请你扮演我的[角色]助手,
回答用户问题时,严格按我的[上面写的 SOP]思考,
参考我给你的 3 个案例回答风格。

不要给用户我没说过的建议;
不确定的时候,告诉用户'建议咨询专业人士'。"
```

#### Step 4:通过 AI 分发

**分发渠道**:
- 自己做一个微信机器人 / 网页
- 在公司内做一个内部 AI 助手(用 RAG 喂你的文档)
- 做成付费产品(小红书 / 知识星球 / 小报童)
- 卖给行业客户(B 端工具)

### 6.5 5 个真实例子

```text
沉淀方式:

杠杆率:原本只服务一个医院的孩子 → 通过 AI 服务 10 万基层医生 →

```

## 九、FAQ

### Q1:AI 会不会让我变笨?

**会 —— 如果你只是把 AI 当抄作业工具**。

正确用法:**AI 出方案,你审方案;**AI 起框架,你填血肉。

如果 AI 什么都替你做了,你只是"AI 操作员",不是"AI 主人"。

### Q2:免费版够用吗?

**99% 的人免费版就够**。付费版主要是:
- 更长的上下文(可以处理超长文档)
- 更新的模型
- 更快的速度
- 更高的使用额度

建议先用免费版 1 个月,真的"卡上限"再考虑付费。

### Q3:用 AI 写出来的东西算不算"我的"?

**法律上**:目前大部分国家/地区,**AI 生成的内容没有版权**,但你用 AI 生成并做了实质性修改的,有版权。

**伦理上**:用 AI 写出来直接交差 = 不诚实;用 AI 起草 + 自己深度修改 = 工具化使用,合理。

**实践上**:大多数场景下,没人关心你用了 AI —— 大家关心你的最终成果好不好。

### Q4:AI 回答错了怎么办?

1. **指出错误**:`"你刚才的回答有错,[正确的事实是 X],请重新回答"`
3. **换个 prompt**:`"请你重新回答,但这次 [加更多约束 / 给更多上下文]"`
4. **换工具**:不同 AI 的训练数据不一样,同一个问题问 2-3 个工具对照

### Q5:我爸妈 / 我老板 / 我朋友不会用 AI,怎么教他们?

**3 步教学法**:
1. **演示**:你亲自示范一个他们关心的具体场景(写个朋友圈文案、查个菜谱)
2. **让他们试一次**:手把手让他们输 prompt,看到结果
3. **给一个模板**:让他们存起来,以后自己用
