## 第一讲:为什么你打不开外网

### 1.1 讲什么

这一讲的目的不是让大家懂技术,而是**让学员理解"为什么"**,后面学 Clash 时才不会觉得是在做一件 mysteriously 的事。

### 1.2 先做个现场小测试

讲师现场问三个问题,举手统计:

```text
1. 你现在能打开 google.com 吗?
2. 你能打开 baidu.com 吗?
3. 你知道为什么第 1 题和第 2 题答案不一样吗?
```

通常结果是:百度人人能开,Google 大部分人开不了。这说明**问题不在你的电脑,而在"路"上**。

### 1.3 核心原理:四道门

用"快递"打比方,学员秒懂:

> 你寄一个包裹到国外。包裹要经过:**你家楼下 → 快递点 → 跨境关口 → 对方国家 → 收件人**。
> 任何一关卡住,包裹就到不了。

对应到网络:

```text
你的电脑
   │
   ▼
① 家里/公司的网络出口（运营商网关）
   │      ← 有些单位会在这里设置访问限制
   ▼
② 跨境链路（国际出口）
   │      ← 带宽有限、有策略、部分服务不在可用范围内
   ▼
③ 目标网站的服务器（它的门禁和风控）
   │      ← 有些网站对中国大陆 IP 做区域限制
   ▼
④ 目标服务（Google、OpenAI、Anthropic…）
```

**四个环节,任何一环都可能把你挡住。** 这也是为什么"有时候能上,有时候不能"——不同网站卡在不同的环节。

### 1.4 最常见的三个具体原因

**原因一:链路本身不通(最常见)**

国际出口的流量是按目的地分流的。有些境外服务不在可用列表里,访问请求到关口就被拦下了。表现就是:页面一直转圈,最后显示"无法访问此网站"。

**原因二:域名解析被干扰(第二常见)**

你输入的是域名 `google.com`,但电脑需要先把它变成一串 IP 地址才能连接。这个转换动作叫 **DNS 解析**,由 DNS 服务器完成。如果返回的 IP 是错的或者空的,浏览器就会报:

```text
DNS_PROBE_FINISHED_NXDOMAIN
ERR_NAME_NOT_RESOLVED
```

这就是为什么"有代理也打不开"——你的代理根本没机会工作,因为它连门牌号都没拿到。

**原因三:网站主动限制你的地区**

即使网络通了,网站本身也可能对"中国大陆 IP"限制访问。这类情况表现很有特征:**别的网站都正常,偏偏某一个打不开,或者能打开但提示"服务不可用"**。

### 1.5 Clash 是干什么的

> **Clash 的作用:替你从"能通的那扇门"出去。**

它的具体工作有三件事:

| 工作 | 大白话解释 |
| --- | --- |
| **换一条路出去** | 把你的访问请求交给境外的出口服务器,再由它去访问目标网站 |
| **管好 DNS** | 让域名解析走该走的服务器,不被干扰 |
| **分流** | 国内网站直连(不绕路),只有需要的境外网站才走通道 |

**"分流"是 Clash 最被低估的价值。** 如果所有流量都绕道,你会遇到:国内网站变慢、网银弹风控、快递和支付异常、公司内网打不开。而开了规则分流后,你几乎感觉不到它的存在,只有打开 Google 的时候才"嗖"一下变快了。

### 1.6 现场演示

讲师现场打开 Clash,展示三个东西,让学员建立直观印象:

1. 打开客户端 → 展示"代理""直连""拒绝"三种规则的真实匹配日志
2. 打开一条日志,指着 `google.com` 那行说"这条走了代理",指着 `taobao.com` 那行说"这条直连"
3. 现场切换一次节点,让学员看到延迟数字变化

### 1.7 学员练习

```text
【练习 1-1】用一句话向同桌解释:为什么你打不开 Google?
参考:不是电脑坏了,是"路"不通;Clash 就是帮你换一条能通的路。

【练习 1-2】说出三个"可能出问题"的环节。
参考:本地网络出口 / 跨境链路 / 网站自身限制(再加 DNS 解析更好)。
```

### 1.8 常见提问

| 学员会问 | 讲师这样答 |
| --- | --- |
| "是不是我电脑坏了?" | 换台电脑、换手机热点试,能开就是网络问题,不是电脑问题 |
| "用外网违法吗?" | 请遵守所在地法律法规和单位规定;工具本身是公开的,关键是使用场景要合法合规 |
| "会不会有病毒?" | 认准官方下载渠道;不装来路不明的"破解版""绿色版" |
| "免费的和付费的差别?" | 免费节点不稳定、人多;付费一般更稳定、延迟更低。具体请自行选择合规渠道 |

## 第二讲:用 Clash 把外网连起来

### 2.1 讲什么

这一讲是**动手课**。目标:全班每一个人都成功打开 Google。

### 2.2 第一步:下载安装包

| 系统 | 推荐客户端 | 说明 |
| --- | --- | --- |
| Windows | **Clash Verge Rev** | 最主流,教程最多 |
| macOS | **Clash Verge Rev** | 支持 Intel 和 Apple Silicon |
| 安卓手机 | **Clash Meta for Android** | 手机端主力 |
| iPhone | **Stash** | 需要 App Store 获取 |

**下载要点**:

```text
1. 搜索引擎搜 "Clash Verge Rev 官网",认准官方 GitHub 项目页
2. 进入 Releases 页面,选择与你系统对应的版本
3. Windows 选 .exe,macOS 选 .dmg
4. 下载后先看文件大小是否正常(几十 MB 量级)
```

**安全提醒**:认准官方仓库,不要从网盘、论坛附件、群文件里下载二手安装包——这类文件被植入额外程序的比例不低。

**macOS 额外一步**:第一次打开会提示"无法打开,因为来自身份不明的开发者"。解决办法是:在访达里**右键点击 → 打开 → 再点"打开"**。

### 2.3 第二步:导入订阅

Clash 本身不含任何线路,它只是一个"交通指挥中心"。你需要把服务方提供的**订阅链接**交给它。

```text
1. 打开 Clash Verge Rev
2. 左侧栏找到「订阅」(有的版本叫"配置"/"Profiles")
3. 点「新建」,把订阅链接粘贴进去,给它起个名字(如"我的订阅")
4. 保存 → 右键这条订阅 → 点「更新」
5. 更新成功后,列表里会出现一串节点(国家名 + 数字)
```

**如果这一步卡住**:

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 提示订阅无效 | 链接复制不全,少了字符 | 重新完整复制,注意别漏开头结尾 |
| 更新超时 | 网络问题,或订阅已过期 | 先用手机热点试;确认订阅还有效 |
| 更新成功但没有节点 | 订阅里没配置 | 找服务方确认 |

### 2.4 第三步:选节点

```text
1. 左侧「代理」页面
2. 顶部会看到几个分组,通常是「节点选择」「自动选择」「直连」等
3. 点进分组,会看到一长串节点,前面带国旗和延迟数字
4. 选一个延迟较小的(100–300ms 都算正常)
5. 想省事就直接选「自动选择」,客户端会自己挑最快的
```

**延迟数字怎么看**:

| 数字 | 含义 |
| --- | --- |
| 绿色 / < 200ms | 流畅,日常够用 |
| 黄色 / 200–500ms | 能用,看视频可能偶尔卡 |
| 红色 / > 800ms 或超时 | 换节点 |

**选节点的地区建议**:日本、韩国、新加坡、香港通常延迟低且稳定;美西次之。选**距离近**的比选"看起来厉害"的重要。

### 2.5 第四步:打开系统代理(最关键的一步)

```text
1. 回到客户端主界面(右上角或右上角小图标)
2. 找到「系统代理」开关,点开
3. 浏览器打开 google.com
```

> ⚠️ **这是全场最高频的失误点。** 很多学员导入完订阅、选好节点,发现还是打不开——因为**总开关没打开**。讲师务必让每个学员当场确认浏览器能打开 Google 再进入下一节。

### 2.6 第五步:选对"模式"

客户端一般有三种模式:

| 模式 | 含义 | 建议 |
| --- | --- | --- |
| **规则模式(Rule)** | 按规则分流:国内直连、境外走代理 | ✅ **日常用这个** |
| **全局模式(Global)** | 所有流量都走代理 | ❌ 会让国内网站变慢、网银风控 |
| **直连模式(Direct)** | 全部不走代理 | ❌ 等于没开 |

### 2.7 第六步(可选):DNS 与 TUN

**DNS 设置**:如果规则模式都调好了,只有个别网站打不开,页面上出现 `DNS_PROBE_FINISHED_NXDOMAIN`,就需要改 DNS。

```text
位置:设置 → DNS
做法:把 DNS 改成「远程 DNS / DoH」,填入例如
      https://doh.pub/dns-query
      https://dns.alidns.com/dns-query
```

**TUN 模式**:让那些"不支持系统代理"的软件(某些手机 App、命令行工具、游戏)也能走通道。

```text
位置:主界面上的「TUN 模式」开关
什么时候开:系统代理开着但某个 App 还是连不上时
注意:开启后如果出现网络异常,先关掉 TUN,回到系统代理
```

### 2.8 排错速查表(打印贴在桌上)

| 现象 | 最可能的原因 | 处理动作 |
| --- | --- | --- |
| 所有网站都打不开 | 本地网络断了 | 用手机热点测试,排除本地问题 |
| 国内正常、境外全打不开 | 系统代理开关没开 | 打开总开关 |
| 浏览器可以,微信/QQ 不行 | 该软件不支持系统代理 | 打开 TUN 模式 |
| 网银、支付、公司系统打不开 | 走了代理触发风控 | 换规则模式;把相关站点设为直连 |
| 提示 DNS 解析错误 | DNS 被干扰 | 改成 DoH(见 2.7) |
| 时好时坏 | 节点拥塞 | 换节点,或用"自动选择" |
| 视频网站提示不可用 | 出口地区受限 | 换国家/地区的节点 |
| 用了 VPN 软件后 Clash 失效 | 两个软件抢占代理设置 | 关掉其中一个 |

### 2.9 现场演示

```text
演示 A:导入订阅 → 选节点 → 开系统代理 → 打开 Google(全程投屏)
演示 B:故意把模式切成「全局」,打开淘宝,让学员看到加载变慢
        再切回「规则」,淘宝立刻恢复 —— 讲清"分流"的价值
演示 C:打开客户端日志,指着 google.com 和 taobao.com 两条不同的走向
```

### 2.10 学员练习

```text

【练习 2-2】打开客户端日志,找到 google.com 那一行,截图保存,
```

## 第三讲:Google 搜索与 SCI 论文检索

### 3.1 讲什么

这一讲是全场**最实用**的部分,分两半:

```text
上半场:Google 怎么搜得准(通用技巧)
下半场:怎么找论文、怎么判断是不是 SCI(学术检索)
```

### 3.2 先把 Google 账号办好

一个 Google 账号是整个工具链的通行证——ChatGPT、YouTube、很多 AI 工具都能直接用它登录。

**注册要点**:

| 步骤 | 说明 |
| --- | --- |
| 邮箱 | 用常用邮箱(QQ、163、Outlook 都行) |
| 手机号 | 收不到验证码就换号或用语音验证 |
| 验证 | 按提示点"我不是机器人" |

**注册完立刻做两件事**:

```text
1. 打开 myaccount.google.com,添加一个备用邮箱(主邮箱登不上时的救命通道)
2. 开启两步验证:优先选「通行密钥」或「验证器 App」,不要只靠短信
```

### 3.3 上半场:让 Google 搜得更准

| 技巧 | 写法 | 效果 |
| --- | --- | --- |
| 精确短语 | `"连字符为什么报错"` | 只找含这句话的页面 |
| 限定网站 | `site:zhihu.com 考公 报名` | 只在指定站点里搜 |
| 限定文件 | `filetype:pdf 机械制图 习题` | 只找 PDF |
| 排除 | `买手机 -二手 -广告` | 排掉不想要的 |
| 任选其一 | `PS OR Sketch 设计工具` | OR 表示二选一 |
| 通配 | `"如何申请*补贴"` | 星号代表任意词 |
| 找相似站 | `related:youtube.com` | 找同类网站 |
| 缓存快照 | `cache:example.com` | 网站打不开时看旧内容 |

**三条最实用的组合**:

```text
# 找官方教程,避开二手转载
site:support.google.com 账号申诉

# 搜报错:必须用完整原句 + 引号
"SSL certificate problem: unable to get local issuer certificate"

# 搜软件官方文档
site:docs.python.org "asyncio.wait_for"
```

> 💡 **一个立刻见效的习惯**:中文搜索结果里营销号太多,**在中文关键词后面加一个英文词**,往往直接命中官方文档。

### 3.4 Google 的其他常用功能

| 功能 | 入口 | 用途 |
| --- | --- | --- |
| 翻译 | translate.google.com | 整页翻译、文档翻译、语音翻译 |
| 图片搜索 | images.google.com | 搜图、反查图片出处 |
| 地图 | maps.google.com | 导航、查营业时间、看实景 |

**NotebookLM 值得单独讲**:你把 PDF、讲义、笔记、录音转写丢进去,它**只根据你给的材料回答**,还能自动生成摘要、脑图和音频播客。做作业、读文献、总结会议记录,它比通用 AI 靠谱得多,因为它被限制在"只从资料里找答案"。

### 3.5 下半场:为什么要查 SCI

先讲清楚几个概念,这是很多人混着说的地方:

| 概念 | 准确含义 |
| --- | --- |
| **SCI** | Science Citation Index,现全称 SCI Expanded(SCI-E),是 Web of Science 收录的**自然科学类期刊索引** |
| **SCI 论文** | **发表在 SCI 收录期刊上的论文**。判断标准是期刊,不是论文本身 |
| **SSCI** | 社会科学引文索引,对应社科类期刊 |
| **EI** | 工程索引,工程类期刊 |
| **影响因子(IF)** | 期刊的引用影响力指标,不是单篇论文的指标 |
| **JCR 分区** | Clarivate 官方分区,按影响因子在同领域期刊中排名,分 Q1–Q4 |
| **中科院分区** | 中国科学院文献情报中心分区,分 1–4 区,另有大类/小类 |

**为什么普通人也要关心**:

- 学生:毕业、评奖、申请奖学金、读博
- 医生:职称晋升、课题申报
- 工程师/教师:职称评定、基金项目
- 写文章、做内容:找权威资料、引用正规文献

> ⚠️ **一个必须讲清的误区**:**"SCI 论文"不等于"SCI 期刊"**,而**"SCI 期刊"也不等于"中科院一区"**。这是三套不同的评价体系,招聘和申报时要求写得很具体,不要混为一谈。

**普通学员怎么用付费库**(这是最常被问的):

```text
方法一(最省事):连校园网访问
        很多高校的 IP 段在校内是直接开通 Web of Science / Scopus / 知网 的
        只要电脑连着校园 WiFi,打开数据库就自动识别权限

方法二:学校图书馆的 WebVPN
        登录学校图书馆主页 → "校外访问"/"WebVPN" → 用校园账号登录
        → 在资源列表里点 Web of Science / 知网 → 全文访问

方法三:文献传递
        实在拿不到,可以让图书馆帮忙"文献传递"或"馆际互借"
        在学校图书馆网站找"文献传递"入口,一般免费或很低成本

方法四:找开放获取版本
        arXiv、PubMed Central、DOAJ、Unpaywall
        Google 学术结果右侧常直接出现 [PDF] 或 [HTML] 链接,点它就是可下载的版本
```

### 3.7 怎么判断一篇论文是不是 SCI

给出**固定四步法**,学员照做即可:

```text
第 1 步:拿到期刊全名
        注意是"完整英文刊名",不是缩写(如 "IEEE Transactions on Image Processing")

第 2 步:打开 Web of Science 的期刊查询页
        地址:webofscience.com → 顶部 "Master Journal List"
        或直接访问 wosmasterlist.clarivate.com

第 3 步:输入刊名,勾选 SCI-E / SSCI,看是否出现在结果里

第 4 步:再查分区
        - JCR 分区:webofscience.com → Journal Citation Reports
        - 中科院分区:分区表通常要学校/图书馆权限或官方购买
```

**辅助判断方法**:

| 方法 | 说明 |
| --- | --- |
| 看期刊官网 | 很多期刊首页会写 "Indexed in SCI / SCIE / EI" |
| 看文章首页的标注 | 正式发表的 SCI 论文通常会印 "SCI 收录" 或具体的收录号 |
| 查 ISSN | 期刊官网或 ISSN Portal 可查 |
| 用 Web of Science 反查 | 在 WoS 里按刊名搜索,能看到该刊收录的全部文章 |

**讲清楚三个常见混淆**:

```text
✗ "这个期刊是核心期刊" → 说的是中文核心(北大核心/CSSD/CSCD),不是 SCI
✗ "这个期刊影响因子 5" → IF 高不代表是中科院一区,两套分区算法不同
✗ "这篇文章发在 SCI 期刊上所以是 SCI 论文" → 对,但仍需确认该刊在当年确实被收录
```

### 3.8 检索论文的实用技巧

**关键词组合**(在 Web of Science、Google 学术里通用):

```text
基础写法:
  "关键词A" AND "关键词B"
  "machine learning" AND "medical imaging"

排除:
  "keyword A" NOT "keyword B"

字段限定(Web of Science 专属):
  TI(题名)      TI="segmentation"
  AB(摘要)      AB="transformer"
  AU(作者)      AU="Zhang Wei"
  SO(期刊名)    SO="Nature"

组合示例:
  TI="deep learning" AND AB="ECG" AND AU="Smith"
```

**最有效的爬文献方法:引文追踪**

```text
1. 先用 Google 学术找到 1–2 篇这个方向的核心综述(Review)
2. 在综述里,顺着"参考文献"往下读 —— 综述已经把该领域的重要文献整理好了
3. 在 Google 学术里点"被引用次数"(Cited by),看后来的论文引用了谁
4. 用 Connected Papers 输入一篇核心论文,直接生成关系图谱,
   找综述和领域内的其他关键文献,比一个个搜快十倍
```

> 💡 **一句口诀**:**先找综述,顺着综述的参考文献读;再顺着被引,看最新进展。**

### 3.9 用 AI 帮你读论文

这是把 AI 用在科研场景的最直接价值点,也是培训的高潮。

**方法一:把 PDF 丢给 ChatGPT 或 Claude**

ChatGPT 和 Claude 都支持直接上传 PDF,然后用这个模板问:

```text
请以严谨的研究助理身份,读我上传的这篇论文,并输出:

1. 【一句话结论】这篇论文解决了什么问题
2. 【研究问题】它想回答什么
3. 【方法】用了什么模型/算法/实验设计,关键创新点在哪
4. 【数据集与实验】用了什么数据,主要指标和结果是什么,
   请把关键数据整理成表格(指标 / 数值 / 对比基线)
5. 【局限】作者自己承认的局限,以及我额外发现的 3 个问题
6. 【复现要点】如果我要复现,需要哪些数据、算力和步骤
7. 【术语表】把文中 10 个专业术语列成"中文(English)"对照表

要求:
- 每个结论后面用 [原文页码] 标注出处
- 如果文中没有提到某个信息,直接写"文中未提及",不要编造
- 如果我看不懂某个关键概念,额外用通俗语言解释一段
```

**方法二:批量丢进 NotebookLM**

```text
把 10–20 篇同一主题的论文丢进 NotebookLM,
然后问:"这些论文在方法上的分歧是什么?""哪个结论被最多论文支持?"
它会基于你给的材料回答,并标注出自哪篇文档的哪一段。
```

**必须提醒学员的三条底线**:

```text
1. AI 读论文会"美化"——它可能把作者没做的实验说成做了。
   要求它标注原文页码,自己核对。
2. 绝对不要把 AI 的总结当成文献综述直接用。
   综述必须自己一篇篇读过、确认引用准确。
3. 涉及数据和结论,永远以原文为准。AI 只是你的阅读加速器,不是替身。
```

## 第四讲:YouTube 自学法

### 4.1 讲什么

**YouTube 是全世界最大、最免费、最系统的学习库**。很多英文教程有自动字幕,配合 AI 摘要,效率能翻倍。

### 4.2 先把播放器调顺手

| 设置 | 在哪点 | 建议 |
| --- | --- | --- |
| 字幕 | 播放器右下角 `CC` | 英文视频必开 |
| 字幕语言 | 齿轮 → 字幕 → 字幕语言 | 有"自动生成"就够 |
| 播放速度 | 齿轮 → 播放速度 | **1.25–1.5 倍**是甜点区 |
| 画质 | 齿轮 → 画质 | 1080p 足够,网差就降 |
| 章节 | 进度条上的小标记 | 找重点直接跳 |
| 跳过广告 | 点"跳过广告" | 手点即可 |

**倍速是被严重低估的功能**。1.5 倍速配合字幕,大部分科普和教程类视频的理解速度能提升一半以上。

### 4.3 找好内容的搜索语法

| 写法 | 作用 | 例子 |
| --- | --- | --- |
| `"..."` | 精确短语 | `"excel 快捷键 教程"` |
| `-` | 排除 | `吉他 -翻唱` |
| `intitle:` | 标题必须含 | `intitle:"零基础"` |
| `after:` / `before:` | 时间限定 | `after:2025 python 教程` |
| `channel:` | 指定频道 | `channel:fireship` |

**找"完整系列课"的实用写法**:

```text
"完整教程" "从入门到精通"
"零基础" "全流程" 副业
site:youtube.com "system design interview"
```

### 4.4 收藏:建立你自己的课程表

```text
建三个播放列表:
  「想看」  —— 刷到先存下来
  「正在学」 —— 学到哪了,进度就在哪
  「看完要动手」 —— 看完了要实践的,提醒自己动手
```

> 💡 **一句话纪律**:**收藏而不看等于没收藏**。每周清一次「想看」,超过两周没动的就删掉。

### 4.5 用 AI 消化字幕(重点技巧)

```text
1. 打开视频 → 点 CC → 用鼠标选中字幕文本 → 复制
2. 粘贴到 ChatGPT 或 Claude,配上这段话:

下面是我从视频里复制出来的字幕,可能有识别错误。
请帮我:
1. 整理成结构化笔记:核心观点分条列出,配上例子
2. 列出视频里提到的实用技巧或资源
3. 给我 3 个可以立刻动手练习的小任务
4. 最后出 5 道自测题,附答案

字幕:
(粘贴在这里)
```

对英文视频尤其有用:你不必完整听懂每个词,AI 帮你把结构理出来,你再回头看重点片段。

### 4.6 学员练习

## 第五讲:ChatGPT 上手

### 5.1 讲什么

ChatGPT 是**最通用的 AI**,写作、翻译、总结、研究都能用,也是大多数人的第一站。

### 5.2 注册有个坑要先知道

**ChatGPT 不支持手机号直接注册**,要用:

```text
① Google 账号(推荐,前面已经注册好了)  ← 最快
② Apple 的"通过 Apple 登录"
③ Microsoft 账号
④ 邮箱 + 手机号
```

### 5.3 选版本

| 版本 | 价格 | 建议 |
| --- | --- | --- |
| **免费版** | 0 | 先试一周,日常提问足够 |
| **Go** | 约 $8/月 | 想多聊又不想花 $20 |
| **Plus** | 约 $20/月(约 ¥145) | **个人最值得的一档** |
| **Pro** | 约 $100–200/月 | 靠 AI 干活,量很大 |
| **团队版** | 每席位约 $25/月 | 公司同事一起用 |

> 📌 **建议**:先用免费版把"什么问题上该问 AI"变成习惯。习惯养成了再升 Plus,不然容易变成"钱花了但没啥用"。

### 5.4 网页端值得花时间学的五个功能

| 功能 | 解决什么 | 怎么用 |
| --- | --- | --- |
| **联网搜索** | 查最新的东西,答案带链接 | 提问框点"搜索"图标 |
| **Projects 项目** | 长期任务的专属空间,资料和指令常驻 | 左侧栏 → 新建项目 → 上传文件 |
| **深度研究** | 自动查几十个来源,产出带引用的报告 | 提问框选"深度研究"模式 |
| **语音对话** | 不想打字,直接说 | 麦克风图标 |
| **上传文件** | 把 PDF、Word、图片丢给它读 | 提问框旁的回形针 |

**重点讲 Projects**:做"课题资料整理""公众号运营""毕业论文"这类要持续几天的事,建一个项目,把资料传进去,再写一段固定指令(比如"回答用中文,先给结论,数据要标来源"),之后每次开这个项目上下文都在,不用重复交代。

**深度研究**是做决策的神器:问"2026 年做跨境电商还来得及吗",它会自己查行业数据、平台政策、新闻,给你一份带出处的报告。不能全信,但作为"了解全貌"的起点极好。

### 5.5 提问四要素(全场最重要的技巧)

**① 一次只问一件事。** 三件事塞一条消息,它会答得又浅又乱。

**② 给出身份和背景。**

```text
我是一名高一学生的家长,孩子想学编程,
不知道该选 Python 还是 C++,请给建议并说明理由。
```

有了身份,建议会具体得多,而不是"这取决于个人偏好"。

**③ 把要求说清楚。**

```text
帮我写一封请假邮件。
要求:200 字以内,语气礼貌但不解释原因,
收件人是部门经理,直接给可用的版本。
```

"多少字""什么语气""要不要解释""给成品"——这四个限定加上,质量立刻不同。

**④ 不满意就追问,别重开。**

```text
太长了,压缩到 100 字。
语气再正式一点。
第三段不太通顺,重写一下。
```

一次就完美的情况少,**追问三轮**基本够了。

| **它会一本正经地编** | 尤其爱编书名、论文、链接、具体数字 | 凡是出处、数据、引用,必须自己点开核实 |

| **免费版限速** | 用多了提示达到上限 | 升级,或换 Claude / MiniMax 顶着 |
| **隐私** | 免费版对话可能被用于改进模型 | 设置里关掉 "Improve the model for everyone";敏感内容别贴 |
| **过度依赖** | 交上去不动脑,反而变弱 | 把 AI 当"随叫随到的聪明实习生",最后自己核对 |

## 第六讲:Claude 与长文档处理

### 6.1 讲什么

**Claude 更擅长"读长文"和"动手做东西"**,和 ChatGPT 形成很好的互补。

### 6.2 两者的差别

> **ChatGPT 更像"什么都会的通才";Claude 更像"读过很多书、还能动手的专才"。**

| 场景 | ChatGPT | Claude |
| --- | --- | --- |
| 读很长的 PDF / 一本书 | 能读,容易漏细节 | **更稳**,长文总结是强项 |
| 写作文案的风格 | 偏通用、偏安全 | **更有味道**,长文一致性更好 |
| 写代码、做小工具 | 能做,Codex 生态成熟 | **准确度和风格一致性更强** |
| 深度研究 | **更成熟**,引用完整 | 也不错 |
| 语音、图片理解 | **支持更全面** | 相对弱一些 |

> 💡 **给学员的建议**:不确定就两个都注册,免费版试错成本很低。谁顺手长期用谁。

### 6.3 套餐

| --- | --- | --- |

| Max 5× | $100/月 | Pro 的 5 倍用量 |
| Max 20× | $200/月 | Pro 的 20 倍用量 |
| 团队版 | 每席位 $30/月 | 团队协作 |

### 6.4 网页版三个值得用的功能

- **Artifacts(工件)**:左边聊天,右边独立工作区。它写的代码、画的图、做的文档直接显示在右边,你可以直接在里面改,不用复制到记事本。
- **Projects(项目)**:和 ChatGPT 概念一样,长期任务的专属空间。
- **研究模式**:连着查很多资料,给出结构化调研结果。

### 6.5 Claude Code:让 AI 真的做出东西

**Claude Code** 能在你的项目文件夹里直接读代码、改代码、跑命令。对学员的意义是:

> **你不需要会写代码,也能让 AI 帮你做出一个小工具。**

比如:"帮我做一个记账网页,记录每天花了多少钱,按分类统计,能导出成表格。"它会建文件、写代码、启动本地预览给你看,你说"改成深色主题",它就改。

**收费跟着 Claude 订阅走**:买 Pro 或 Max 就能用,也可以用自己的 API 密钥按量付费。

完全不想碰命令行的学员,看第九讲的 **ZCode**——那是同一件事的图形界面版本。

### 6.6 一个必须讲的限制

**Claude 网页版按 5 小时滚动窗口限制用量**,不是"每天 N 条"。窗口用满了就得等它滚动恢复。

```text

· 遇到限流,切到 ChatGPT 或 MiniMax 顶着
· Max 档位买的就是更大的窗口容量
```

## 第八讲:ZCode——你说想法,它帮你做出来

### 8.5 怎么把需求说清楚(核心技巧)

同样的工具,会提问和不会提问,结果差十倍。

**可复制的模板**:

```text
我要做一个:【一句话说清是什么】

给谁用:【用户是谁】
核心功能:【列出 3-5 条】
界面要求:【大概长什么样,越具体越好】
参考:【有类似的网站或 App 就写出来】

限制:
- 不要改动我已有的文件
- 不要自动联网下载东西
- 做完告诉我怎么启动它

不确定的地方先问我,不要自己猜。
```

**对比示例**:

❌ **差的问法**:"帮我做个记账 app"
→ 大概率给你一个功能残缺的命令行工具,跟"app"两回事。

✅ **好的问法**:

```text
我要做一个手机网页记账工具,存在浏览器里就能用。

- 不要用任何框架,单个 HTML 文件就能跑
- 做完告诉我用浏览器怎么打开
```
→ 它会直接产出一个能双击打开、手机也能用的 HTML 文件。

## 第九讲:MiniMax Design——做图做视频

### 9.1 讲什么

前面讲的工具输出的大多是文字和代码,**MiniMax Design 是专门做视觉内容的**——图片、视频、音频、文本,能在一个项目里混着做。

| 项目 | 信息 |
| --- | --- |
| 官网 | `design.minimax.io`(国内 `design.minimaxi.com`) |
| 形态 | 网页版 + 桌面客户端 |
| 桌面端 | macOS 13+、Windows 10+、Linux(测试版) |

### 9.2 界面只有三个区

| 面板 | 干什么的 |
| --- | --- |
| **AGENT 智能体** | 左边的对话框,提要求、调用技能 |
| **CANVAS 画布** | 中间的画布,所有素材在这里排布、替换、调整 |
| **INSPECTOR 检查器** | 右边属性面板,调尺寸、时长、风格等 |

> 记住"**左边提要求、中间摆素材、右边调参数**",你就已经会用八成了。

### 9.3 工作流五步

```text
AGENT MODE(对话) → CANVAS FLOW(画布) → SKILL READY(存技能)
   → LOCAL INDEX(素材库) → OUTPUT SYNC(导出)
```

大白话翻译:

1. **对话**:告诉它你要什么(用途、风格、尺寸、时长)
2. **画布**:它把需求变成一个个可单独修改的素材块
3. **存技能**:跑通一次后存成"技能",以后一键复用
4. **素材库**:把 logo、产品图、参考风格放进去,它会自动对齐
5. **导出**:成品下载到本地

> 💡 **第 3 步是分水岭**:只会用一次是"尝鲜",能存成技能才是"生产工具"。

### 9.4 动手做第一张图

**场景:咖啡店新品海报**

```text
帮我做一张咖啡店新品海报,竖版,尺寸适合朋友圈。
产品:一杯燕麦拿铁,透明玻璃杯,杯口有拉花。
风格:高级、干净,莫兰迪色调,不要廉价的促销感。
元素:左上是店名占位,中间是杯子,底部留出放价格和活动信息的位置。
```

出来之后在画布里单独调整:换杯子材质、调背景亮度、加大留白,每一处都能单独重生成。

**做视频**多一个"分镜"环节:

```text
这是一个 15 秒的产品宣传片,分三段:
第一段:原料特写(3 秒)
第二段:制作过程延时(7 秒)
第三段:成品展示,出现品牌名和 slogan(5 秒)
整体色调温暖,节奏舒缓,配一段轻柔的钢琴。
```

### 9.5 两个好用的东西

| 功能 | 说明 |
| --- | --- |
| **技能广场** | 现成的流程(电商主图、小红书封面),一键套用,非常适合新手 |
| **插件** | 可接外部工具,比如把 ComfyUI 工作流接进来,给会玩 Stable Diffusion 的人 |

### 9.6 费用:按积分算

| 会员 | 国内月费 | 每月积分 | 海外月费 |
| --- | --- | --- | --- |
| **Starter** | ¥65 | 10,000 | 约 $10.5 |
| **Plus** | ¥499 | 87,000 | 约 $76 |
| **Pro** | ¥1399 | 270,000 | 约 $215 |

**积分换算参考**:

```text
10,000 积分 ≈ 83 秒 2K 高清视频
            ≈ 143 秒 720p 视频

```

```text

```

### 9.7 坑

| 坑 | 怎么办 |
| --- | --- |
| 需求含糊,出来的东西不对味 | 把"用途/风格/尺寸/不能出现什么"都写上 |
| 反复重生成很费积分 | 选定一个方向再微调,别乱试 |

| 风格前后不统一 | 用素材库统一参考图,或把流程存成技能 |

| AI 给的答案能直接用吗? | 不能。具体数字、法律条款、医疗建议、引用出处,必须自己核实 |
| ChatGPT 突然要求验证? | 短时间访问太多。放慢、清 Cookie、换网络 |
| Claude 突然不能用了? | 大概率 5 小时窗口用满。等,或切到别的工具 |
| 公司不让用怎么办? | 听公司的。可以把 ChatGPT 换成国产模型、Google 换成国内搜索、YouTube 换成 B 站。方法论通用,工具可替换 |
| 数据安全吗? | 免费版对话可能用于改进模型。个人内容无所谓;公司机密、客户隐私、未公开计划,别贴进免费版 |
| 手机上怎么用? | 装 ChatGPT App、Claude App、海螺 AI、Google App、YouTube App,配合手机外网客户端基本覆盖日常 |

## 写在最后

工具会一直变,明年还会有新的。

但有两件事不会变:

1. **你能获取信息的能力**,决定你能看到多大的世界
2. **你把 AI 组织进工作流的能力**,决定你能交付多少东西

**建议的起步节奏**:

```text
今天    注册 Google 账号,把 YouTube 的字幕和倍速调好
本周    每天用 Google 搜 5 个以前靠猜的问题,用 AI 问 5 个以前不敢问的问题
本月    找一篇你方向的 SCI,用第四讲的模板做一份结构化笔记
下个月  确实需要了再订阅;需要做图做视频再开 MiniMax Design;
        想做自己的小工具再装 ZCode
```

**不要一开始就订阅一堆工具**——那会让你在"研究工具"上花掉比"用工具"更多的时间。
