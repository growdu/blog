# 博客到公众号与视频号

本目录存放**内容自动分发**相关的文档：怎么把仓库里的 Markdown 母稿转成公众号图文，以及怎么自动生成视频号成片。

## 文章

- [从 Hexo 博客到公众号与视频号：一次发布，自动分发两个平台](./index.html) —— **入口**：现状盘点（读源码）→ 平台硬约束对照 → Markdown→公众号 HTML 转换器 → 公众号发布接口链路与状态机 → 视频号的三条路线 → 复用 AIV 流水线出片 → 整体架构 → 分阶段落地 → 风险兜底

## 关键结论（先看这三条）

| 结论 | 影响 |
| --- | --- |
| 公众号**建草稿**（`draft/add`）可以全自动 | 90% 的手工工作量被自动化掉 |
| 公众号**发表**（`freepublish/submit`）**要看账号资质** | 2025-07 起部分账号类型返回 `48001`，必须自己实测 |
| 视频号**没有公开发布 API** | 默认路线：自动出片 + 人工点发布（方案 B） |
