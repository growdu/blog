## 二、沙盘对抗的四大评分维度 `[已证实]`

历届官方报道反复出现同一套四维框架，这是拿分的直接靶子：

1. **健康指数优化** — 居民健康指数（红/黄/绿灯）提升幅度
2. **医疗资源占比调控** — 预算、人力、转诊量的分配合理性
3. **操作流程准确度** — 服务流程执行是否规范、是否走完闭环
4. **专业知识考点应答** — 现场问答的专业准确度

四维不是独立的。多数队伍死在**四维之间的冲突**上——见第四节。

## 三、佘山社区案例的结构 `[已证实]`

- **场景**：佘山社区五位居民，典型问题为肥胖超重、高血压、高血脂、糖尿病、睡眠障碍
- **机构**：体检中心 / 医院 / 健康管理中心，三方联动
- **人数**：3 名队员，分别扮演三个机构角色
- **节奏**：多期递进（约五期），指数随干预动态变化
- **已知人物**：瞿先生（其案例暴露了一个重要机制，见 4.3）

### 三方机构的正确认知 `[已证实·选手复盘]`

> 医院不是坐等病人的终点站，而是主动出击、赋能前线的指挥枢纽；体检中心是洞察风险的侦察兵；健康管理中心是连接临床与生活的分析师。

**闭环链路**：体检筛查 → 发现异常 → 转诊医院 → 医院诊疗用药 → 回健管中心 → 个性化干预（饮食/运动/心理/戒烟限酒） → 随访复评

任何一环断了，流程分和指数都会掉。

## 四、核心战术

### 4.1 头号陷阱：药物—饮食—运动三角冲突 `[已证实·真实翻车案例]`

这是佘山社区案例里**大量队伍翻车的地方**，必须提前吃透。

典型剧本：
1. 前期按"固定公式"给高血压、高血糖患者优先用药 → 五名患者指数第一期飙到 75+ → 团队士气暴涨
2. 第三期以减重为核心，**未与医院端沟通**，给所有肥胖患者上激进减重食谱
3. 医院端仍按前期方案给糖尿病患者开**格列齐特、格列吡嗪**等强效促泌剂
4. 第四期体重如期大降，但**健康指数停滞不前**
5. 第五期系统警报拉响：五人中三人严重低血糖，最低 **3.4 mmol/L**，指数断崖式下跌

**根因**：减重导致摄入骤降，促泌剂仍在按原剂量继续释放胰岛素 → 严重低血糖。

**正确处理顺序**：
> 减重干预启动前，**必须先做降糖方案调整**（减药 / 换药 / 剂量下调），再上饮食运动干预。顺序反了就是医疗事故。

**通用原则**：安全 > 指标。任何时候"指数好看"和"临床上安全"冲突，选安全。系统会惩罚激进方案，而且惩罚是滞后到后期爆发性的。

### 4.2 分期推进节奏 `[推断，但经验一致]`

- **每期开赛前先定本期目标**，不要边做边想
- 指数是**多维度加权**，不是单一数值。猛压一个维度会让其他维度塌方——第四期"体重降了指数不涨"就是这个道理
- 留缓冲：宁可每期稳涨，不要前期暴涨后期还债

### 4.3 黄灯不一定是真的"数值不够" `[已证实·瞿先生案例]`

> 瞿先生的**基础病现病史已经消除，各方面数值也在逐渐恢复正常，但健康指数一直亮黄灯。**

参加主办方培训会后才搞明白：问题不在某个数值，而在**评估维度没覆盖到 / 三方机构没配合好**。

**推论**：遇到"该做的都做了但灯还黄"，不要继续加码干预，先回头查——是不是漏了某个评估维度？是不是健管和医院的口径没对齐？把团队的理解拉回同一层比继续猛干更重要。

### 4.4 医疗资源占比调控 `[推断]`

- 有限预算 / 人力 / 时间，不可能全给。核心是**排序逻辑**：
  **优先级 = 风险分层 × 干预性价比 × 时间窗紧迫度**
- 风险高、时间窗短（如急性风险、并发症前期）优先
- **过度医疗同样扣分**——资源不是越多越好，要跟风险匹配
- 记得留出随访/复评的预算，不要在初次干预上花光

### 4.5 操作流程准确度 `[推断]`

- 走完闭环，不跳步：筛查 → 转诊 → 干预 → 随访 → 复评
- 机构衔接要显式：体检发现异常后**明确转诊**，不要各干各的
- 流程规范性的分很"死板"，但很便宜——按 SOP 走就行

### 4.6 专业知识考点应答 `[推断]`

- 考的是**评估工具的选择与理由**，不是背结论
- 常见考点：老年综合评估维度选择、衰弱/失能/认知筛查工具、慢病共管要点、随访频率设定依据、适应证与禁忌
- 标准答法：**选什么 + 为什么选它 + 这个场景下为什么合适**。三段式答满
- 拿不准时，答"需要先做 X 评估再决定"，比硬答错更好

## 五、团队分工与协作 `[已证实 + 推断]`

**角色绑定（3 人）**：
| 角色 | 职责 | 天然优势 |
|---|---|---|
| 体检中心 | 筛查、指标采集、风险发现 | 细心、擅长数据 |
| 医院 | 诊断、用药、转诊决策 | 临床思维 |
| 健康管理中心 | 目标制定、饮食运动方案、随访闭环 | 沟通、协调 |

**协作要点** `[推断]`：
- **开场就定同步机制**：每期开始三人对齐一次目标，避免"各管各的"
- **跨机构动作必须口头确认**：4.1 的翻车本质是"未与医院部门沟通"就单方面变更方案。任何影响另一端的干预，先同步再执行
- 设一个**记录位**：把每期决策和依据记下来，复盘和答辩 PPT 都要用

## 六、答辩准备（30%）`[已证实·评分维度]`

评委从三个维度打分：**展示材料专业度、逻辑清晰度、团队配合度**。

- **专业度**：评估工具用对没有、方案有循证支撑、引用的指南/标准准确
- **逻辑清晰度**：问题 → 评估 → 决策 → 结果 → 反思，这条链要能一句话讲清
- **团队配合度**：三个人都要开口，分工要互补不能重叠

**内容素材来自沙盘本身**：把 4.1 那个"低血糖翻车→复盘→修正方案"的故事讲出来，比任何漂亮的成功案例都更有说服力。评委看得出这是真实复盘。

## 七、备赛时间表 `[推断·参考往届 3 个月节奏]`

| 阶段 | 时长 | 重点 |
|---|---|---|
| 规则与案例研读 | 第 1–3 周 | 吃透赛例、评估工具、机构职能；**参加主办方培训会** |
| 角色分工与 SOP | 第 3–5 周 | 定人定岗、把服务流程 SOP 写死 |
| 平台练习 | 第 4–8 周 | 在平台"佘山社区（2026练习）"反复跑，记录每期数据 |
| 复盘迭代 | 第 8–10 周 | 重点复盘指数不涨的期次，找根因 |
| 方案定稿 + 答辩准备 | 第 10–12 周 | 固化方案、准备 PPT、演练答辩 |

**平台练习的正确用法**：不是刷分，是**建立"决策 → 指数变化"的因果直觉**。每期结束后问三个问题：涨了是因为什么？没涨的卡在哪？下期改什么。
