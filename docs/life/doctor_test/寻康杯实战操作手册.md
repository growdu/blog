# 寻康杯 · 佘山社区 实战操作手册（详版）

> 三人三系统 / 限时 / 目标：把居民健康指数拉起来。
> 配合《寻康杯备战方案.md》使用。
>
> 标注说明：
> - `[实证]` = 来自官方通知、高校官宣报道或往届选手公开复盘中已实际发生的过程
> - `[临床]` = 通用临床医学常识，稳定可靠
> - `[推断]` = 经验性建议，**以赛前培训会与《赛事指南》为准**

---

## 零、全书一句话

**三个人一台戏，信息同步就是命。**

三人三系统 = 结构性地互相看不见对方在干什么。佘山社区案例里已经验证过：健管端单方面上激进减重，医院端照旧开促泌剂，五期后三人低血糖、指数断崖。

**本手册 90% 的内容都在解决"跨系统信息同步"这一个问题。**

## 一、临床数值速查表 `[临床]`

> ⚠️ 以下为通用参考值。**沙盘实际阈值以培训会和赛事指南为准**，本表用于建立量级直觉。

### 血糖
| 指标 | 正常 | 异常 | 备注 |
|---|---|---|---|
| 空腹血糖 | 3.9–6.1 mmol/L | ≥7.0 提示糖尿病 | IFG：6.1–7.0 |
| 餐后 2h 血糖 | <7.8 mmol/L | ≥11.1 提示糖尿病 | |
| **低血糖** | **<3.9 mmol/L** 即诊断 | <3.0 为严重 | **<2.8 需立即处理** `[实证]` 案例中最低到 3.4 |
| HbA1c | <7.0% 为一般目标 | 老年人可放宽 7.5–8.0 | 体现个体化 |

**⚠️ 老年糖尿病患者的低血糖风险显著高于高血糖风险。** 这是本案例的核心矛盾。

### 血压
| 人群 | 目标 | 注意 |
|---|---|---|
| 一般成人 | <140/90 mmHg | |
| 老年（≥65 岁） | **<150/90** | 不宜降得过低 |
| 糖尿病患者 | <130/80 | 有低血糖/跌倒权衡 |
| 体位性低血压 | 收缩压下降 ≥20 mmHg 或舒张压 ≥10 mmHg | **跌倒前兆** |

### 血脂与体重
| 指标 | 参考 | 注意 |
|---|---|---|
| BMI | 18.5–23.9 正常；24–27.9 超重；**≥28 肥胖** | 亚洲标准 |
| 腰围 | 男 <90 cm，女 <85 cm | 中心性肥胖风险更高 |
| LDL-C | <2.6 mmol/L；极高危 <1.8 | |
| **安全减重速率** | **每周 0.5–1.0 kg**（或每月 5–10%） | 超过部分多为肌肉流失 |

### 常用评估工具（答题要能说清"为什么选它"）`[临床]`
| 领域 | 工具 | 选择逻辑 |
|---|---|---|
| 认知 | MMSE / MoCA | 受教育程度影响大时 MoCA 更敏感 |
| 营养 | MNA-SF | 老年营养筛查首选 |
| 衰弱 | Fried 表型 / Clinical Frailty Scale | Fried 适合人群研究，CFS 适合快速分层 |
| 跌倒 | Morse 量表 | 按住院/社区场景调整 |
| 压疮 | Braden 量表 | 关注营养、移动能力、感知 |
| 抑郁 | GDS | 老年抑郁筛查 |
| 睡眠 | 必要时筛查睡眠呼吸暂停 | 打鼾+白天嗜睡是信号 |

## 二、三岗位逐期动作细则

### 2.1 体检中心（风险雷达）

**你的定位：发现问题和排序，不做治疗决策。**

每期动作清单：
1. **采集/更新指标** — 血压、空腹血糖、血脂、BMI/腰围、睡眠、活动量、用药依从性
2. **风险分层并公开点名** — "本期风险最高的是 ___"
3. **发起转诊** — 转诊单必须包含四项：**异常指标 + 既往史 + 当前用药 + 初步风险判断**
4. **安排复检时点** — 什么时候再看这个指标

⚠️ **常见失分**
- 只测不判：测完不给出风险判断，等于没测
- 发现异常不转诊：体检端的天职就是发现和转出
- 转诊单信息不全：医院端拿到不完整信息 → 判断错 → 治疗方案错 → 指数掉
- 漏评维度：凭印象只查血糖血压，漏掉睡眠/认知/营养/跌倒/压疮

### 2.2 医院（治疗决策）

**你的定位：唯一有权动药的人，并且必须把用药信息同步出去。**

每期动作清单：
1. **接收转诊 → 出诊断**
2. **开药 / 调药** — 尤其是降糖药、胰岛素、降压药
3. **向健管端同步"饮食与运动禁忌"** ← 这一步最容易被跳过，也最致命
4. **处理急性事件**
5. **随访医嘱落地**

⚠️ **常见失分**
- 换药/停药不通知健管端 → 健管端按旧方案继续执行
- 随访方案不落地 → 流程闭环断裂
- 为了冲指标叠加多药 → 埋下低血压/低血糖/跌倒的雷

### 2.3 健康管理中心（方案落地）

**你的定位：把医嘱变成能执行的生活方式，并闭环随访复评。**

每期动作清单：
1. **制定个体化目标** — 可测量、有时限、有负责人
2. **饮食方案** — 低盐低脂、少量多餐；按代谢状态调整
3. **运动方案** — 低冲击、循序渐进
4. **心理干预、戒烟限酒**
5. **随访与复评** ← 考核"操作流程准确度"主要看这里

⚠️ **常见失分**
- **在没确认医院端用药的情况下上强化干预** ← 全赛最大的坑
- 方案太激进：禁食、高强度运动一步到位
- 只开方案不复评：无法验证效果，也拿不到流程分

## 三、跨系统沟通协议

### 3.1 开期广播（每期开始，各 1 句，≤20 秒）

三个人都说完再动手。**这是全场最便宜的 30 秒。**

| 岗位 | 固定句式 |
|---|---|
| 体检 | "本期我重点筛查 ___，风险最高的是 **___**。" |
| 医院 | "___ 的用药我打算 ___，需要健管同步 ___。" |
| 健管 | "本期目标：把 ___ 的 ___ 指标拉起来。" |

### 3.2 变更预警（动别人系统之前必喊）

固定句式：
> **"我要动 ___ 的 ___ 了，你那边要不要跟着改？"**

**四种必喊情况：**
1. 健管要上**强化饮食/运动干预**（减重、限食、增加运动量）
2. 医院要**加药、减药、换药、停药**
3. 体检发现**新发急性风险**
4. 任何**跨期影响大**的调整

### 3.3 期末报数（每期结束，各 1 句）

> "我这 ___ 涨/跌 ___，卡在 ___。"

**三句报完再进下一期。** 不报数就会重演"第三期埋雷、第五期爆炸"。

## 四、核心安全铁律

### 铁律 1：先调药，再干预
任何强化减重 / 限制饮食 / 增加运动量的干预，启动前**必须**先向医院端确认：
> "这位当前在用什么降糖/降压药？上强化干预需要先调药吗？"
**顺序不能反。**

### 铁律 2：先想最坏情况
上任何干预前问："如果这位是老年糖尿病患者，最坏会发生什么？"答不上来 → 不能上。

### 铁律 3：指数不是唯一目标
系统**滞后**惩罚激进方案。短期暴涨后期塌方，整体是亏的。宁可每期稳涨。

### 铁律 4：闭环优先于新增
未闭合的动作（转诊没接、随访没做、方案没落地）优先级**永远高于**新开一个动作。

## 五、经典案例库 ★ 重点

### 5.1 用药与代谢类

---

#### 案例 1 ★★★：促泌剂遇上激进减重（头号陷阱） `[实证]`

**场景**
佘山社区五位居民中有多位 2 型糖尿病，正在服用格列齐特、格列吡嗪等磺脲类促泌剂；同时肥胖超重，需要减重。

**❌ 易错做法**
健管端第三期以减重为核心，**未与医院端沟通**就上激进"减重食谱"（低热量/限制性）；医院端仍按前期方案继续开具促泌剂。

**🔍 机制**
磺脲类促泌剂刺激胰岛 β 细胞释放胰岛素。当碳水摄入因限食骤减，机体对胰岛素的基础需求下降，但外源药物刺激仍在按原剂量释放 → **胰岛素相对过量** → 低血糖。

**💥 后果**（已实际发生）
第四期体重如期大幅下降，但健康指数**停滞不前**；第五期系统警报拉响，五人中**三人出现严重低血糖，最低 3.4 mmol/L**，指数断崖式下跌，前期积累全部归零。

**✅ 正确做法**
1. 健管端提出减重计划 → **先广播**
2. 医院端确认当前用药，**先下调/暂停促泌剂**，或改用低 hypoglycemia 风险方案
3. 确认后再启动饮食干预
4. 减重速率控制在每周 0.5–1.0 kg
5. 上强化干预后加密血糖监测

**📣 场上要喊的一句**
> "健管要动 ___ 的饮食做减重，他/她现在吃的是 ___，需要先调药吗？"

---

#### 案例 2：多药叠加 → 体位性低血压 → 跌倒 `[临床]`

**场景**
老年居民合并高血压、糖尿病、冠心病，长期多药。

**❌ 易错做法**
为了"指标好看"同时叠加多种降压药，血压降得过快过低。

**🔍 机制**
多药叠加 → 血压骤降 → 体位性低血压（收缩压降 ≥20 或舒张压 ≥10 mmHg）→ 老年平衡能力差 → 跌倒 → 卧床 → 压疮/肺炎/失能 → 多维度扣分并占用后续资源。

**💥 后果**
跌倒事件同时拉低健康指数和满意度，且会挤占后续轮次的人力与预算。

**✅ 正确做法**
- 单一目标优先，逐次调整，每次调整留观察期
- 老年高血压目标放宽至 <150/90
- 每次调整后测**卧位/立位血压**
- 健管端同步加防跌措施（环境评估、辅具、陪同）

**📣 要喊**
> "血压已经到 ___ 了，再加药有跌倒风险，健管那边要不要先加防跌？"

---

#### 案例 3：利尿剂相关电解质与夜尿问题 `[临床]`

**❌** 为降压加利尿剂，不监测电解质；忽略夜尿增多。
**🔍** 低钾 → 乏力、心律失常；夜尿增多 → 起夜跌倒风险显著上升。
**✅** 加利尿剂同时查电解质，必要时补钾；老年患者评估夜尿与起夜跌倒，健管端排对应干预（睡前限水、夜间通道照明、陪护）。

---

#### 案例 4：换药不同步，健管端照旧执行

**场景** 医院端把二甲双胍换成其他有低血糖风险的药物。

**❌** 医院端换药后不广播；健管端仍按"空腹血糖偏高"的方案执行限食。
**✅** **换药 = 跨系统变更，必须广播**。健管端收到后复查目标是否需要调整（尤其是否在限食）。

---

#### 案例 5：多重用药未梳理（polypharmacy） `[临床]`

**❌** 只看本机构开的药，不问患者在别处（社区卫生中心、药店、中医、保健品）服用的药。
**🔍** 老年多重用药是低血糖和药物相互作用的首要来源。
**✅** 建药单时问全："目前所有口服的东西，包括中药和保健品"。体检端采集时就要问全。

### 5.2 饮食与运动类

---

#### 案例 6：禁食 + 高强度运动 `[实证/临床]`

**❌** 为追求快速掉秤，给超重者禁食 + 每天高强度运动。
**🔍** 糖尿病患者 → 低血糖；老年 → 肌肉流失、基础代谢下降；运动性低血压 → 跌倒。
**✅** 温和方案：低盐低脂、少量多餐；低冲击运动（快走、太极、操），循序渐进，从 10 分钟起每周递增。

---

#### 案例 7：快速减重的反弹陷阱 `[临床]`

**❌** 短期激进冲秤重。
**🔍** 每周减超过 1kg 或超过体重 1% 的部分**多为肌肉**。肌肉流失 → 基础代谢下降 → 后期反弹，指数停滞甚至恶化，前期优势蒸发。
**✅** 每周 0.5–1.0 kg / 每月 5–10%，配合抗阻训练保肌，必要时转临床营养科。

---

#### 案例 8：无差别高蛋白 `[临床]`

**❌** 对所有肥胖者一律高蛋白饮食。
**🔍** 肾功能异常者高蛋白会加重肾脏负担。
**✅** 肾功能指标异常时限蛋白，并转诊肾内科/临床营养做个体化方案。

---

#### 案例 9：睡眠障碍的错误处理 `[临床]`

**❌** 白天补觉；直接开镇静药。
**🔍** 白天补觉打乱昼夜节律；镇静药增加跌倒、依赖、影响认知。
**✅**
- 先查**可逆原因**：打鼾 + 白天嗜睡 → 筛查睡眠呼吸暂停；情绪问题；咖啡因/酒精；药物影响
- 非药物优先：规律作息、睡前卫生、限制睡前大量饮水和咖啡因、白天适度活动、日间光照
- 排查后再决定是否转诊睡眠门诊

---

#### 案例 10：降脂药与饮食/运动的冲突 `[临床]`

**❌** 开了降脂药，健管端没同步改饮食；或患者在做剧烈运动。
**🔍** 他汀类与他汀相关肌痛；剧烈运动 + 高强度他汀使用时需警惕横纹肌溶解。
**✅** 用药与饮食干预同步；运动强度循序渐进；出现不明原因肌痛要上报并复查。

### 5.3 评估与认知类

---

#### 案例 11 ★★★：黄灯不涨 ≠ 干预不够（瞿先生）`[实证]`

**场景**
瞿先生的**基础病现病史已经消除，各方面数值也在逐渐恢复正常，但健康指数一直亮黄灯。**

**❌ 易错做法**
看到黄灯 → 继续加码干预：加药、加频次、加强度。

**🔍 机制**
问题**不在数值**，在于评估维度没覆盖到、或三方机构口径没对齐。主办方培训会上才点破。

**✅ 正确做法**
停下来做三件事：
1. 重新过一遍**完整的评估维度清单**（血糖、血压、血脂、体重、睡眠、认知、营养、跌倒、压疮、用药、依从性）
2. 三方对齐"这个人还差什么"——把三边看到的拼在一起
3. 复评时确认**是否用对评估工具**

**📣 要喊**
> "___ 数值都正常了还黄灯——体检这边还差什么没查？医院那边呢？"

---

#### 案例 12：漏评维度 `[临床]`

**❌** 只盯血糖血压，漏掉睡眠、认知、营养、跌倒、压疮。
**🔍** 老年健康管理是**清单式**的，漏一个维度就会在该维度持续扣分。
**✅** 每期对照完整维度清单逐项过，不要凭印象。老年综合评估（CGA）本身就是清单工具。

---

#### 案例 13：评估工具选错 `[临床]`

**❌** 用错工具 → 分层错误 → 干预不匹配 → 指数不涨还可能过度干预。
**✅** 三段式答题（见下），同时在复评时确认工具适用性。

**答题三段式**：
1. **选什么** — "用 MNA-SF 评估营养状态"
2. **为什么选它** — "它对早期营养风险敏感，且适用于社区老年人"
3. **为什么适合这个人** — "他 BMI 偏低且近期食欲下降，MNA-SF 能捕捉到 BMI 掩盖的早期风险"

---

#### 案例 14：不做复评 `[临床]`

**❌** 给了干预就结束，不管效果。
**🔍** 无法验证效果，无法调整方向；"操作流程准确度"这一维度主要扣在这里。
**✅** **干预 → 复评** 是闭环核心。每期留出固定的复评时间点，结果直接决定下期方案。

---

#### 案例 15：转诊单信息不全 `[推断·高发]`

**❌** 体检转诊只写"血糖高"，不带既往史和当前用药。
**🔍** 医院端拿到不完整信息 → 判断错 → 治疗方案错 → 指数掉，且责任不清。
**✅** 转诊单四项齐全：**异常指标 + 既往史 + 当前用药 + 初步风险判断**。

### 5.4 流程与协作类

---

#### 案例 16：转诊未闭环 `[推断]`

**❌** 体检转了没人接；或医院接了没反馈给健管。
**🔍** 转出后失联，患者状态恶化无人知晓。
**✅** 每期末三人必核对一句：**"本期的转诊都接完了吗？结果反馈回来了吗？"**

---

#### 案例 17：三方重复劳动 `[实证]`

**❌** 体检端和健管端都在做生活方式干预，内容重复且口径不一致。
**✅** 边界清晰：
- 体检 → 发现与筛查
- 医院 → 治疗与用药
- 健管 → 生活方式与随访

---

#### 案例 18：中途换位/状态交接 `[推断]`

**❌** 队友状态不好临时换位，交接含糊。
**✅** 换位前必须口头完整交接：**当前在管的患者、当前用药、当前目标、本期已做未做**。

### 5.5 资源与节奏类

---

#### 案例 19：预算前期烧光 `[推断]`

**❌** 前两期把预算全投在初次干预上，后续没钱做随访和应急。
**✅** 预留 30%–40% 给**随访 / 复评 / 应急**。前期投得猛但没闭环，等于白花。

---

#### 案例 20：过度转诊 `[推断]`

**❌** 什么都要往医院转 → 医疗资源占比失衡。
**✅** 转诊分层：
- 急危重 → 必转
- 明确需专科处理 → 转
- 可控、稳定 → 留在社区管理

---

#### 案例 21：风险排序错 `[推断]`

**❌** 资源平均分给所有居民。
**✅** 排序公式：**优先级 = 风险严重度 × 可干预性 × 时间窗紧迫度**
高风险且高可干预的优先；高风险但不可干预的（不可逆损害）重点在维持和舒缓。

---

#### 案例 22：追求全指标完美 `[推断]`

**❌** 平均用力，每项都推一点。
**✅** **先抓最短板**——把居民拖后腿的那一项拉上来，而不是去抓最容易涨的那一项。

## 七、时间不够时的砍单顺序 `[推断]`

赛前演练过很多遍、赛场上时间突然不够用时，按这个顺序砍：

| 优先级 | 做什么 | 理由 |
|---|---|---|
| **P0** | 排查安全风险（低血糖、低血压、跌倒、急性事件） | 一次失误可能拖垮全局 |
| **P1** | 补齐未闭合动作（转诊、随访、复评） | 不补会在后续轮次放大 |
| **P2** | 执行本期计划内干预 | 正常得分项 |
| **P3** | 优化既有方案 | 有收益但可延后 |
| **P4** | 额外宣教、额外筛查、锦上添花 | 先砍这个 |

**永远不要为了 P3/P4 去做有安全风险的动作。**
