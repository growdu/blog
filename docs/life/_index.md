## 核心约束（跨文档共通）

- **年龄线**：本科 35 / 硕士 40 / 博士 45（公务员考试通用，部分省份已松动）
- **专业代码**：云南省考/事业单位计算机岗多用 **B0809 计算机类**
- **PG 内核学习**：从「记录者」到「架构师」4 个能力层级，**12 个月 5~10 个 patch + 1 个扩展**
- **时间预算**：每天 4~5 小时双线推进（考公 / 自考 / PG 内核 视阶段侧重）

## 决策矩阵速览

### A. 体制内路径（35 岁前关键）

| 当前年龄 | 推荐路径 | 理由 |
| --- | --- | --- |
| < 35 岁 | **自考本科 + 全力考公** | 本科 35 岁线够用，最省钱 |
| 35~36 岁 | **自考本科（兜底） + 在职硕士（主推）** | 双线并行，硕士给 5 年缓冲 |
| 37~38 岁 | **非全日制硕士 + 自考本科并行** | 必须 40 岁前拿学位，硕士是救命药 |
| ≥ 39 岁 | **同等学力申硕 + 选岗避开 B0809** | 35 岁线已死，硕士也来不及 |

### B. 技术深度路径（PG 内核开发）

| 当前层级 | 12 个月目标 | 24 个月目标 |
| --- | --- | --- |
| **L1: Reader（当前）** | 5~10 个 patch + 1 个扩展 + 1 次 talk | 1 个 feature + PG contributor |
| **L2: Modifier** | 3 个 feature patch + 主导 1 个 commitfest | PostgreSQL committer 候选 |
| **L3: Designer** | 1 个完整子系统设计 + 1 次主旨 talk | 业界公认的 PG 专家 |
