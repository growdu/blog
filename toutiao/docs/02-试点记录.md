## 实测记录

### R1 · 2026-11-12 · 头条号后台找不到「开放平台」入口

**现象**：登录头条号后台（`mp.toutiao.com`）→ 设置，**找不到「开放平台」入口**。
（用户找的是「开发平台」——**不是**同一个名字，别再按错名字找了。）

**判定**：**不是路径走错，是账号条件没到。** 三条依据：

1. **入口的正式名字是「开放平台」，不是「开发平台」。**
   第三方对接文档（php 中文网《讯飞绘文怎么发布到头条号》）写的路径是
   「头条号创作者中心 → 设置 → 开放平台 → **API 权限管理**」。
2. **开通条件写明**：同源文档写「仅企业认证号、媒体认证号、个人认证号（**粉丝 ≥ 1000**）
   可开通此权限；普通未认证账号即使完成 OAuth2 登录，也会在发布时返回『权限不足』」。
3. **头条号后台的权益入口遵循同一套「达标才渲染」规则**：
   第三方攻略对「图文赞赏」的描述是「系统仅在满足条件后自动释放该权益入口，
   未达标账号不会显示该开通入口」。「开放平台」入口属于同一类。

> **处置**：这一项**从阶段一移到阶段二**（它依赖认证，本就不该在阶段一）。
> `publish/capabilities/toutiao.toml` 的 `automation` 维持 `manual`——
> 本来就是现在的取值，**轨道 A 不受任何影响**。
>
> 阶段一剩下要做的是**账号状态自查**与**手工发一篇测试文章**，
> 后者完全不依赖 API 权限，今天就能做。

#### 排查顺序（按这个顺序查，不要跳着试）

| # | 检查项 | 怎么查 | 不达标的后果 |
| --- | --- | --- | --- |
| 1 | 名字对不对 | 找「**开放平台**」，不是「开发平台」 | — |
| 2 | 账号认证状态 | App「我的」头像旁的认证标识；或后台「设置 → 账号详情 → 帐号自证」 | 未认证 → **入口不渲染** |
| 3 | 账号主体类型 | 必须是个人 / 企业 / 媒体；**不能是国家机构 / 新闻媒体 / 其他组织** | 类型受限 → 职业认证也申请不了 |
| 4 | 粉丝数 | 今日头条 + 西瓜视频合计；个人认证号需 ≥ 1000 | 不足 → **入口不渲染** |
| 5 | 入口不在「设置」顶层 | 逐个点「设置 → 账号详情」「设置 → 功能设置」「左侧 → 工具」 | 路径在二级菜单里 |
| 6 | 登录的是不是同一个号 | 后台登录手机号 vs App 登录账号 | 账号不对 → 什么都看不到 |

> **第 2、4 项是主嫌。** 头条号后台 2022 年改版公告里，「设置」页的功能位置调整只列了三处
> （安全中心 → 帐号详情、帐号自证 → 帐号详情、自定义菜单 → 功能设置），**没有提「开放平台」**——
> 因为它是条件渲染的，未达标账号连菜单项都没有。

### 2. 手工发一篇测试文章（**最值钱的一步**）

**怎么做**：后台「创作」→「文章」，走完「上传图片 → 排版 → 发表」全流程。
内容用 growdu.cn 上任意一篇的精简版即可（无害、可编辑），**不要用正式要发的稿子**。

**放进去的探针**（每放一个，就能在结果页读出一个答案）：

| 探针 | 放什么 | 读出什么 |
| --- | --- | --- |
| 外链图 | 一张 growdu.cn 正文图的完整 URL | 外链图能不能显示 / 要不要重传 |
| 裸 URL | 正文里直接写 `https://growdu.cn/xxx` | URL 会不会被系统改写或拦下 |
| 长标题 | 一个 > 30 字的标题 | 标题**实际**能填多少字 |
| 首段 | 正文第一段写成一句话 | 摘要是不是自动取首段、取多少字 |
| 封面 | 从正文图里选一张当封面 | 封面的**实际**比例与最小尺寸 |
