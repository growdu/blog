# 头条号 adapter 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 `toutiao/` 这个独立 adapter——把博客母稿裁成头条版（3K 精简稿 + 最多 3 张图，0 张也行），产出可人工上传的发布包，并把「出包 / 待发表 / 已发布」三种状态如实记下来。

**Architecture:** 契约层（`publish/`）不动。本计划只写 `toutiao/` 这个顶层目录里的包，以及它自己的一份能力模型 TOML。adapter 与契约层之间只有两处接缝：`publish/capabilities/toutiao.toml`（限额与自动化档位）和一份发布清单 JSON 格式。adapter **不 import `weixin/`，也不 import `publish/` 的包**。

**Tech Stack:** Python 3.11（`tomllib` 读 TOML、零依赖）、Pillow（webp 转换与封面裁切）、pytest（测试）。HTTP 用标准库 `urllib`，只用到 `notify.py`。

**上游规格：** [00-设计.md](00-设计.md)（实现规格）、[../../publish/spec/06-发布计划与调度.md](../../publish/spec/06-发布计划与调度.md) §6（头条号一节）。

## Global Constraints

以下每一条都来自上游规格，**每个任务都隐含包含它们**：

1. **头条与微信不共用一份代码。** `toutiao/` 是从 `weixin/` 派生的**独立副本**：
   两边各改各的——不抽公共模块、不做同步修复、不互相 import。
   也不 import `publish/` 的任何包（`publish/spec/00-架构设计.md` §11.1）。
   需要什么就自己写一份；可以**复制** `weixin/` 的代码作为起点，
   但复制过来之后就是两份各自演化的代码，一边的修改**不回流**到另一边。
2. **测试不依赖 `source/_posts`。** `source/` 在 `.gitignore` 里（`.gitignore:3`），干净检出里没有语料。所有测试必须用 `tmp_path` 造的夹具。需要真实语料的测试用 `@pytest.mark.skipif` 跳过。
3. **测试不依赖网络。** 平台接口用本地假 HTTP server 模拟（绑定 `127.0.0.1`），手法照抄 `weixin/tests/test_publish.py`。
4. **限额从 TOML 读，不写死在代码里。** `publish/capabilities/toutiao.toml` 是唯一真相。改平台规则 = 改 TOML。
5. **不做静默成功。** 每个「成功」都必须是显式确认过的成功。错误不吞，退出码不为 0。
6. **超限跳过并记录原因，不做静默截断。** 唯一例外是标题裁剪，且必须标记 `title_truncated` 并写进 `notes`。
7. **凭据永不入库。** `toutiao/.gitignore` 已挡 `secrets.json` 与 `out/`。
8. **通知措辞必须区分三种状态**：`packaged`（待上传）/ `drafted`（待你点发表）/ `published`（已发布）。含糊说「已发布」是发布场景里最贵的 bug。
9. **每个 commit 必须在只含该 commit 内容的干净检出上独立跑通全部测试**，不得引用后续 commit 才引入的文件。
10. **只 `git add` 自己任务里的文件。** 仓库有并行会话在改 `weixin/`、`aiv/`、`tools/`。

创建 `toutiao/toutiao/capability.py`：

```python
"""Read the Toutiao capability declaration.

The platform limits live in ``publish/capabilities/toutiao.toml`` -- data,
not code.  The adapter reads them at runtime so that a platform rule change
is a TOML edit and never a code change.
"""

from __future__ import annotations

import tomllib
from dataclasses import dataclass
from pathlib import Path

__all__ = [
    "AUTOMATIONS", "Capability", "Limits", "default_capability_path",
    "load_capability",
]

AUTOMATIONS = ("manual", "api_draft", "api_publish")

_REPO_ROOT = Path(__file__).resolve().parents[2]


@dataclass(frozen=True)
class Limits:
    """What the platform accepts."""

    title_chars: int
    body_chars: int
    digest_chars: int
    image_bytes: int
    image_formats: tuple[str, ...]
    cover_ratio: str
    cover_min_pixels: tuple[int, int]
    max_body_images: int


@dataclass(frozen=True)
class Capability:
    """The whole declaration for one platform."""

    id: str
    name: str
    kind: str
    automation: str
    review: str
    requires_certification: bool
    requires_min_followers: int
    verified: str | None
    limits: Limits
    adapter_package: str
    adapter_command: tuple[str, ...]


def default_capability_path() -> Path:
    """The declaration shipped with the repository."""
    return _REPO_ROOT / "publish" / "capabilities" / "toutiao.toml"


def _require(data: dict, key: str, where: str):
    if key not in data:
        raise ValueError("能力模型缺少字段 {}.{}".format(where, key))
    return data[key]


def load_capability(path: Path) -> Capability:
    """Load and validate one capability declaration."""
    path = Path(path)
    with path.open("rb") as handle:
        data = tomllib.load(handle)

    automation = data.get("automation", "")
    if automation not in AUTOMATIONS:
        raise ValueError(
            "automation 必须是 {} 之一，实际是 {!r}".format(
                " / ".join(AUTOMATIONS), automation
            )
        )

    limits_raw = _require(data, "limits", "根")
    adapter_raw = _require(data, "adapter", "根")

    limits = Limits(
        title_chars=int(_require(limits_raw, "title_chars", "limits")),
        body_chars=int(_require(limits_raw, "body_chars", "limits")),
        digest_chars=int(_require(limits_raw, "digest_chars", "limits")),
        image_bytes=int(_require(limits_raw, "image_bytes", "limits")),
        image_formats=tuple(_require(limits_raw, "image_formats", "limits")),
        cover_ratio=str(_require(limits_raw, "cover_ratio", "limits")),
        cover_min_pixels=tuple(_require(limits_raw, "cover_min_pixels", "limits")),
        max_body_images=int(_require(limits_raw, "max_body_images", "limits")),
    )

    return Capability(
        id=str(_require(data, "id", "根")),
        name=str(data.get("name", "")),
        kind=str(data.get("kind", "document")),
        automation=automation,
        review=str(data.get("review", "platform")),
        requires_certification=bool(data.get("requires_certification", False)),
        requires_min_followers=int(data.get("requires_min_followers", 0)),
        verified=data.get("verified"),
        limits=limits,
        adapter_package=str(_require(adapter_raw, "package", "adapter")),
        adapter_command=tuple(_require(adapter_raw, "command", "adapter")),
    )
```

### Task 2: 母稿解析与正文扫描

创建 `toutiao/tests/test_mdparse.py`：

```python
import typing
from pathlib import Path

import pytest

from toutiao.mdparse import (
    SourcePost,
    discover,
    discover_unsupported,
    load_post,
    parse_front_matter,
)


def test_front_matter_scalars_and_lists():
    text = (
        "---\n"
        'title: "标题"\n'
        "date: 2026-09-04 11:39:04\n"
        "categories:\n"
        "  - 数据库\n"
        "  - 源码\n"
        "---\n"
        "\n正文第一段。\n"
    )
    fields, body = parse_front_matter(text)
    assert fields["title"] == "标题"
    assert fields["date"] == "2026-09-04 11:39:04"
    assert fields["categories"] == ["数据库", "源码"]
    assert body.strip() == "正文第一段。"


def test_escaped_quotes_are_unescaped():
    """``tools/sync-hexo.py`` escapes quotes inside a title; we must undo it.

    ``yaml_escape`` writes ``\\"`` for a quote inside a double-quoted title,
    so a post whose title contains ``"`` reaches us as ``\\"``.  Hexo reads
    that back with a real YAML parser, which turns ``\\"`` into ``"``; if we
    keep the backslash the published title shows ``\\"`` to the reader.
    """
    fields, _ = parse_front_matter(
        '---\ntitle: "为什么\\"获得就释放\\"的机制"\n---\n\nx\n'
    )
    assert fields["title"] == '为什么"获得就释放"的机制'


def test_escaped_backslash_is_unescaped():
    """``yaml_escape`` doubles a backslash, so ``\\`` must become ``\\``."""
    fields, _ = parse_front_matter('---\ntitle: "C:\\\\路径"\n---\n\nx\n')
    assert fields["title"] == "C:\\路径"


def test_unknown_keys_are_kept():
    fields, _ = parse_front_matter(
        "---\nfoo: bar\nplatforms:\n  - wechat\n---\n\nx\n"
    )
    assert fields["foo"] == "bar"
    assert fields["platforms"] == ["wechat"]


def test_text_without_front_matter_is_all_body():
    fields, body = parse_front_matter("正文\n")
    assert fields == {}
    assert body == "正文\n"


def test_front_matter_closing_without_trailing_newline():
    """文件以结束 ``---`` 收尾（末尾没有换行）也是闭合的。

    ``---`` 独占一行就够了，文件可以在此结束。之前用正则匹配
    ``\\n---\\n``，末尾没换行的文件会被当成「未闭合」而误报。
    """
    fields, body = parse_front_matter("---\ntitle: x\n---")
    assert fields["title"] == "x"
    assert body == ""


def test_front_matter_closing_may_carry_trailing_whitespace():
    """结束 ``---`` 行尾可以有空白（YAML 允许），这也还是闭合的。"""
    fields, body = parse_front_matter("---\ntitle: x\n--- \n")
    assert fields["title"] == "x"
    assert body == ""


def test_unterminated_front_matter_raises():
    """A file that starts with ``---`` but never closes it is broken.

    Silently treating it as "no front matter" would publish the raw
    ``---`` and ``title:`` lines as body text and fall back to the file
    name for the title -- a broken file would go out as a good one.
    """
    with pytest.raises(ValueError) as excinfo:
        parse_front_matter("---\ntitle: 坏文件\n\n正文还在\n")
    message = str(excinfo.value)
    assert "闭合" in message
    # 消息说的是「找不到配对的结束 '---'」，只有真的没找到时才成立。
    assert "没有找到配对的结束" in message


def test_document_without_leading_dashes_is_not_an_error():
    """A normal document that merely contains ``---`` in its body is fine."""
    fields, body = parse_front_matter("正文\n\n---\n\n更多正文\n")
    assert fields == {}
    assert body == "正文\n\n---\n\n更多正文\n"


def test_empty_front_matter_raises():
    """``---\\n---\\n`` has no content for the field parser to read."""
    with pytest.raises(ValueError) as excinfo:
        parse_front_matter("---\n---\n\n正文\n")
    # 与「未闭合」是两种坏法，消息要能分开。
    assert "为空" in str(excinfo.value)


def test_load_post_derives_slug_and_title(tmp_path):
    posts = tmp_path / "source" / "_posts"
    (posts / "db").mkdir(parents=True)
    path = posts / "db" / "demo.md"
    path.write_text(
        "---\ntitle: 演示\ndate: 2026-01-01\n---\n\n内容\n", encoding="utf-8"
    )
    post = load_post(path, posts)
    assert post.slug == "db/demo"
    assert post.title == "演示"
    assert post.date == "2026-01-01"
    assert post.body.strip() == "内容"


def test_load_post_falls_back_to_filename_when_title_is_missing(tmp_path):
    """No ``title`` field means the file name stands in for it."""
    posts = tmp_path / "posts"
    posts.mkdir()
    path = posts / "no-title.md"
    path.write_text("---\ndate: 2026-01-01\n---\n\n内容\n", encoding="utf-8")

    post = load_post(path, posts)
    assert post.title == "no-title"


def test_load_post_date_is_empty_when_date_is_missing(tmp_path):
    """No ``date`` field means an empty date, not a guessed one."""
    posts = tmp_path / "posts"
    posts.mkdir()
    path = posts / "no-date.md"
    path.write_text("---\ntitle: 有标题\n---\n\n内容\n", encoding="utf-8")

    post = load_post(path, posts)
    assert post.date == ""


def test_load_post_error_mentions_the_file_path(tmp_path):
    """坏文件报错要带上路径，否则调用方不知道该去修哪一个。"""
    posts = tmp_path / "posts"
    posts.mkdir()
    path = posts / "broken.md"
    path.write_text("---\ntitle: 坏文件\n\n正文还在\n", encoding="utf-8")

```python
"""Read a source post: front matter plus body.

Deliberately line-based.  The WeChat adapter needs a full block AST because
it keeps code blocks and tables; the Toutiao version drops both, so a line
scanner is enough -- and much smaller.
"""

from __future__ import annotations

import re
from dataclasses import dataclass, field
from pathlib import Path

__all__ = [
    "SourcePost", "parse_front_matter", "load_post", "discover",
    "discover_unsupported",
]

# The front matter block is opened and closed by a line holding ``---``.
_DELIMITER = "---"

# The escapes ``tools/sync-hexo.py`` writes into a double-quoted value.
# ``yaml_escape`` doubles a backslash and escapes a double quote, so these
# two are exactly what can come back out of a quoted title.
_ESCAPES = {"\\": "\\", '"': '"'}
_ESCAPE_RE = re.compile(r"\\(.)")


@dataclass(frozen=True)
class SourcePost:
    """One blog post as it exists in ``source/_posts``."""

    slug: str
    title: str
    date: str
    body: str
    fields: dict[str, object] = field(default_factory=dict)


def _unquote(value: str) -> str:
    """Strip the surrounding quotes and undo the escapes inside them.

    ``tools/sync-hexo.py`` writes the title as a double-quoted YAML scalar
    and escapes what it has to (``yaml_escape``).  Hexo reads that back
    with a real YAML parser, which turns ``\\"`` into ``"`` again -- so we
    must undo the same escapes, otherwise the published title carries
    stray backslashes.  Single-quoted scalars keep their content verbatim,
    which is what YAML says.
    """
    value = value.strip()
    if len(value) >= 2 and value[0] == value[-1] and value[0] in "\"'":
        inner = value[1:-1]
        if value[0] == '"':
            inner = _ESCAPE_RE.sub(lambda m: _ESCAPES.get(m.group(1), m.group(0)), inner)
        return inner
    return value


def _is_delimiter(line: str) -> bool:
    """Is ``line`` a front matter delimiter?

    The delimiter owns its line: nothing but whitespace may follow it.
    Trailing whitespace is allowed (YAML allows it too), which is why this
    is not a plain ``==`` against ``"---"``.
    """
    return line.rstrip() == _DELIMITER


def _split_front_matter(text: str) -> tuple[list[str], str] | None:
    """Split ``text`` into its front matter lines and its body.

    Returns ``None`` when the document does not open a front matter block
    at all.  A document that opens one and never closes it is broken, and
    this raises ``ValueError`` rather than passing it off as a document
    without front matter: that would publish the raw ``---`` and
    ``title:`` lines as body text and fall back to the file name for the
    title -- a broken file going out as a good one.

    The closing ``---`` owns its line and may carry trailing whitespace;
    the file may also end right there, with no trailing newline.  Both are
    legal YAML, and a generator that writes the last byte without a
    newline still produced a closed front matter block.
    """
    lines = text.split("\n")
    if not lines or not _is_delimiter(lines[0]):
        return None

    for index in range(1, len(lines)):
        if not _is_delimiter(lines[index]):
            continue
        front_matter_lines = lines[1:index]
        if not front_matter_lines:
            raise ValueError(
                "front matter 为空：'---' 与结束 '---' 之间没有任何字段。"
            )
        return front_matter_lines, "\n".join(lines[index + 1:])

    raise ValueError(
        "front matter 未闭合：文件以 '---' 开头，但没有找到配对的结束 '---'"
        "（结束标记需独占一行，行尾可有空白）。"
    )


def parse_front_matter(text: str) -> tuple[dict[str, object], str]:
    """Split front matter from the body.

    ``tools/sync-hexo.py`` generates the front matter itself, so its shape is
    known and fixed: ``key: value`` scalars plus ``key:`` followed by
    ``  - item`` lists.  Unknown keys are kept as they are, so a future
    contract field cannot break the parser.

    A document that opens a front matter block but never closes it is
    broken, and this raises ``ValueError`` rather than passing it off as a
    document without front matter.  Silently doing the latter would publish
    the raw ``---`` and ``title:`` lines as body text and fall back to the
    file name for the title -- a broken file going out as a good one.
    """
    split = _split_front_matter(text)
    if split is None:
        return {}, text
    front_matter_lines, body = split

    fields: dict[str, object] = {}
    list_key = None
    list_items: list[str] = []

    def close_list():
        nonlocal list_key, list_items
        if list_key is not None:
            fields[list_key] = list(list_items)
        list_key = None
        list_items = []

    for raw in front_matter_lines:
        if not raw.strip():
            continue
        stripped = raw.lstrip()
        if stripped.startswith("- "):
            if list_key is not None:
                list_items.append(_unquote(stripped[2:]))
            continue
        if ":" in raw:
            key, _, value = raw.partition(":")
            key = key.strip()
            value = value.strip()
            if value == "":
                close_list()
                list_key = key
            else:
                close_list()
                fields[key] = _unquote(value)
    close_list()

    return fields, body


def load_post(path: Path, posts_dir: Path) -> SourcePost:
    """Load one post file into a :class:`SourcePost`."""
    path = Path(path)
    text = path.read_text(encoding="utf-8")
    try:
        fields, body = parse_front_matter(text)
    except ValueError as error:
        # 说清楚是哪个文件坏了：调用方（扫描命令）只拿到一句异常，
        # 没有路径就不知道该去修哪一个。
        raise ValueError("{}: {}".format(path, error)) from error
    slug = path.relative_to(posts_dir).with_suffix("").as_posix()
    title = str(fields.get("title") or path.stem).strip()
    date = str(fields.get("date") or "")
    return SourcePost(slug=slug, title=title, date=date, body=body, fields=fields)


def discover(posts_dir: Path) -> list[SourcePost]:
    """Load every markdown post under ``posts_dir``."""
    posts_dir = Path(posts_dir)
    if not posts_dir.is_dir():
        raise FileNotFoundError(
            "找不到 {}。先跑 `python3 tools/sync-hexo.py`（约 3 分钟）。".format(posts_dir)
        )
    return [load_post(path, posts_dir) for path in sorted(posts_dir.rglob("*.md"))]


def discover_unsupported(posts_dir: Path) -> list[str]:
    """列出 source/_posts 下本适配器不支持的文件（当前是 .html 母稿）。

    这些文件会被站点发布，但头条号 adapter 不解析它们。
    返回相对 posts_dir 的路径字符串列表，排序后返回。
    目录不存在时返回空列表。

    ``tools/sync-hexo.py`` 也会把 ``docs/`` 下的 .html 博文写进
    ``source/_posts/``，而 ``discover()`` 只收 .md —— 这些母稿不会进头条号
    的发布流程。把它们显式列出来，扫描方才能说清楚「哪些没发」而不是
    静默少发几篇。

    隐藏文件（``.DS_Store`` 之类）与隐藏目录不算：站点不会发布它们。
    """
    posts_dir = Path(posts_dir)
    if not posts_dir.is_dir():
        return []

    unsupported = []
    for path in posts_dir.rglob("*"):
        if not path.is_file():
            continue
        relative = path.relative_to(posts_dir)
        if any(part.startswith(".") for part in relative.parts):
            continue
        if path.suffix == ".md":
            continue
        unsupported.append(relative.as_posix())
    return sorted(unsupported)
```

"""Slice a source post into the Toutiao version.

The Toutiao version is a re-cut, not a copy: 3K of prose, one to three
images, and every link flattened to plain text.  The reasons are platform
constraints, not taste:

- the title cap is 30 characters
- Toutiao will not render an external image, so every image is a manual
  upload step -- which is why there are only three of them
- an external URL is not a link unless the account has the "insert external
  link" entitlement, and the platform forbids external jump code outright
"""

from __future__ import annotations

import html
import re
from dataclasses import dataclass

from .capability import Limits
from .mdparse import SourcePost

__all__ = ["SliceResult", "ToutiaoArticle", "slice_post"]

_HEADING = re.compile(r"^(#{1,6})\s+(.*)$")
_IMAGE_LINE = re.compile(r"^!\[([^\]]*)\]\(([^)]*)\)$")
_IMAGE_INLINE = re.compile(r"!\[([^\]]*)\]\(([^)]*)\)")

# The HTML elements that may show up in a body.  A ``<name>`` that is not
# on this list is not markup: ``<db_oid>``, ``<relfilenode>`` and ``<slug>``
# are placeholders in paths and identifiers, and stripping them would
# publish a wrong technical fact.
#
# Two groups are deliberately left out:
#   - head-only elements (``title``, ``meta``, ``link``, ``base``, ``html``,
#     ``head``, ``body``) -- they never carry body prose, and ``<title>`` is
#     a common path placeholder in these drafts;
#   - names that read like ordinary words and are used as placeholders
#     (``slot``, ``data``, ``time``, ``output``, ``summary``, ``param``,
#     ``source``, ``object``) -- ``<slot_name>``, ``<source_path>`` ...
_HTML_ELEMENTS = frozenset((
    "a", "abbr", "address", "area", "article", "aside", "audio", "b", "bdi",
    "bdo", "big", "blockquote", "br", "button", "canvas", "caption", "center",
    "cite", "code", "col", "colgroup", "del", "details", "dfn", "dialog",

def _field_text(fields: dict, key: str) -> str:
    value = fields.get(key)
    if isinstance(value, str):
        return value.strip()
    return ""


def _join(lines: list) -> str:
    """Join wrapped lines back into one paragraph.

    Chinese text is joined without a space; anything else keeps one.
    """
    out = ""
    for line in lines:
        if not out:
            out = line
            continue
        if _CJK.search(out[-1]) and _CJK.search(line[0]):
            out += line
        else:
            out += " " + line
    return out


def _truncate_title(title: str, limit: int) -> str:
    """Cut a title to ``limit`` characters, preferring a natural break."""
    head = title[:limit]
    for separator in ("：", ":", "，", "、", "——", "—", " ", "|"):
        cut = head.rfind(separator)
        if cut >= limit // 2:
            return head[:cut].rstrip(" ：:，、—|")
    return head.rstrip(" ：:，、—|")


def _image_path(raw: str) -> str:
    """The path inside ``![alt](path)`` -- without the optional title.

    Markdown allows a title after the path: ``![alt](https://x/a.png "图说")``.
    Keeping it would hand the downloader a string that is not a path at all,
    so the title is dropped and only the URL or file path survives.
    """
    path = raw.strip()
    return _IMAGE_TITLE.sub("", path).strip()


def _replace_inline_images(text: str, images: list[str]) -> str:
    """Swap every inline image for a ``【图N】`` placeholder.

    An image that sits inside a line of prose is an image too: it has to
    be uploaded like the ones that stand on their own line, so it goes
    into ``images`` and leaves a placeholder behind.  The numbering is
    shared with the standalone images and follows document order.
    """

    def replace(match):
        images.append(_image_path(match.group(2)))
        return "【图{}】".format(len(images))

    return _IMAGE_INLINE.sub(replace, text)


def _split_code(text: str) -> list[tuple[bool, str]]:
    """Split the text into ``(is_code, chunk)`` pieces on inline code spans."""
    pieces: list[tuple[bool, str]] = []
    last = 0
    for match in _INLINE_CODE.finditer(text):
        if match.start() > last:
            pieces.append((False, text[last:match.start()]))
        pieces.append((True, match.group(0)))
        last = match.end()
    if last < len(text):
        pieces.append((False, text[last:]))
    return pieces


def _is_code_sample(chunk: str) -> bool:
    """Whether a backtick-quoted span really is a code sample.

    Two stray backticks around a piece of prose are not a code span.
    When such a span carries a real tag, the tag is markup in a normal
    sentence and has to come out -- otherwise the body keeps a literal
    ``<div>`` in it.

    The one exception is a span that holds nothing but markup (a lone
    ``<div>`` between backticks): there the tags are the sample itself,
    and taking them away would leave nothing behind.
    """
    if not _HTML_TAG.search(chunk):
        return True
    return not _HTML_TAG.sub("", chunk).strip("`").strip()


def _clean_html(text: str) -> str:
    """Take the HTML markup out, keep the text it wraps.

    Inline code is protected: inside backticks every character is literal,
    so ``base/<db_oid>/<relfilenode>`` is a path, not a tag.  Only the
    known HTML elements count as tags -- ``<db_oid>`` is not one of them,
    and stripping it would publish a wrong path.

    A backtick pair that spans a real tag is not code, it is two stray
    backticks around a sentence -- so the tag still comes out.

    Entities are decoded as well, but only for a block that really carries
    a tag: decoding everywhere would rewrite text that never was HTML.
    """
    pieces = [
        (False, chunk) if is_code and not _is_code_sample(chunk) else (is_code, chunk)
        for is_code, chunk in _split_code(text)
    ]
    if not any(_HTML_TAG.search(chunk) for is_code, chunk in pieces if not is_code):
        return text
    out = []
    for is_code, chunk in pieces:
        if is_code:
            out.append(chunk)
        else:
            out.append(html.unescape(_HTML_TAG.sub("", chunk)))
    return "".join(out)



def _drop_excess_markers(block: str, keep: int) -> str:
    """Remove the placeholders of the images that did not make the cut."""
    return _MARKER_IN_TEXT.sub(
        lambda m: "" if int(m.group(1)) > keep else m.group(0), block
    )


def _scan(body: str) -> tuple[list[str], list[str]]:
    """Split a post body into kept blocks and image paths.

    Kept: ``##`` / ``###`` headings, paragraphs, list items.
    Dropped: fenced code, tables, block quotes, raw HTML, ``####`` and
    deeper headings -- they are exactly what makes a 3K version impossible.

    Heading levels are normalized: ``##`` and ``###`` both come out as
    ``##``, because a ``##`` sub-heading is what the Toutiao version must
    carry between paragraphs.  ``#`` is dropped -- that is the post title,
    which already lives in the title field.
    """
    blocks: list[str] = []
    images: list[str] = []
    paragraph: list[str] = []

    def flush():
        if paragraph:
            text = _clean_html(_replace_inline_images(_join(paragraph), images)).strip()
            if text:
                blocks.append(text)
            del paragraph[:]

    in_fence = False
    fence_marker = ""
    for raw in body.split("\n"):
        stripped = raw.strip()

        if in_fence:
            if stripped.startswith(fence_marker):
                in_fence = False
            continue

        if stripped.startswith("```") or stripped.startswith("~~~"):
            flush()
            in_fence = True
            fence_marker = stripped[:3]
            continue

        if not stripped:
            flush()
            continue

        if stripped.startswith("|") or stripped.startswith(">"):
            flush()
            continue

        if _LINK_DEFINITION.match(stripped):
            # A reference definition is a link definition, not prose --
            # keeping it would leak the URL it points at.
            flush()
            continue

        if _HTML_TAG.search(stripped) and not _HTML_TAG.sub("", stripped).strip():
            # A line that is nothing but HTML markup goes; a line that
            # mixes markup with text keeps its text -- the tags are taken
            # out when the block is finished.
            flush()
            continue

        heading = _HEADING.match(stripped)
        if heading:
            flush()
            if 2 <= len(heading.group(1)) <= 3:
                text = _clean_html(
                    _replace_inline_images(heading.group(2).strip(), images)
                ).strip()
                if text:
                    blocks.append("## " + text)
            continue

        image = _IMAGE_LINE.match(stripped)
        if image:
            flush()
            images.append(_image_path(image.group(2)))
            blocks.append("【图{}】".format(len(images)))
            continue

        item = _LIST.match(stripped)
        if item:
            flush()
            text = _clean_html(
                _replace_inline_images(item.group(1).strip(), images)
            ).strip()
            if text:
                blocks.append("- " + text)
            continue

        if _LIST_EMPTY.match(stripped):
            # A list marker with nothing behind it is not a paragraph --
            # "1. " would otherwise come out as a stray "1." block.
            flush()
            continue

        paragraph.append(stripped)

    flush()
    return blocks, images


def _strip_links(text: str) -> tuple[str, int]:
    """Turn every markdown link into plain text; count what was removed.

    Both shapes count: the inline one (``[text](url)``) and the
    reference one (``[text][1]``).  Both are links, so both are counted.
    """
    count = 0

    def replace(match):
        nonlocal count
        count += 1
        return match.group(1)

    text = _LINK.sub(replace, text)
    return _LINK_REFERENCE.sub(replace, text), count


def _first_paragraph(blocks: list[str]) -> str:
    for block in blocks:
        if not block or block.startswith("## ") or block.startswith("【图"):
            continue
        if block.startswith("- "):
            return block[2:].strip()
        return block
    return ""


def slice_post(post: SourcePost, limits: Limits, source_url: str = "https://growdu.cn") -> SliceResult:
    """Cut one source post into the Toutiao version.

    The digest falls back through ``description`` -> ``tldr`` -> the first
    paragraph -> the article title.  The title is the last resort: it only
    steps in when the body has no paragraph to summarize at all, which is
    what a picture-led post looks like.  A digest that is still too long
    is cut down and the cut is written into ``notes`` -- nothing is
    shortened silently.
    """
    notes: list[str] = []

    short_title = _field_text(post.fields, "short_title")
    if short_title:
        if len(short_title) > limits.title_chars:
            return SliceResult(
                reason="short_title 超过 {} 字（{}）".format(limits.title_chars, len(short_title))
            )
        title = short_title
        title_truncated = False
    elif len(post.title) > limits.title_chars:
        title = _truncate_title(post.title, limits.title_chars)
        title_truncated = True
        if not title.strip():
            # A title of nothing but separators cuts down to nothing --
            # publishing it would be a silent success with no title.
            return SliceResult(reason="标题裁剪后为空")
        notes.append("标题已裁剪到 {} 字（实际 {} 字）".format(limits.title_chars, len(title)))
    else:
        title = post.title
        title_truncated = False
        if not title.strip():
            return SliceResult(reason="标题为空")

    blocks, images = _scan(post.body)
    if not blocks:
        # Nothing survived the filter: a body of nothing but tables,
        # quotes, code fences or raw HTML has no Toutiao version.  Say so
        # instead of publishing an empty article.
        return SliceResult(reason="正文里没有可保留的内容")

    if len(images) > limits.max_body_images:
        dropped = len(images) - limits.max_body_images
        images = images[: limits.max_body_images]
        # The placeholders of the images that did not make the cut go too --
        # they sit inside a line of prose as often as they stand alone.
        blocks = [
            _drop_excess_markers(block, limits.max_body_images).strip()
            for block in blocks
        ]
        blocks = [block for block in blocks if block]
        notes.append("正文图 {} 张，只保留前 {} 张".format(len(images) + dropped, limits.max_body_images))

    dropped_links = 0
    stripped_blocks = []
    for block in blocks:
        text, count = _strip_links(block)
        dropped_links += count
        stripped_blocks.append(text)
    blocks = stripped_blocks

    digest = (
        _field_text(post.fields, "description")
        or _field_text(post.fields, "tldr")
        or _first_paragraph(blocks)
        or title
    )
    # `title` is non-empty here -- the three title branches (`short_title`,
    # `_truncate_title`, plain `post.title`) each guarantee it -- so the
    # digest never is.
    if len(digest) > limits.digest_chars:
        digest = digest[: limits.digest_chars]
        notes.append("摘要已裁剪到 {} 字".format(limits.digest_chars))

    site = source_url.split("://", 1)[-1].rstrip("/")
    tail = "完整版见 {}".format(site)
    budget = max(limits.body_chars - len(tail) - 2, 1)

    body_text = "\n\n".join(blocks).strip()
    body_truncated = False
    if len(body_text) > budget:
        cut = body_text.rfind("\n\n", 0, budget)
        if cut <= 0:
            cut = budget
        body_text = body_text[:cut].rstrip()
        body_truncated = True
        notes.append("正文超过 {} 字，已截断".format(limits.body_chars))
    body_text = body_text + "\n\n" + tail

    article = ToutiaoArticle(
        content_id=post.slug,
        title=title,
        digest=digest,
        body=body_text,
        images=tuple(images),
        title_truncated=title_truncated,
        body_truncated=body_truncated,
        dropped_links=dropped_links,
        notes=tuple(notes),
    )
    return SliceResult(article=article)
```

### Task 4: 图片与封面

**Files:**
- Create: `toutiao/toutiao/assets.py`
- Test: `toutiao/tests/test_assets.py`

**Interfaces:**
- Consumes: `Limits`（Task 1）
- Produces:
  - `class PreparedImage`（frozen dataclass）：`source: str`、`path: Path`、`width: int`、`height: int`、`size_bytes: int`
  - `class ImageTooLarge(ValueError)`
  - `class RemoteAsset(ValueError)`：图路径是外链 URL
  - `class AssetNotFound(ValueError)`：图路径解析不到文件，或跑出了站点根目录
  - `class UnreadableImage(ValueError)`：文件不是 Pillow 能转的格式（如 SVG）。`prepare_image()` 抛它 —— 调用方要能把它与「转不动」（`ImageTooLarge`）分辨开：前者交人工处理，后者是尺寸问题
  - `is_remote(path: str) -> bool`
  - `resolve_asset(path: str, posts_dir: Path) -> Path`
  - `prepare_image(src: Path, dst: Path, max_bytes: int) -> PreparedImage`
  - `can_make_cover(src: Path, ratio: str, min_pixels: tuple) -> bool`
  - `make_cover(src: Path, dst: Path, ratio: str, min_pixels: tuple) -> PreparedImage`

**规则（实现必须逐条对上）：**

| 项 | 规则 |
| --- | --- |
| 外链图 | **不下载**：`is_remote()` 认得出来，`resolve_asset()` 抛 `RemoteAsset`。出包不依赖网络；远程图由 Task 6 在出包清单里列为「需人工下载」并附上 URL |
| 找不到的图 | `resolve_asset()` 抛 `AssetNotFound`，**错误里带上那个路径**。静默返回一个相对路径，会让出包缺图却没人知道 |
| 越界的路径 | 解析结果必须留在 `posts_dir.parent`（站点根目录）之内；跑出去就抛 `AssetNotFound` |
| 读不了的格式 | Pillow 读不了的格式（如 SVG）→ `prepare_image()` 抛 `UnreadableImage`，**不是**裸的 `UnidentifiedImageError` 漏出去。调用方要能分辨「这个文件不是我能转的格式」与「这个文件我转不动（压不进 5MB）」—— 前者交人工处理，后者是尺寸问题。真实的 60 张本地图里就有 1 张 SVG，不专门接住它，那一篇的整包会崩 |
| 透明像素 | 带 alpha 的图**合成到白底**再转 RGB。`convert("RGB")` 是**丢弃** alpha：透明像素保留自己那点几乎全黑的原色，图就变成黑底 —— 真实语料里有 2 张白底示意图带真透明像素，丢完 alpha，深色标注变成黑底上的深色、几乎不可读。`prepare_image()` 与 `make_cover()` 走**同一个**合成函数 |
| 封面 | 裁的是**已转好的 webp**（`prepare_image()` 的产物），不是原始 PNG；裁完仍必须 ≥ `cover_min_pixels`，不够就报错。`can_make_cover()` 与 `make_cover()` 用同一把尺子：3:4 的裁切会让图变小 |
| 张数 | 正文图最多 `max_body_images` 张（Task 3 定的）；**0 张也能出包**，见 `00-设计.md` §3.3 |

```python
"""Prepare images for Toutiao.

Toutiao will not render an external image: every picture has to be uploaded
into the editor by hand.  That is why the Toutiao version keeps at most
three of them.  This module does the part a machine can do -- convert to
webp, squeeze under the size cap, crop a cover to 3:4.

Only local images are handled.  A remote URL is never fetched: the package
must not depend on the network, and the uploader has to download such a
picture by hand anyway.

Pillow does not read every picture format there is -- an SVG is not one it
can open.  Such a file is refused with :class:`UnreadableImage`, so that the
caller can tell "this file is not a picture I can convert" apart from "this
picture is too big to squeeze".
"""

from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path

__all__ = [
    "AssetNotFound", "ImageTooLarge", "PreparedImage", "RemoteAsset",
    "UnreadableImage", "can_make_cover", "is_remote", "make_cover",
    "prepare_image", "resolve_asset",
]

# The quality ladder ``prepare_image()`` walks down when the picture is too
# big.  The cover gets its own quality: it is the one image the reader sees
# first, and it is cropped down afterwards.
_QUALITIES = (85, 75, 65, 55)
_COVER_QUALITY = 88

# The modes that carry an alpha band of their own.  A palette image keeps
# its transparency in ``info`` instead -- see ``_flatten_on_white()``.
_ALPHA_MODES = ("RGBA", "LA", "RGBa", "PA")


class ImageTooLarge(ValueError):
    """The image cannot be squeezed under the platform limit."""


class RemoteAsset(ValueError):
    """The asset path is a remote URL -- there is no local file."""


class AssetNotFound(ValueError):
    """The asset path does not resolve to a file inside the site."""


class UnreadableImage(ValueError):
    """The file is not a picture Pillow can convert.

    Raised instead of letting Pillow's own ``UnidentifiedImageError`` (an
    ``OSError``) out: the caller has to be able to tell "this file is not a
    picture I can convert" -- a job for a human -- from "this picture is too
    big to squeeze under the limit".
    """


@dataclass(frozen=True)
class PreparedImage:
    """One image that is ready to upload."""

    source: str
    path: Path
    width: int
    height: int
    size_bytes: int


def is_remote(path: str) -> bool:
    """Whether an asset path points at a remote file.

    Toutiao will not render an external image anyway, and the package
    must not depend on the network: a remote image is a manual step for
    the person uploading, not something this module fetches.

    Takes the path as it was written in the post -- a ``str``.  A ``Path``
    would have swallowed the ``//`` of the scheme on the way in, so it is
    not accepted here.
    """
    return path.strip().lower().startswith(("http://", "https://"))


def resolve_asset(path: str, posts_dir: Path) -> Path:
    """Resolve an asset path from a post to a real file.

    ``tools/sync-hexo.py`` rewrites every image reference to
    ``images/<path relative to docs/>`` and copies the files to
    ``source/images/``.  So an asset path resolves against the ``source/``
    root -- the parent of ``_posts/``.

    Three things are refused here, and each of them says what went wrong:

    - a remote URL: the package must not depend on the network;
    - a path that resolves to no file: a silent fallback would ship a
      package with a missing picture and no word about it;
    - a path that leaves the site root: an asset path is a relative path
      inside the site, never a way out of it.
    """
    if is_remote(path):
        raise RemoteAsset("外链图不在本地：{}".format(path))
    site_root = Path(posts_dir).parent.resolve()
    candidate = Path(path)
    resolved = candidate.resolve() if candidate.is_absolute() else (site_root / candidate).resolve()
    if resolved != site_root and site_root not in resolved.parents:
        raise AssetNotFound(
            "图路径跑出了站点根目录 {}：{}".format(site_root, path)
        )
    if not resolved.is_file():
        raise AssetNotFound("找不到图文件：{}（按 {} 解析）".format(path, site_root))
    return resolved


def _flatten_on_white(image):
    """Flatten a picture onto a white background.

    ``convert("RGB")`` *throws the alpha away*: a transparent pixel keeps
    whatever colour it had underneath -- almost black -- so a picture with
    a transparent margin comes out with a **black** background.  Two of the
    real pictures are white-background diagrams with transparent margins:
    dropping the alpha turns their dark labels into unreadable
    dark-on-dark.

    Composing onto white is the deterministic choice, and it is what the
    browser shows on the blog page.  Keeping the alpha in the webp would
    leave the question of how the platform renders transparency to them.

    A picture without an alpha band is left alone -- the white background
    of an opaque picture is already what it is.
    """
    from PIL import Image

    if image.mode in _ALPHA_MODES:
        rgba = image.convert("RGBA")
    elif image.mode == "P":
        # A palette picture keeps its transparency in ``info``, not in a band.
        rgba = image.convert("RGBA") if "transparency" in image.info else None
    elif image.mode == "RGB" and "transparency" in image.info:
        rgba = image.convert("RGBA")
    else:
        rgba = None

    if rgba is None:
        return image.convert("RGB")
    background = Image.new("RGBA", rgba.size, (255, 255, 255, 255))
    return Image.alpha_composite(background, rgba).convert("RGB")


def _load_picture(src):
    """Read a picture, flattened onto a white background.

    One place reads pictures, so one place decides what an unreadable
    file looks like: :class:`UnreadableImage`, never Pillow's own
    ``UnidentifiedImageError``.  A caller must not have to know whether
    the picture it asked about went through ``prepare_image()`` or
    straight into a cover.
    """
    from PIL import Image, UnidentifiedImageError

    src = Path(src)
    try:
        with Image.open(src) as opened:
            return _flatten_on_white(opened)
    except UnidentifiedImageError as error:
        raise UnreadableImage(
            "Pillow 读不了这个文件（可能是 SVG 等格式）：{}".format(src.name)
        ) from error
    except (FileNotFoundError, PermissionError):
        # The file is not there, or not ours to read -- that is not an
        # unreadable picture, and the caller has to see it as it is.
        raise
    except OSError as error:
        # The format is one Pillow knows, but the file does not decode (a
        # truncated picture, for one).  Also a job for a human.
        raise UnreadableImage(
            "Pillow 解不开这个文件（可能已截断）：{}".format(src.name)
        ) from error


def prepare_image(src: Path, dst: Path, max_bytes: int) -> PreparedImage:
    """Convert an image to webp, shrinking until it fits ``max_bytes``.

    Two levers are pulled, in this order: the quality of the webp, and --
    when even the lowest quality is too big -- the size of the picture
    itself.  When neither is enough the picture is refused rather than
    written out over the limit: a package that ships an oversized image is
    a package the platform will reject at upload time.

    A picture with transparency is flattened onto a white background
    first -- see ``_flatten_on_white()``.

    A file Pillow cannot open (an SVG, for one) is refused with
    :class:`UnreadableImage` before any of that: it is not a picture that
    is too big, it is a file that needs a human.
    """
    src = Path(src)
    dst = Path(dst)
    dst.parent.mkdir(parents=True, exist_ok=True)

    image = _load_picture(src)

    for quality in _QUALITIES:
        image.save(dst, "WEBP", quality=quality, method=6)
        if dst.stat().st_size <= max_bytes:
            break
    else:
        image.thumbnail((max(image.width // 2, 1), max(image.height // 2, 1)))
        image.save(dst, "WEBP", quality=_QUALITIES[-1], method=6)
    # ``image.size`` is read after the shrink, so the reported size is
    # the size of the file that was actually written.
    width, height = image.size

    size = dst.stat().st_size
    if size > max_bytes:
        # Do not leave the oversized file behind: it would sit in the
        # output directory looking like a finished picture.
        dst.unlink(missing_ok=True)
        raise ImageTooLarge(
            "{} 压缩后仍有 {} 字节，超过上限 {}".format(src.name, size, max_bytes)
        )
    return PreparedImage(source=str(src), path=dst, width=width, height=height, size_bytes=size)


def _parse_ratio(ratio: str) -> tuple[int, int]:
    """The ``W:H`` of a ratio, as two positive integers."""
    parts = ratio.split(":")
    if len(parts) != 2:
        raise ValueError("封面比例必须是 W:H，实际是 {!r}".format(ratio))
    try:
        width, height = (int(part) for part in parts)
    except ValueError:
        raise ValueError("封面比例必须是两个整数，实际是 {!r}".format(ratio)) from None
    if width <= 0 or height <= 0:
        raise ValueError("封面比例必须为正数，实际是 {!r}".format(ratio))
    return width, height


def _cover_box(width: int, height: int, target_width: int, target_height: int) -> tuple:
    """The centre crop of ``width`` x ``height`` at the given ratio.

    The crop is an exact multiple of the ratio -- ``target_width * k`` by
    ``target_height * k`` -- because rounding the crop size instead leaves
    an off-by-one ratio behind: a 640x960 picture cropped to 640x853 is
    2560:2559, not 3:4.
    """
    scale = min(width // target_width, height // target_height)
    crop_width = target_width * scale
    crop_height = target_height * scale
    left = (width - crop_width) // 2
    top = (height - crop_height) // 2
    return (left, top, left + crop_width, top + crop_height)


def _cover_plan(size, ratio: str) -> tuple:
    """The crop box for a picture of ``size`` cut to ``ratio`` -- the one ruler.

    ``can_make_cover()`` and ``make_cover()`` both go through this, so the
    two can never disagree about whether a picture can be a cover: the
    crop is what counts, because a 3:4 crop of a wide picture throws away
    part of its width and the leftover can fall under the platform
    minimum even when the source cleared it.
    """
    target_width, target_height = _parse_ratio(ratio)
    return _cover_box(size[0], size[1], target_width, target_height)


def can_make_cover(src: Path, ratio: str, min_pixels: tuple) -> bool:
    """Whether this image can produce a valid cover of ``ratio``.

    A file that is not a picture at all is refused with
    :class:`UnreadableImage` -- the same way ``prepare_image()`` refuses
    it.
    """
    image = _load_picture(src)
    left, top, right, bottom = _cover_plan(image.size, ratio)
    min_width, min_height = min_pixels
    return right - left >= min_width and bottom - top >= min_height


def make_cover(src: Path, dst: Path, ratio: str, min_pixels: tuple) -> PreparedImage:
    """Crop the centre of ``src`` to ``ratio`` and save it as webp.

    The cover has to clear the platform minimum *after* the crop: a 3:4
    crop of a small picture is smaller than the picture.

    The picture handed in is the webp that ``prepare_image()`` produced --
    cropping the original would work on a file the platform never sees,
    and would drop the size cap that file was already squeezed under.

    A picture with transparency is flattened onto a white background
    first, exactly like ``prepare_image()`` does -- see
    ``_flatten_on_white()``.
    """
    src = Path(src)
    dst = Path(dst)
    dst.parent.mkdir(parents=True, exist_ok=True)

    image = _load_picture(src)
    left, top, right, bottom = _cover_plan(image.size, ratio)
    min_width, min_height = min_pixels
    crop_width, crop_height = right - left, bottom - top
    if crop_width < min_width or crop_height < min_height:
        raise ValueError(
            "裁完的封面只有 {}×{}，小于下限 {}×{}".format(
                crop_width, crop_height, min_width, min_height
            )
        )

    cropped = image.crop((left, top, right, bottom))
    cropped.save(dst, "WEBP", quality=_COVER_QUALITY, method=6)

    return PreparedImage(
        source=str(src),
        path=dst,
        width=crop_width,
        height=crop_height,
        size_bytes=dst.stat().st_size,
    )

"""Render the Toutiao article as paste-ready HTML and as plain text.

Two artefacts, two purposes:

- ``html`` is what the author pastes into the Toutiao editor.  Styles are
  inline because the editor drops ``<style>`` blocks, and there are no
  ``class`` attributes for the same reason.
- ``text`` is the fallback for the case where the editor mangles the HTML.
"""

from __future__ import annotations

import re
from dataclasses import dataclass

from .contract import ToutiaoArticle

__all__ = ["RenderResult", "render"]

_P_STYLE = "margin:0 0 16px 0;line-height:1.75;font-size:16px;color:#333333;"
_H2_STYLE = "margin:24px 0 12px 0;font-size:18px;font-weight:bold;color:#222222;"
_MARK_STYLE = "margin:16px 0;text-align:center;color:#999999;font-size:14px;"

_MARKER = re.compile(r"^【图(\d+)】$")
_INLINE_CODE = re.compile(r"`([^`]+)`")
_BOLD = re.compile(r"\*\*([^*]+)\*\*")
_ITALIC = re.compile(r"(?<!\*)\*([^*]+)\*(?!\*)")


@dataclass(frozen=True)
class RenderResult:
    """The two pasteable forms of one article."""

    html: str
    text: str
    image_markers: tuple


def _escape(text: str) -> str:
    return text.replace("&", "&amp;").replace("<", "&lt;").replace(">", "&gt;")


def _inline(text: str) -> str:
    """Escape HTML, then restore the inline markdown the blog actually uses."""
    out = _escape(text)
    out = _INLINE_CODE.sub(r"<code>\1</code>", out)
    out = _BOLD.sub(r"<strong>\1</strong>", out)
    out = _ITALIC.sub(r"<em>\1</em>", out)
    return out


def render(article: ToutiaoArticle) -> RenderResult:
    """Render the article body into HTML and plain text."""
    html_parts: list = []
    text_parts: list = []
    markers: list = []

    for raw_block in article.body.split("\n\n"):
        block = raw_block.strip()
        if not block:
            continue

        if block.startswith("## "):
            heading = block[3:].strip()
            html_parts.append('<h2 style="{}">{}</h2>'.format(_H2_STYLE, _inline(heading)))
            text_parts.append(heading)
            continue

        if _MARKER.match(block):
            markers.append(block)
            html_parts.append('<p style="{}">{}</p>'.format(_MARK_STYLE, _escape(block)))
            text_parts.append(block)
            continue

        lines = [line.strip() for line in block.split("\n") if line.strip()]
        if lines and all(line.startswith("- ") for line in lines):
            for line in lines:
                item = line[2:].strip()
                html_parts.append('<p style="{}">• {}</p>'.format(_P_STYLE, _inline(item)))
                text_parts.append("• " + item)
            continue

        html_parts.append('<p style="{}">{}</p>'.format(_P_STYLE, _inline(block)))
        text_parts.append(block)

    return RenderResult(
        html="\n".join(html_parts),
        text="\n\n".join(text_parts),
        image_markers=tuple(markers),
    )

In ``manual`` mode nothing is uploaded: the package is written to disk and a
human uploads it.  That is the current state of affairs -- the account has

@dataclass(frozen=True)
class PackageResult:
    """What the manual path produced for one article."""

    content_id: str
    platform: str
    automation: str
    status: str
    title: str
    package_dir: Path
    files: tuple
    reason: str | None = None


def flatten_id(content_id: str) -> str:
    """Turn a site slug into a filesystem- and filename-safe id."""
    return content_id.replace("/", "-")


def snapshot_name(content_id: str, platform: str) -> str:
    """The outbox file name for one content id on one platform."""
    return "{}__{}.json".format(flatten_id(content_id), platform)


def write_package(
    article: ToutiaoArticle,
    capability: Capability,
    package_root: Path,
    posts_dir: Path,
    source_url: str = "https://growdu.cn",
) -> PackageResult:
    """Write the manual publish package for one article.

    A post without a body image still gets a package: Toutiao has a
    no-image mode, and 470 of the 542 publishable posts have no image at
    all.  The checklist says so in as many words instead of pretending
    there is a cover.
    """
    package_dir = Path(package_root) / flatten_id(article.content_id)
    images_dir = package_dir / "images"
    package_dir.mkdir(parents=True, exist_ok=True)
    images_dir.mkdir(parents=True, exist_ok=True)

    limits = capability.limits
    site = source_url.split("://", 1)[-1].rstrip("/")

    rendered = render(article)
    (package_dir / "article.html").write_text(rendered.html + "\n", encoding="utf-8")
    (package_dir / "article.txt").write_text(rendered.text + "\n", encoding="utf-8")
    (package_dir / "title.txt").write_text(
        "{}\n{}\n".format(article.title, article.digest), encoding="utf-8"
    )

    prepared = []
    remote_images = []
    missing_images = []
    unreadable_images = []
    local_images = []
    for index, relative in enumerate(article.images, start=1):
        if is_remote(relative):
            # 外链图不下载 —— 出包不依赖网络，交给人工。
            remote_images.append(relative)
            continue
        local_images.append(relative)
        try:
            source = resolve_asset(relative, posts_dir)
        except AssetNotFound:
            missing_images.append(relative)
            continue
        try:
            info = prepare_image(
                source, images_dir / "{:02d}.webp".format(index), limits.image_bytes
            )
        except UnreadableImage:
            # 读不了的格式（如 SVG）—— 不当失败，列进清单交给人工。
            unreadable_images.append(relative)
            continue
        prepared.append(info)

    # 封面取「第一张能裁出合规封面的正文图」—— 第一张裁不动、第二张能裁时
    # 要用第二张。判定用的是已转好的 webp：prepare_image() 压不进时会缩一半，
    # 原图能裁不代表 webp 能裁，拿 webp 判两边才一致。
    cover_written = False
    for info in prepared:
        if not can_make_cover(info.path, limits.cover_ratio, limits.cover_min_pixels):
            continue
        try:
            make_cover(
                info.path,
                package_dir / "cover.webp",
                limits.cover_ratio,
                limits.cover_min_pixels,
            )
        except ValueError:
            # 判定与裁切用的是同一把尺子，这里不该再失败；失败就换下一张。
            continue
        cover_written = True
        break

    markers = "、".join(rendered.image_markers) if rendered.image_markers else "（无）"
    checklist = [
        "- [ ] 打开头条号后台 → 发文章",
        "- [ ] 标题：复制 `title.txt` 第一行（{} 字以内）".format(limits.title_chars),
        "- [ ] 正文：把 `article.html` 粘贴到编辑器（若排版丢失，改用 `article.txt`）",
        "- [ ] 图片：上传 `images/` 里的 {} 张图，文件名 NN 对应正文里的【图NN】；"
        "要替换的占位符是 {}".format(len(prepared), markers),
    ]
    if cover_written:
        checklist.append(
            "- [ ] 封面：上传 `cover.webp`（{}，不小于 {}）".format(
                limits.cover_ratio, "{0}×{1}".format(*limits.cover_min_pixels)
            )
        )
    elif not article.images:
        checklist.append("- [ ] 封面：{}".format(NO_COVER_NOTE))
    elif not local_images:
        # 正文图全是外链：出包不下载外链图，没有本地文件可裁。
        checklist.append("- [ ] 封面：{}".format(NO_COVER_REMOTE_ONLY_NOTE.format(
            ratio=limits.cover_ratio,
            min_pixels="{0}×{1}".format(*limits.cover_min_pixels),
        )))
    else:
        # 有本地图但一张都裁不出合规封面 —— 与前两种分开说。
        checklist.append("- [ ] 封面：{}".format(NO_COVER_UNCROPPABLE_NOTE.format(
            ratio=limits.cover_ratio,
            min_pixels="{0}×{1}".format(*limits.cover_min_pixels),
        )))
    if remote_images:
        checklist.append(
            "- [ ] 远程图：出包不下载外链图，这 {} 张要人工下载后上传：{}".format(
                len(remote_images), "、".join(remote_images)
            )
        )
    if missing_images:
        checklist.append(
            "- [ ] 缺图：出包时找不到这 {} 个文件，需人工核对路径：{}".format(
                len(missing_images), "、".join(missing_images)
            )
        )
    if unreadable_images:
        checklist.append(
            "- [ ] 读不了的图：出包时无法转换这 {} 个文件（Pillow 读不了，"
            "可能是 SVG 等格式），需人工处理：{}".format(
                len(unreadable_images), "、".join(unreadable_images)
            )
        )
    checklist.append("- [ ] 检查正文末尾是纯文本「{}」，不是超链接".format(site))
    checklist.append("- [ ] 发表")

    (package_dir / "README.md").write_text(
        README_HEAD.format(article.title) + "\n".join(checklist) + "\n",
        encoding="utf-8",
    )

    files = tuple(sorted(p.name for p in package_dir.iterdir()))
    return PackageResult(
        content_id=article.content_id,
        platform=capability.id,
        automation=capability.automation,
        status="packaged",
        title=article.title,
        package_dir=package_dir,
        files=files,
    )


def write_snapshot(result: PackageResult, outbox_dir: Path) -> Path:
    """Write the cross-platform status snapshot for one article."""
    outbox_dir = Path(outbox_dir)
    outbox_dir.mkdir(parents=True, exist_ok=True)
    path = outbox_dir / snapshot_name(result.content_id, result.platform)
    payload = {
        "content_id": result.content_id,
        "platform": result.platform,
        "status": result.status,
        "automation": result.automation,
        "title": result.title,
        "published_url": None,
        "package_dir": "{}/".format(result.package_dir.name),
        "updated_at": datetime.now(timezone.utc).isoformat(timespec="seconds"),
        "reason": result.reason,
    }
    path.write_text(
        json.dumps(payload, ensure_ascii=False, indent=2, sort_keys=True) + "\n",
        encoding="utf-8",
    )
    return path
```

| # | 原骨架 | 改成 | 为什么 |
| --- | --- | --- | --- |
| 1 | `save()` 里 `state.updated_at = ...`（就地改调用方传进来的对象） | 复制一份、打上时间戳、存副本，调用方的对象一个字段都不动 | store 悄悄改调用方的输入是看不见的副作用；调用方随后读到的 `updated_at` 会是一个「其实从没存过」的时间戳 |
| 2 | `except (json.JSONDecodeError, OSError): return {}` | 损坏的文件**改名隔离**成 `<path>.corrupt`（不删），`store.quarantined` 记下隔离路径，然后照旧当作空状态 | 状态一丢，所有记录都变成「没发过」，流水线会把发过的东西再发一遍。发重了比发慢了糟糕得多，所以证据要留着、也要报出来 |

创建 `toutiao/toutiao/state.py`：

```python
"""Idempotency bookkeeping for Toutiao publishing.

Publishing the same article twice is the worst failure mode of an automated
pipeline, so the state is kept in three layers:

- the body fingerprint decides whether the content changed at all
- the platform-side id (``object_id``) records that a post already exists
- ``published_url`` records that it is out there

**Two state mechanisms live in this project, and they are not the same
thing.**  Mixing them up is the easy mistake here:

- ``publish/outbox/<content_id>__<platform>.json`` is the *committed*
  idempotency key: the snapshot written by ``publish.py``.  It is public,
  it goes into the repository, and it is what the "already published, do
  not publish again" rule reads.
- ``toutiao/out/state.json`` is this machine's *working record*: the
  content fingerprint, the state of an attempt, the package directory.
  ``toutiao/.gitignore`` excludes it and it never enters the repository.

The fingerprint covers the *sliced Toutiao body* -- ``fingerprint(result.
article.body)`` in the CLI -- not the source post.  Only a change in what
actually goes out is a change worth republishing for: a paragraph the
slicer drops is not a new article.

A corrupt state file is never swallowed.  It is renamed to
``<path>.corrupt`` -- the bytes are kept as evidence -- and the store
remembers where it went in ``quarantined`` so the caller can report it
loudly.  Reading a broken file as "nothing was ever published" would
republish everything, and publishing twice is much worse than being slow.
"""

from __future__ import annotations

import hashlib
import json
from dataclasses import asdict, dataclass, replace
from datetime import datetime, timezone
from pathlib import Path

__all__ = ["PublishState", "StateStore", "fingerprint", "needs_publish"]


@dataclass
class PublishState:
    """What we already did with one article.

    Mutable on purpose: the CLI reads a record, fills in what it just
    learned (``fingerprint``, ``status``) and hands the same object back
    to ``StateStore.save()``.
    """

    fingerprint: str | None = None
    status: str | None = None
    object_id: str | None = None
    published_url: str | None = None
    updated_at: str | None = None
    package_dir: str | None = None


def fingerprint(body: str) -> str:
    """The content hash used to detect a changed article.

    The body is the Toutiao version that would be published, not the
    source post -- see the module docstring.
    """
    return hashlib.sha256(body.encode("utf-8")).hexdigest()


class StateStore:
    """A JSON file holding the state of every article we have packaged.

    The file is this machine's own working record (``toutiao/out/
    state.json``) and is never committed.
    """

    def __init__(self, path: Path):
        self.path = Path(path)
        #: The broken file that was moved aside, if there was one.
        #: ``None`` until the store has read its file.
        self.quarantined: Path | None = None

    def _load_all(self) -> dict:
        """Every record, keyed by content id.

        A file that cannot be read as the expected shape is moved aside
        and the records are treated as empty -- the caller has to be
        told about it (``quarantined``), because an empty state reads as
        "never published".
        """
        if not self.path.is_file():
            return {}
        try:
            raw = json.loads(self.path.read_text(encoding="utf-8"))
        except (json.JSONDecodeError, UnicodeDecodeError, OSError):
            self._quarantine()
            return {}
        if not isinstance(raw, dict):
            self._quarantine()
            return {}
        articles = raw.get("articles", {})
        if not isinstance(articles, dict):
            self._quarantine()
            return {}
        return articles

    def _quarantine(self) -> None:
        """Move a broken state file aside, keeping the evidence.

        The file is renamed, never deleted: whatever went wrong, the
        bytes that caused it are worth keeping for the next look.
        """
        target = self._quarantine_path()
        try:
            self.path.rename(target)
        except OSError:
            # The file could not be moved aside (permissions, a race).
            # It stays where it is, the caller still gets an empty state,
            # and ``quarantined`` stays ``None`` so that nothing claims
            # the file was dealt with.
            return
        self.quarantined = target

    def _quarantine_path(self) -> Path:
        """A free ``<name>.corrupt`` path next to the state file.

        An earlier quarantine must not be overwritten: it is the evidence
        of an earlier failure.
        """
        candidate = self.path.with_name(self.path.name + ".corrupt")
        index = 1
        while candidate.exists():
            candidate = self.path.with_name(
                "{}.corrupt.{}".format(self.path.name, index)
            )
            index += 1
        return candidate

    def all(self) -> dict:
        """Every recorded article, keyed by content id."""
        return self._load_all()

    def get(self, content_id: str) -> PublishState:
        """The record of one article; an empty one when there is none."""
        entry = self._load_all().get(content_id)
        if not isinstance(entry, dict):
            return PublishState()
        known = {name: entry.get(name) for name in PublishState.__dataclass_fields__}
        return PublishState(**known)

    def save(self, content_id: str, state: PublishState) -> None:
        """Write one record, stamped with the time of the write.

        The caller's object is left alone: a store that quietly stamps
        the object it was handed makes the caller's ``updated_at`` mean
        "somebody wrote this somewhere" instead of "this was stored".
        The timestamp therefore goes onto a copy.
        """
        articles = self._load_all()
        stamp = datetime.now(timezone.utc).isoformat(timespec="seconds")
        articles[content_id] = asdict(replace(state, updated_at=stamp))
        self.path.parent.mkdir(parents=True, exist_ok=True)
        self.path.write_text(
            json.dumps(
                {"articles": articles}, ensure_ascii=False, indent=2, sort_keys=True
            ) + "\n",
            encoding="utf-8",
        )


def needs_publish(fp: str, state: PublishState) -> bool:
    """True when the article still has to be packaged or published.

    Only ``packaged`` and ``published`` count as handled: the fingerprint
    of those decides whether the article may be skipped.  Any other
    status means the attempt did not get that far, so it has to run
    again.
    """
    if state.status in ("published", "packaged"):
        return state.fingerprint != fp
    return True
```

```python
"""Notify the author that a package is waiting, or that a post is out.

The wording matters more here than in most tools.  A message that says
"published" when the article is only packaged is the worst possible bug in
a publishing pipeline: the author stops checking and the article never
goes out.  So each state has its own subject line, and the three of them
say three different things:

- ``packaged``  -- the package is on disk, a human still has to upload it
- ``drafted``   -- a draft exists on the platform, a human still has to publish it
- ``published`` -- it is out

The three backends are thin wrappers over one HTTP POST, so the shape of
each request can be checked without touching the network: the tests
replace ``_post()`` and look at the URL, the payload and the content type
that *would* have been sent.
"""

from __future__ import annotations

import json
import urllib.parse
import urllib.request

__all__ = ["STATUS_SUBJECTS", "build_message", "send"]

#: The subject prefix of each state.  The three of them are deliberately
#: different words: 「待上传」/「待发表」/「已发布」 say three different
#: things about what has happened to the article.
STATUS_SUBJECTS = {
    "packaged": "头条号待上传",
    "drafted": "头条号待发表",
    "published": "头条号已发布",
}


def build_message(status: str, title: str, detail: str = "") -> tuple[str, str]:
    """Return ``(subject, body)`` for one status.

    The state comes first in the subject: the subject is what the author
    reads in the notification list, and that is where "已发布" on an
    article that is still waiting to be uploaded does its damage.
    """
    subject_prefix = STATUS_SUBJECTS.get(status)
    if subject_prefix is None:
        raise ValueError("未知状态 {!r}".format(status))
    subject = "{}：{}".format(subject_prefix, title)
    body = "《{}》\n{}".format(title, subject_prefix)
    if detail:
        body += "\n" + detail
    return subject, body


def _post(url: str, *, data: bytes, content_type: str, timeout: int) -> None:
    """Send one POST request -- the only place in this module that opens
    a socket."""
    request = urllib.request.Request(url, data=data, method="POST")
    request.add_header("Content-Type", content_type)
    with urllib.request.urlopen(request, timeout=timeout) as response:
        response.read()


def _serverchan(key: str, subject: str, body: str, timeout: int) -> None:
    """Server酱: a form post, the key in the path."""
    payload = urllib.parse.urlencode({"title": subject, "desp": body}).encode("utf-8")
    _post(
        "https://sctapi.ftqq.com/{}.send".format(key),
        data=payload,
        content_type="application/x-www-form-urlencoded",
        timeout=timeout,
    )


def _wechat_work(key: str, subject: str, body: str, timeout: int) -> None:
    """企业微信群机器人: a JSON text message, the key in the query."""
    payload = json.dumps(
        {"msgtype": "text", "text": {"content": subject + "\n" + body}}
    ).encode("utf-8")
    _post(
        "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key={}".format(key),
        data=payload,
        content_type="application/json",
        timeout=timeout,
    )


def _webhook(key: str, subject: str, body: str, timeout: int) -> None:
    """A self-hosted webhook: the key is the whole URL."""
    payload = json.dumps({"title": subject, "body": body}).encode("utf-8")
    _post(key, data=payload, content_type="application/json", timeout=timeout)


_BACKENDS = {
    "serverchan": _serverchan,
    "wechat_work": _wechat_work,
    "webhook": _webhook,
}


def send(backend: str, key: str, subject: str, body: str, *, timeout: int = 15) -> None:
    """Push one notification through ``backend``.

    A notification failure is not a publishing failure: the caller decides
    whether to let the exception out.
    """
    handler = _BACKENDS.get(backend)
    if handler is None:
        raise ValueError("未知通知通道 {!r}".format(backend))
    handler(key, subject, body, timeout)
```

**这一节偏离了最初的骨架，七处：**

| # | 原骨架 | 改成 | 为什么 |
| --- | --- | --- | --- |
| 1 | 选项只挂在顶层解析器上 | 顶层与每个子命令各挂一份，缺省值用 `argparse.SUPPRESS` | 原骨架的选项只能写在命令名**前面**，而计划自己的测试把选项写在命令名**后面**——照骨架实现，那 8 条用例一条都跑不起来。`SUPPRESS` 也是必须的：不加它，子命令自己的缺省值会把命令名前面给的值盖掉（argparse 的子解析器是整体覆盖父命名空间的） |
| 2 | `main()` 让 argparse 自己 `sys.exit(2)` | 捕获 `SystemExit`：用法错误返回 `EXIT_USAGE`（1），`--help` 返回 `EXIT_OK` | 退出码是对外的契约，参数错是 1，不是 argparse 的 2 |
| 3 | 能力声明读不出来时落到通用兜底（3） | `_ConfigError` → 退出码 1 | 能力声明是**配置**不是内容：声明坏了是「配置错误」，不是「接口、写盘或母稿解析错误」 |

| 5 | 状态文件坏了就当空状态 | `_report_quarantine()` 打到 stderr，本次运行退出码是 3 | 空状态读起来就是「什么都没发过」——那正是把发过的文章再发一遍的起点。隔离出来的文件必须有出口，不能默默当空状态 |
| 6 | `status` 直接打印状态字符串 | 三种状态各带一句中文：`packaged（待人工上传）`／`drafted（待人工发表）`／`published（已发布）` | `drafted` 最容易被读成「还没发」——其实它是「草稿已在平台上，等人点发表」。读成「还没发」的人会把这篇重发一遍 |

```python
"""Command line entry point for the Toutiao adapter.

    scan              list the corpus and what can go to Toutiao
    convert <slug>   slice one post and write the publish package
    publish <slug>   package it, and upload once the API permission exists
    status            show the recorded state of every article

Every path these commands touch can be pointed somewhere else --
``--posts-dir``, ``--out-dir``, ``--outbox-dir``, ``--state-file`` -- so a
run never has to write into the repository.  The shared options work on
either side of the command name.

Two things this module refuses to do quietly:

- a corrupt state file is announced on stderr and turns the exit code
  into ``EXIT_ERROR``.  An unreadable state reads as "nothing was ever
  published", and that is exactly how an article gets published twice;
- a post that cannot go to Toutiao says why and exits with
  ``EXIT_INELIGIBLE`` instead of exiting successfully with nothing done.
"""

from __future__ import annotations

import argparse
import sys
from pathlib import Path

from .capability import default_capability_path, load_capability
from .contract import slice_post
from .mdparse import discover, discover_unsupported, load_post
from .notify import build_message, send
from .publish import PackageResult, write_package, write_snapshot
from .state import StateStore, fingerprint, needs_publish

__all__ = [
    "EXIT_ERROR", "EXIT_INELIGIBLE", "EXIT_OK", "EXIT_USAGE", "main",
]

#: The exit codes are the contract with whoever runs the command:
#: ``0`` success, ``1`` a bad argument or a bad configuration, ``2`` this
#: post is not eligible for Toutiao, ``3`` an interface, a write or a
#: source-parsing error.
EXIT_OK = 0
EXIT_USAGE = 1
EXIT_INELIGIBLE = 2
EXIT_ERROR = 3

_REPO_ROOT = Path(__file__).resolve().parents[2]
DEFAULT_POSTS_DIR = _REPO_ROOT / "source" / "_posts"
DEFAULT_OUT_DIR = _REPO_ROOT / "toutiao" / "out"
DEFAULT_OUTBOX_DIR = _REPO_ROOT / "publish" / "outbox"
DEFAULT_CAPABILITY = default_capability_path()
DEFAULT_STATE_FILE = _REPO_ROOT / "toutiao" / "out" / "state.json"

#: The value of every shared option when it was not given.  The options
#: are attached to the top-level parser *and* to every subcommand, so
#: they work before the command name as well as after it; argparse's
#: ``SUPPRESS`` keeps an option that was not given out of the namespace
#: entirely, because otherwise the subcommand's own default would
#: overwrite the value that was given before the command name.
_DEFAULTS = {
    "posts_dir": DEFAULT_POSTS_DIR,
    "out_dir": DEFAULT_OUT_DIR,
    "outbox_dir": DEFAULT_OUTBOX_DIR,
    "capability": DEFAULT_CAPABILITY,
    "state_file": DEFAULT_STATE_FILE,
    "source_url": "https://growdu.cn",
    "notify": "",
    "notify_key": "",
}

#: What each recorded status means.  ``drafted`` is the one that gets
#: misread: it means a draft exists on the platform and a human still has
#: to publish it -- not that the article was never sent.
_STATUS_TEXT = {
    "packaged": "packaged（待人工上传）",
    "drafted": "drafted（待人工发表）",
    "published": "published（已发布）",
}


class _ConfigError(Exception):
    """A configuration problem: a bad argument or a bad declaration.

    It is a separate type so that ``main()`` can tell it apart from a
    failure that happened while doing the work, and answer with the
    matching exit code.
    """


def _capability(path: Path):
    """Load the platform declaration, or refuse it as a configuration error.

    The declaration is configuration, not content: a broken TOML file is
    the exit code for a bad configuration (``EXIT_USAGE``), not the exit
    code for a broken post.
    """
    try:
        return load_capability(path)
    except (OSError, ValueError) as error:
        raise _ConfigError("能力声明读取失败：{}".format(error)) from error


def _inside(path: Path, root: Path) -> bool:
    """Is ``path`` inside ``root``?

    Used to keep a slug from pointing out of the posts directory: the
    command reads files, and it should only read the ones it was pointed
    at.
    """
    try:
        path.resolve().relative_to(root.resolve())
    except ValueError:
        return False
    return True


def _resolve_post(posts_dir: Path, slug: str):
    """Find one post by slug, tolerating a missing ``.md``.

    The slug is a path inside the site (``db/postgresql/demo``).  A slug
    that points outside the posts directory is not followed.
    """
    posts_dir = Path(posts_dir)
    if not posts_dir.is_dir():
        raise FileNotFoundError(
            "找不到 {}。先跑 `python3 tools/sync-hexo.py`（约 3 分钟）。".format(posts_dir)
        )
    direct = posts_dir / (slug + ".md")
    if not _inside(direct, posts_dir):
        return None
    if direct.is_file():
        return load_post(direct, posts_dir)
    matches = sorted(posts_dir.rglob(slug + ".md"))
    if matches:
        return load_post(matches[0], posts_dir)
    return None


def _report_quarantine(store: StateStore) -> bool:
    """Announce that the state file was broken and has been set aside.

    Returns ``True`` when a broken file was found.  A corrupt state file
    reads as "nothing was ever published" unless somebody says so, and
    that is how an article gets published twice: the run has to announce
    it, and the exit code has to say the run was not clean.
    """
    if store.quarantined is None:
        return False
    print(
        "状态文件损坏，已隔离到 {}，本次按空状态处理，"
        "发过的文章可能被再发一遍，请人工核对".format(store.quarantined),
        file=sys.stderr,
    )
    return True


def cmd_scan(args) -> int:
    """List the corpus and say which posts can go to Toutiao."""
    capability = _capability(args.capability)
    try:
        posts = discover(args.posts_dir)
    except FileNotFoundError as error:
        # 目录不存在：错误消息里已经带了「先跑 tools/sync-hexo.py」的指引。
        print("扫描失败：{}".format(error), file=sys.stderr)
        return EXIT_USAGE
    except ValueError as error:
        # 母稿坏掉（front matter 没闭合）：消息里带着出错的文件路径。
        print("扫描失败：{}".format(error), file=sys.stderr)
        return EXIT_ERROR
    ok = 0
    print("共 {} 篇\n".format(len(posts)))
    for post in posts:
        result = slice_post(post, capability.limits, args.source_url)
        if result.article is None:
            print("  ✗ {} —— {}".format(post.title, result.reason))
            continue
        notes = "；".join(result.article.notes)
        print("  ✓ {}{}".format(
            result.article.title,
            "（{}）".format(notes) if notes else "",
        ))
        ok += 1
    print("\n可发 {} / {} 篇".format(ok, len(posts)))

    # 母稿格式不支持的文件要显式说出来，不能静默漏掉。
    unsupported = discover_unsupported(args.posts_dir)
    if unsupported:
        print("\n另有 {} 个母稿格式不支持，已跳过：".format(len(unsupported)))
        for path in unsupported:
            print("  - {}".format(path))
    return EXIT_OK


def _convert(args) -> tuple:
    """Slice one post and write the package.  Returns ``(code, package)``.

    The package is ``None`` when there was nothing to package: the post
    does not exist, does not qualify, or is already packaged unchanged.
    """
    capability = _capability(args.capability)
    post = _resolve_post(args.posts_dir, args.slug)
    if post is None:
        print("找不到文章: {}".format(args.slug), file=sys.stderr)
        return EXIT_USAGE, None

    result = slice_post(post, capability.limits, args.source_url)
    if result.article is None:
        print("不能发到头条号：{}".format(result.reason), file=sys.stderr)
        return EXIT_INELIGIBLE, None

    # The fingerprint covers the Toutiao version, not the source post: only
    # a change in what actually gets published matters here.
    fp = fingerprint(result.article.body)
    store = StateStore(args.state_file)
    state = store.get(result.article.content_id)
    # 状态文件坏掉了：先说出来，再往下走。这一次的空状态不可信。
    broken = _report_quarantine(store)
    if not needs_publish(fp, state):
        print("内容未变，已有同样的发布包：{}".format(state.updated_at))
        return EXIT_OK, None

    try:
        package = write_package(
            result.article, capability, args.out_dir, args.posts_dir, args.source_url
        )
    except ValueError as error:
        print("不能发到头条号：{}".format(error), file=sys.stderr)
        return EXIT_INELIGIBLE, None

    snapshot = write_snapshot(package, args.outbox_dir)

    state.fingerprint = fp
    state.status = package.status
    state.package_dir = str(package.package_dir)
    store.save(result.article.content_id, state)

    print("标题：{}".format(package.title))
    print("字数：{}（上限 {}）".format(len(result.article.body), capability.limits.body_chars))
    print("图片：{} 张".format(len(result.article.images)))
    print("发布包：{}".format(package.package_dir))
    print("状态快照：{}".format(snapshot))
    for note in result.article.notes:
        print("  ! {}".format(note))
    # 出包本身成功了，但状态文件坏过：这次运行不算干净。
    return (EXIT_ERROR if broken else EXIT_OK), package


def cmd_convert(args) -> int:
    """Slice one post and write the package; nothing is uploaded."""
    code, _package = _convert(args)
    return code


def cmd_publish(args) -> int:
    """Package one post and notify about it.

    The API permission is not available yet, so this is the manual path.
    The distinction matters: the notification must say "待上传", not "已发布".
    """
    code, package = _convert(args)
    if package is None:
        # 没有出包：原因已经说过了，退出码也已经带上了。
        return code
    if args.notify and not args.notify_key:
        print(
            "指定了通知通道 {} 但没有通知凭据（--notify-key），没有发通知".format(
                args.notify
            ),
            file=sys.stderr,
        )
    elif args.notify:
        subject, body = build_message(
            "packaged",
            package.title,
            detail="发布包：{}".format(package.package_dir),
        )
        try:
            send(args.notify, args.notify_key, subject, body)
        except Exception as error:                  # noqa: BLE001 -- 通知失败不影响发布结果
            print("通知失败（不影响发布结果）：{}".format(error), file=sys.stderr)
    return code


def cmd_status(args) -> int:
    """Show the recorded state of every article."""
    store = StateStore(args.state_file)
    articles = store.all()
    if _report_quarantine(store):
        # 状态文件坏掉时的空状态是不可信的：说清楚，别让它读成「没发过」。
        print("状态文件损坏，本次按空状态处理，没有可显示的记录（详情见 stderr）")
        return EXIT_ERROR
    if not articles:
        print("还没有发过任何文章")
        return EXIT_OK
    for content_id in sorted(articles):
        entry = articles[content_id]
        status = entry.get("status") or "-"
        print("  {}  {}  {}".format(
            content_id,
            _STATUS_TEXT.get(status, status),
            entry.get("published_url") or entry.get("package_dir") or "",
        ))
    return EXIT_OK


def _add_common_options(parser: argparse.ArgumentParser) -> None:
    """Attach the options every command shares.

    ``default=argparse.SUPPRESS`` is what makes the option work on
    either side of the command name: an option that was not given stays
    out of the namespace, so the subcommand's default cannot overwrite
    the value that was given before the command name.
    """
    parser.add_argument("--posts-dir", type=Path, default=argparse.SUPPRESS,
                        help="母稿目录（默认：source/_posts）")
    parser.add_argument("--out-dir", type=Path, default=argparse.SUPPRESS,
                        help="发布包目录（默认：toutiao/out）")
    parser.add_argument("--outbox-dir", type=Path, default=argparse.SUPPRESS,
                        help="状态快照目录（默认：publish/outbox）")
    parser.add_argument("--capability", type=Path, default=argparse.SUPPRESS,
                        help="平台能力声明（默认：publish/capabilities/toutiao.toml）")
    parser.add_argument("--state-file", type=Path, default=argparse.SUPPRESS,
                        help="幂等状态文件（默认：toutiao/out/state.json）")
    parser.add_argument("--source-url", default=argparse.SUPPRESS,
                        help="正文末尾署名的站点地址")
    parser.add_argument("--notify", default=argparse.SUPPRESS,
                        help="通知通道：serverchan / wechat_work / webhook")
    parser.add_argument("--notify-key", default=argparse.SUPPRESS,
                        help="通知凭据")


def build_parser() -> argparse.ArgumentParser:
    """The argument parser, with the shared options on both sides."""
    parser = argparse.ArgumentParser(
        prog="toutiao", description="博客到头条号的切片与发布"
    )
    _add_common_options(parser)

    sub = parser.add_subparsers(dest="command", required=True)
    sub.add_parser("scan", help="盘点：哪些文章能发到头条号",
                   parents=[_common_parser()]).set_defaults(func=cmd_scan)

    convert = sub.add_parser("convert", help="切片并产出发布包（不调接口）",
                             parents=[_common_parser()])
    convert.add_argument("slug")
    convert.set_defaults(func=cmd_convert)

    publish = sub.add_parser("publish", help="产出发布包（API 权限开通后才会真正上传）",
                             parents=[_common_parser()])
    publish.add_argument("slug")
    publish.set_defaults(func=cmd_publish)

    sub.add_parser("status", help="查看状态",
                   parents=[_common_parser()]).set_defaults(func=cmd_status)
    return parser


def _common_parser() -> argparse.ArgumentParser:
    """A parser holding the shared options, for a subcommand to inherit."""
    common = argparse.ArgumentParser(add_help=False)
    _add_common_options(common)
    return common


def _fill_defaults(namespace: argparse.Namespace) -> None:
    """Put the default value in for every shared option that was not given."""
    for name, value in _DEFAULTS.items():
        if not hasattr(namespace, name):
            setattr(namespace, name, value)


def main(argv=None) -> int:
    """Run one command and return its exit code."""
    parser = build_parser()
    try:
        args = parser.parse_args(argv)
    except SystemExit as error:
        # argparse 已经把用法和错误打印出来了。``--help`` 退出码是 0，
        # 其余都是用法错误 —— 本命令约定用法错误是 1。
        return EXIT_OK if error.code == 0 else EXIT_USAGE
    _fill_defaults(args)
    try:
        return args.func(args)
    except _ConfigError as error:
        print(str(error), file=sys.stderr)
        return EXIT_USAGE
    except FileNotFoundError as error:
        print(str(error), file=sys.stderr)
        return EXIT_USAGE
    except Exception as error:                      # noqa: BLE001 -- 错误不吞
        print("失败：{}".format(error), file=sys.stderr)
        return EXIT_ERROR


if __name__ == "__main__":
    raise SystemExit(main())
