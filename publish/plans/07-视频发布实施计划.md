# 视频发布实施计划（视频号 · B站）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 AIV 产出的成片，变成视频号与 B 站上可发布的成品包（文案 + 封面 + 字幕 + 人工清单），并让 B 站这一侧具备用 arcopen 开放平台接口直接投稿的能力。

**Architecture:** 三层——成片合不合格归生产者（`aiv/pipeline/pyv/preflight.py`），这一期怎么自我介绍归内容侧（`aiv/publish/<EP>.json`，入库），平台怎么发归 adapter（`channels/`、`bilibili/`，平级独立、互不引用）。能力模型是 `publish/capabilities/*.toml`，两个 adapter 各自读各自那份；`publish/publishkit/` 尚未实现，本计划**不碰它**。

**Tech Stack:** Python 3.11（`tomllib` 读 TOML、`urllib` 发 HTTP、`hashlib`/`hmac` 算签名，零第三方依赖）、Pillow 9.4（封面裁切）、ffmpeg/ffprobe（抽帧与探测）、pytest（测试）。

**上游规格：** [../spec/07-视频发布契约.md](../spec/07-视频发布契约.md)（本文实现它）。

## Global Constraints

- **每个 commit 完成立即提交**；每个 commit 必须配套**单元测试 + 集成测试**，且在**只含该 commit 内容的干净检出**上独立跑通全部测试——不得引用后续 commit 才引入的文件。
- **入库的是事实，不入库的是产物。** 契约、发布元数据、能力声明、状态快照入库；成片、旁白、时间轴、发布包、凭据不入库。
- **不静默成功。** 每一个「成功」都必须是显式确认过的成功；平台报错、超时、审核不通过都要落到状态快照里，不许吞异常。
- **不静默截断。** 标题超限就报错让作者改元数据，不许悄悄裁一刀。
- **平台之间互不 import。** `channels/` 与 `bilibili/` 不互相引用，也不 import `publish/` 或 `weixin/` 的任何 Python 包；它们只读数据文件（`aiv/publish/<EP>.json` 与 `publish/capabilities/<platform>.toml`）。
- **凭据永不入库。** `channels/secrets.json`、`bilibili/secrets.json` 都在各自 `.gitignore` 里。
- **发布在本地执行。** 与公众号同因：平台侧有 IP / 凭据约束。
- **测试不依赖网络。** HTTP 一律用本地假 server（照 `weixin/tests/test_publish.py` 的手法）。
- **不碰 `weixin/` 与 `toutiao/`。** 那两个目录正在被别的会话并行开发，本计划的文件集合与它们完全不重叠。
- **纯数据 commit 的集成测试豁免。** 只新增数据文件（TOML / JSON）、没有任何生产代码消费者的 commit，
  它的「集成测试」就是**契约层校验测试本身**——数据文件与读它的断言同处一个 commit，
  在只含该 commit 内容的干净检出上独立跑通，等价于集成测试。
  没有下游消费者的 commit 不硬凑一个假集成测试。

### 视频平台限额（数值来源见规格 §5.2、§6.1.3、§6.3）

| 平台 | 标题 | 简介 | 话题 / 标签 | 封面 | 分区 |
| --- | --- | --- | --- | --- | --- |
| 视频号 | ≤ 22 字 | ≤ 1000 字 | ≤ 5 个，单个 ≤ 15 字 | 1080×608 与 1080×1920 各一张 | 无 |
| B站 | < 80 字（上限取 79） | < 250 字（上限取 249） | 逗号分隔总长 < 200 字（上限取 199） | ≥ 1146×717，jpeg/png ≤ 5MB | `tid` 必填 |

### 关键帧门槛

B站《文件上传预处理》要求「关键帧至少 10 秒一个」，即**间隔 ≤ 10 s**。
实测 EP01 最大间隔 7.167 s（合格）、EP02 最大间隔 10.417 s（**超标**）。
Task 3 在 `compose` 的编码参数里加 `-g 240`（24fps × 10 s）根治。

```python
契约层的数据文件也要有测试——平台规则变了改 TOML，
但「该有的键有没有」「数值还是不是当初核过的那几个」得有人盯着。

import tomllib
from datetime import date
from pathlib import Path

import pytest

REPO_ROOT = Path(__file__).resolve().parents[2]
CAPABILITIES = REPO_ROOT / "publish" / "capabilities"

PLATFORMS = ("channels", "bilibili")

TOP_KEYS = ("id", "name", "kind", "auth", "automation", "review",

AUTOMATION = ("manual", "api_draft", "api_publish")

def _load(platform: str) -> dict:
    path = CAPABILITIES / f"{platform}.toml"
    assert path.is_file(), f"缺少能力声明：{path}"
    return tomllib.loads(path.read_text(encoding="utf-8"))

    for key in TOP_KEYS:

    assert data["id"] == platform
    assert data["kind"] == "video"

    assert data["review"] in REVIEW

        assert limits[key] > 0

    limits = _load(platform)["limits"]

            f"{platform}.toml 的 limits.{key} 变成了 {limits[key]}，"
            f"当初核过的是 {value}"

@pytest.mark.parametrize("platform", PLATFORMS)
def test_the_pinned_media_numbers_still_hold(platform):
    """[media] 段的关键数值也钉住。

    「键在不在」只是一半——键在但数值被人改掉，闸还在，只是判的是另一个标准。
    变异测试证明过这一点：把 max_duration_s 改回 18000、把 require_faststart 改 false、
    把 max_video_bitrate 改大，整套测试照样全绿。
    """
    media = _load(platform)["media"]
    # 键集合必须**完全相等**：多出一个键就是凭空多一道闸——规格 §5.2 里视频号
    # 明确为「—」的项（比如 max_video_bitrate），加上去就多判一道。
    assert set(media) == set(MEDIA_PINNED[platform]), (
        f"{platform}.toml 的 media 键集合变了："
        f"多出 {sorted(set(media) - set(MEDIA_PINNED[platform]))}，"
        f"缺少 {sorted(set(MEDIA_PINNED[platform]) - set(media))}"
    )
    for key, value in MEDIA_PINNED[platform].items():
        assert media[key] == value, (
            f"{platform}.toml 的 media.{key} 变成了 {media[key]}，"
            f"当初核过的是 {value}"
        )


@pytest.mark.parametrize("platform", PLATFORMS)
def test_the_pinned_switches_still_hold(platform):

    data = _load(platform)
    assert data["requires_certification"] is False
    assert data["requires_min_followers"] == 0

    assert adapter["package"] == platform
    assert adapter["command"][0] == "python3"
    assert adapter["command"][1] == "-m"
    assert adapter["command"][2] == f"{platform}.cli"


def test_bilibili_keeps_the_keyframe_rule():
    """B站的「关键帧至少 10 秒一个」是硬门槛，少这条键就等于少一道闸。"""
    media = _load("bilibili")["media"]
    assert media["max_keyframe_gap_s"] == 10


def test_channels_has_no_keyframe_rule():
    """视频号没这条要求，别把它也加上——加了会凭空多一道闸。"""
    media = _load("channels")["media"]
    assert "max_keyframe_gap_s" not in media


def test_top_level_key_sets_are_identical():
    """两个平台的顶层键必须完全一样。

    不对称的键集合意味着「有一个平台少了一道闸」。
    少一道闸比闸判错更糟——它不报错，只是静悄悄地不生效。

    bilibili = set(_load("bilibili"))
    assert channels == bilibili, (
        f"两个平台的顶层键不一致："
        f"只有视频号有 {sorted(channels - bilibili)}，"
        f"只有B站有 {sorted(bilibili - channels)}"

    for platform in PLATFORMS:

def test_verified_is_a_real_date():
    """`verified` = 这些平台数字最后对着平台文档复核过的日期。

    要真的是一个存在的日子——光对上正则的 `2026-13-45` 是蒙混过关。

    for platform in PLATFORMS:
        value = _load(platform)["verified"]
        try:
            date.fromisoformat(value)
        except ValueError:

                f"{platform}.toml 的 verified={value!r} 不是一个存在的日期"

def test_both_platforms_keep_the_audio_gates():

    视频号曾经漏掉这两道闸——闸缺席不报错，只是静悄悄地不生效。
    """

    assert channels["max_audio_channels"] == 2

        assert _load(platform)["media"]["require_video_codec"] == "h264"
```

```python
"""成片技术门槛预检。

预检要能**抓得出问题**，所以测试里现造一段有问题的视频，
而不是只测一段好视频通过。

成片本身不入库（`aiv/out/` 是 gitignore 的产物目录），
所以这里用 ffmpeg 现场生成 12 秒的小视频——
既不把媒体塞回仓库，又能在干净检出上跑通。
"""
import struct
import subprocess

from pyv import preflight


def _make_video(path, seconds=12, gop=None, faststart=False):
    """现场造一段小视频。

    gop 决定关键帧间隔，faststart 决定 moov 排不排在 mdat 前面。
    """
    cmd = [
        "ffmpeg", "-y", "-f", "lavfi", "-i",
        f"testsrc=size=320x180:rate=24:duration={seconds}",
        "-c:v", "libx264", "-preset", "ultrafast", "-pix_fmt", "yuv420p",
    ]
    if gop is not None:
        cmd += ["-g", str(gop)]
    if faststart:
        cmd += ["-movflags", "+faststart"]
    cmd += [str(path)]
    proc = subprocess.run(cmd, capture_output=True, text=True)
    assert proc.returncode == 0, proc.stderr[-500:]
    return path


def test_probe_reads_the_technical_parameters(tmp_path):
    video = _make_video(tmp_path / "probe.mp4", seconds=2, gop=48)
    info = preflight.probe(video)
    assert info.width == 320
    assert info.height == 180
    assert round(info.fps) == 24
    assert 1.5 < info.duration < 2.5
    assert info.pix_fmt == "yuv420p"

def test_the_box_parser_handles_a_64_bit_extended_size(tmp_path):
    """盒子超过 4 GiB 时必须用 64 位扩展长度。

    扩展形式的盒头是 16 字节（8 字节头 + 8 字节扩展长度）——
    按 8 字节跳会把下一个盒头错位 8 字节，读到垃圾盒子，
    faststart 的结论就跟着错（真 faststart 的文件会被判成不是）。
    """
    def box(kind: bytes, payload: bytes) -> bytes:
        return struct.pack(">I", 8 + len(payload)) + kind + payload

    def box64(kind: bytes, payload: bytes) -> bytes:
        return (struct.pack(">I", 1) + kind
                + struct.pack(">Q", 16 + len(payload)) + payload)

    path = tmp_path / "wide.mp4"
    # ftyp + free(64 位扩展) + moov + mdat —— moov 在 mdat 之前，是 faststart
    path.write_bytes(
        box(b"ftyp", b"") + box64(b"free", b"\x00" * 64)
        + box(b"moov", b"") + box(b"mdat", b"\x00" * 16)
    )
    assert preflight._top_level_boxes(path) == ["ftyp", "free", "moov", "mdat"]
    assert preflight.has_faststart(path) is True


def test_a_non_h264_video_fails_the_codec_rule():
    """平台只要 H.264——HEVC 在部分安卓机上放不出来。

    这里直接造 VideoInfo，不去编 HEVC：那台机器的 ffmpeg 未必带 libx265。
    """
    info = preflight.VideoInfo(
        width=1920, height=1080, fps=24.0, duration=38.0,
        video_codec="hevc", pix_fmt="yuv420p", audio_codec="aac",
        sample_rate=48000, channels=2, audio_bitrate=192000,

    )

    assert any(f.rule_id == "preflight.codec" for f in findings)

    assert any(f.rule_id == "preflight.video-bitrate" for f in findings)
```

```python
"""每期的发布元数据：这一期在各个平台怎么自我介绍。

**入库的是事实**：元数据要评审、要版本化，所以进 `aiv/publish/<EP>.json`。
**不入库的是产物**：成片、发布包都留本机。

元数据只回答「这一期叫什么、封面取哪一帧、两个平台的文案是什么」，
不回答「怎么发」——那是 adapter 的事。

平台段落里**缺一个字段就报错**，绝不静默补默认值：
补出来的默认值看起来能用，但它会让「作者忘了写」变得无声无息。
"""
from __future__ import annotations

import json
import tomllib
from dataclasses import dataclass
from pathlib import Path

# aiv/ 是 pipeline/ 的上一级：pyv/epmeta.py → pyv → pipeline → aiv
AIV_ROOT = Path(__file__).resolve().parents[2]
REPO_ROOT = AIV_ROOT.parent
PUBLISH_DIR = AIV_ROOT / "publish"
# 能力声明是契约层的数据文件。pyv 只**读**它，不 import 契约层的任何包。
CAPABILITIES_DIR = REPO_ROOT / "publish" / "capabilities"

ERROR = "error"
WARNING = "warning"

# 每个平台：必填字段、文本限额在 TOML 里的键名、列表限额、整数字段
PLATFORM_SPECS = {
    "channels": {
        "required": ("title", "description", "topics"),
        "text_limits": {"title": "title_chars", "description": "description_chars"},
        "list_limits": {"topics": ("topics_max", "topic_chars")},
        "int_fields": (),
    },
    "bilibili": {
        "required": ("title", "description", "tags", "tid", "copyright", "no_reprint"),
        "text_limits": {"title": "title_chars", "description": "description_chars"},
        "list_limits": {"tags": ("tags_chars", "tag_chars")},
        "int_fields": ("tid", "copyright", "no_reprint"),
    },
}


class MetaError(ValueError):
    """发布元数据本身坏了（文件读不了、不是对象）。"""


@dataclass(frozen=True)
class Finding:
    """一条检查结果。"""

    rule_id: str
    level: str
    message: str
    target: str = ""

    def __str__(self) -> str:
        where = f"[{self.target}] " if self.target else ""
        return f"{where}{self.rule_id} {self.message}"


@dataclass(frozen=True)
class EpisodeMeta:
    """一期的发布元数据。"""

    episode: str
    title: str
    cover_at: float
    url: str = ""
    channels: dict | None = None
    bilibili: dict | None = None
    path: Path | None = None

    def platform(self, name: str) -> dict | None:
        """某个平台的文案段落；没配就是 None（那一期不发这个平台）。"""
        if name not in PLATFORM_SPECS:
            raise KeyError(name)
        return getattr(self, name)


def meta_path(episode: str, root: Path | None = None) -> Path:
    base = Path(root) if root else PUBLISH_DIR
    return base / f"{episode}.json"


def load_meta(episode: str, root: Path | None = None) -> EpisodeMeta:
    path = meta_path(episode, root)
    if not path.is_file():
        raise MetaError(f"发布元数据不存在：{path}")
    raw = json.loads(path.read_text(encoding="utf-8"))
    if not isinstance(raw, dict):
        raise MetaError(f"发布元数据必须是对象：{path}")
    channels = raw.get("channels")
    bilibili = raw.get("bilibili")
    return EpisodeMeta(
        episode=str(raw.get("episode", "")),
        title=str(raw.get("title", "")),
        cover_at=float(raw.get("cover_at", -1.0)),
        url=str(raw.get("url", "")),
        channels=channels if isinstance(channels, dict) else None,
        bilibili=bilibili if isinstance(bilibili, dict) else None,
        path=path,
    )


def load_limits(platform: str, capabilities_dir: Path | None = None) -> dict:
    """读平台能力声明的 [limits] 段。"""
    base = Path(capabilities_dir) if capabilities_dir else CAPABILITIES_DIR
    path = base / f"{platform}.toml"
    if not path.is_file():
        raise MetaError(f"能力声明不存在：{path}")
    data = tomllib.loads(path.read_text(encoding="utf-8"))
    return data.get("limits", {}) or {}


def check_meta(meta: EpisodeMeta, contract_episode: str | None = None,
               duration: float | None = None,
               limits_loader=load_limits) -> list[Finding]:
    """校验一期元数据。返回的 Finding 里 level=error 的必须先改。"""
    findings: list[Finding] = []
    target = meta.episode or (meta.path.name if meta.path else "")

    if not meta.episode:
        findings.append(Finding("epmeta.episode", ERROR, "缺少 episode", target))
    elif contract_episode and meta.episode != contract_episode:
        findings.append(Finding(
            "epmeta.episode", ERROR,
            f"元数据的 episode 是 {meta.episode!r}，契约里是 {contract_episode!r}",
            target))

    if not meta.title:
        findings.append(Finding("epmeta.required", ERROR, "缺少 title", target))

    if meta.cover_at < 0:
        findings.append(Finding("epmeta.cover-at", ERROR,
                                "缺少 cover_at 或取值为负", target))
    elif duration is not None and meta.cover_at > duration:
        findings.append(Finding(
            "epmeta.cover-at", ERROR,
            f"cover_at {meta.cover_at:.3f}s 超出成片时长 {duration:.3f}s", target))

    for platform, spec in PLATFORM_SPECS.items():
        section = meta.platform(platform)
        if section is None:
            findings.append(Finding(
                "epmeta.platform-missing", WARNING,
                f"没有配置 {platform} 的文案，这一期不发这个平台", target))
            continue
        findings.extend(
            _check_platform(platform, section, spec, limits_loader, target))
    return findings


def _check_platform(platform, section, spec, limits_loader, target):
    findings: list[Finding] = []
    for key in spec["required"]:
        if key not in section or section[key] in (None, ""):
            findings.append(Finding(
                "epmeta.platform-required", ERROR,
                f"{platform} 的文案缺少 {key!r}", target))
    if findings:
        # 缺字段的时候先报缺字段，别同时报出一堆长度错误。
        return findings

    try:
        limits = limits_loader(platform)
    except MetaError as exc:
        findings.append(Finding("epmeta.limits", ERROR, str(exc), target))
        return findings

    for field_name, limit_key in spec["text_limits"].items():
        limit = limits.get(limit_key)
        if limit is None:
            findings.append(Finding(
                "epmeta.limits", ERROR,
                f"{platform} 的能力声明缺少 limits.{limit_key}", target))
            continue
        value = str(section.get(field_name, ""))
        if len(value) > limit:
            findings.append(Finding(
                "epmeta.text-limit", ERROR,
                f"{platform} 的 {field_name} 有 {len(value)} 字，超过上限 {limit}",
                target))

    for field_name, (total_key, item_key) in spec["list_limits"].items():
        total_limit = limits.get(total_key)
        item_limit = limits.get(item_key)
        if total_limit is None or item_limit is None:
            findings.append(Finding(
                "epmeta.limits", ERROR,
                f"{platform} 的能力声明缺少 {total_key} / {item_key}", target))
            continue
        items = section.get(field_name) or []
        if not isinstance(items, list):
            findings.append(Finding(
                "epmeta.platform-required", ERROR,
                f"{platform} 的 {field_name} 必须是列表", target))
            continue
        if len(items) > total_limit:
            findings.append(Finding(
                "epmeta.list-limit", ERROR,
                f"{platform} 的 {field_name} 有 {len(items)} 项，超过上限 {total_limit}",
                target))
        for item in items:
            if len(str(item)) > item_limit:
                findings.append(Finding(
                    "epmeta.list-limit", ERROR,
                    f"{platform} 的 {field_name} 里 {item!r} 有 {len(str(item))} 字，"
                    f"超过单项上限 {item_limit}", target))

    for field_name in spec["int_fields"]:
        value = section.get(field_name)
        if not isinstance(value, int) or isinstance(value, bool):
            findings.append(Finding(
                "epmeta.int-field", ERROR,
                f"{platform} 的 {field_name} 必须是整数，实际 {value!r}", target))
    return findings
```

```python
"""成片技术门槛预检：这条片子能不能传上去。

「成片合不合格」是**生产者**的责任，不是平台的。
两个平台各判一遍会出现两个结论，门槛数字也会漂。
所以判定只有这一份，adapter 拿结果，不自己判。

硬门槛（平台会拒）→ 报错并给出修复命令；
建议门槛（平台接受但会降质）→ 告警，继续出包。
"""
from __future__ import annotations

import hashlib
import json
import subprocess
import tomllib
from dataclasses import dataclass
from fractions import Fraction
from pathlib import Path

from pyv.epmeta import CAPABILITIES_DIR, Finding, MetaError

ERROR = "error"
WARNING = "warning"


@dataclass(frozen=True)
class VideoInfo:
    """一条视频的技术参数。"""

    width: int
    height: int
    fps: float
    duration: float
    video_codec: str
    pix_fmt: str
    audio_codec: str
    sample_rate: int
    channels: int
    audio_bitrate: int
    video_bitrate: int
    size_bytes: int
    keyframe_gaps: tuple[float, ...] = ()
    faststart: bool = False

    @property
    def max_keyframe_gap(self) -> float:
        return max(self.keyframe_gaps) if self.keyframe_gaps else 0.0

    @property
    def avg_bitrate(self) -> int:
        """平均码率（bps）。

        ffprobe 的流级 `bit_rate` 常常缺，退回「文件大小 × 8 ÷ 时长」——
        这个值永远算得出来，也是判定峰值码率门槛时的代理。
        """
        if self.duration <= 0:
            return 0
        return int(self.size_bytes * 8 / self.duration)


def _run_ffprobe(args: list[str]) -> str:
    proc = subprocess.run(["ffprobe", "-v", "error", *args],
                          capture_output=True, text=True)
    if proc.returncode != 0:
        raise RuntimeError(f"ffprobe 失败：{(proc.stderr or '')[-500:]}")
    return proc.stdout


def keyframe_gaps(video: str | Path) -> tuple[float, ...]:
    """相邻关键帧之间的间隔（秒），末尾还接一段到片尾。

    B站《文件上传预处理》要求「视频关键帧至少 10 秒一个」，
    也就是**间隔不得超过 10 秒**。
    """
    out = _run_ffprobe([
        "-select_streams", "v:0", "-skip_frame", "nokey",
        "-show_entries", "frame=pts_time", "-of", "csv=p=0", str(video),
    ])
    times: list[float] = []
    for line in out.splitlines():
        line = line.strip().rstrip(",")
        if not line or line == "N/A":
            continue
        try:
            times.append(float(line))
        except ValueError:
            continue
    times.sort()
    gaps = [round(b - a, 3) for a, b in zip(times, times[1:])]
    if times:
        # 这里不能调 probe()：probe() 会反过来调 keyframe_gaps()，两者互递归
        # 会一路 RecursionError 炸到底。时长单独取。
        tail = round(_probe_duration(video) - times[-1], 3)
        if tail > 0:
            gaps.append(tail)
    return tuple(gaps)


def _probe_duration(video: str | Path) -> float:
    """只要时长。

    单独拎出来，是为了断开 `probe()` ↔ `keyframe_gaps()` 的互递归：
    probe() 要调 keyframe_gaps()，keyframe_gaps() 就不能再调 probe()。
    """
    raw = _run_ffprobe(["-of", "json", "-show_format", str(video)])
    data = json.loads(raw or "{}")
    return float(data.get("format", {}).get("duration", 0.0))


def _parse_fps(value: str) -> float:
    try:
        return float(Fraction(value))
    except (ValueError, ZeroDivisionError):
        return 0.0


def probe(video: str | Path) -> VideoInfo:
    """用 ffprobe 读一条视频的技术参数。"""
    path = Path(video)
    if not path.is_file():
        raise FileNotFoundError(f"成片不存在：{path}")
    raw = _run_ffprobe(["-of", "json", "-show_format", "-show_streams", str(path)])
    data = json.loads(raw or "{}")
    streams = data.get("streams", [])
    video_stream = next((s for s in streams if s.get("codec_type") == "video"), None)
    audio_stream = next((s for s in streams if s.get("codec_type") == "audio"), None)
    if video_stream is None:
        raise RuntimeError(f"这不是一条视频：{path}")
    fmt = data.get("format", {})
    return VideoInfo(
        width=int(video_stream.get("width", 0)),
        height=int(video_stream.get("height", 0)),
        fps=_parse_fps(video_stream.get("r_frame_rate", "0/1")),
        duration=float(fmt.get("duration", 0.0)),
        video_codec=str(video_stream.get("codec_name", "")),
        pix_fmt=str(video_stream.get("pix_fmt", "")),
        audio_codec=str((audio_stream or {}).get("codec_name", "")),
        sample_rate=int((audio_stream or {}).get("sample_rate", 0)),
        channels=int((audio_stream or {}).get("channels", 0)),
        audio_bitrate=int((audio_stream or {}).get("bit_rate", 0)),
        video_bitrate=int(video_stream.get("bit_rate", 0)),
        size_bytes=int(fmt.get("size", path.stat().st_size)),
        keyframe_gaps=keyframe_gaps(path),
        faststart=has_faststart(path),
    )


def _top_level_boxes(path: Path) -> list[str]:
    """按文件顺序读出 mp4 顶层盒子的类型。

    mp4 是「盒子套盒子」：每个顶层盒子头 8 字节 = 4 字节长度（含头）+ 4 字节类型。
    长度 1 表示真实长度在后面 8 字节（64 位扩展），此时盒头共 **16 字节**；
    长度 0 表示这个盒子到文件尾。

    盒头长度必须记清楚：按 8 字节跳会把下一个盒头**错位 8 字节**，读到的是垃圾盒子——
    faststart 的结论就跟着错（一个真 faststart 的文件会被判成不是）。
    """
    boxes: list[str] = []
    with open(path, "rb") as handle:
        while True:
            header = handle.read(8)
            if len(header) < 8:
                break
            size = int.from_bytes(header[:4], "big")
            box = header[4:8].decode("latin-1")
            header_size = 8
            if size == 1:
                extra = handle.read(8)
                if len(extra) < 8:
                    break
                size = int.from_bytes(extra, "big")
                header_size = 16
            boxes.append(box)
            if size == 0 or size < header_size:
                break
            handle.seek(size - header_size, 1)
    return boxes


def has_faststart(video: str | Path) -> bool:
    """moov 是否排在 mdat 之前。

    ffprobe 报不出这个——它只解封装，不报盒子在文件里的位置。
    视频号要求 moov 前置：不前置的片子，手机端要等整片下完才起播。
    """
    boxes = _top_level_boxes(Path(video))
    if "moov" not in boxes:
        return False
    if "mdat" not in boxes:
        return True
    return boxes.index("moov") < boxes.index("mdat")


def _load_media(platform: str, capabilities_dir: Path | None) -> dict:
    base = Path(capabilities_dir) if capabilities_dir else CAPABILITIES_DIR
    path = base / f"{platform}.toml"
    if not path.is_file():
        raise MetaError(f"能力声明不存在：{path}")
    data = tomllib.loads(path.read_text(encoding="utf-8"))
    return data.get("media", {}) or {}


def check_video(info: VideoInfo, platform: str,
                capabilities_dir: Path | None = None) -> list[Finding]:
    """按平台能力声明判定一条成片。"""
    media = _load_media(platform, capabilities_dir)
    findings: list[Finding] = []
    target = platform

    def fail(rule_id, message):
        findings.append(Finding(rule_id, ERROR, message, target))

    if "min_width" in media and info.width < media["min_width"]:
        fail("preflight.resolution",
             f"宽度 {info.width} 低于平台要求的 {media['min_width']}")
    if "min_height" in media and info.height < media["min_height"]:
        fail("preflight.resolution",
             f"高度 {info.height} 低于平台要求的 {media['min_height']}")
    if "max_width" in media and info.width > media["max_width"]:
        fail("preflight.resolution",
             f"宽度 {info.width} 超过平台上限 {media['max_width']}")
    if "max_height" in media and info.height > media["max_height"]:
        fail("preflight.resolution",
             f"高度 {info.height} 超过平台上限 {media['max_height']}")
    if "max_fps" in media and info.fps > media["max_fps"] + 0.01:
        fail("preflight.fps",
             f"帧率 {info.fps:.3f} 超过平台上限 {media['max_fps']}")
    if "require_pix_fmt" in media and info.pix_fmt != media["require_pix_fmt"]:
        fail("preflight.pix-fmt",
             f"像素格式 {info.pix_fmt!r}，平台要求 {media['require_pix_fmt']!r}")
    if "max_duration_s" in media and info.duration > media["max_duration_s"]:
        fail("preflight.duration",
             f"时长 {info.duration:.1f}s 超过平台上限 {media['max_duration_s']}s")
    if "max_bytes" in media and info.size_bytes > media["max_bytes"]:
        fail("preflight.size",
             f"文件 {info.size_bytes} 字节，超过平台上限 {media['max_bytes']}")
    if "max_audio_bitrate" in media and info.audio_bitrate > media["max_audio_bitrate"]:
        fail("preflight.audio",
             f"音频码率 {info.audio_bitrate} 超过平台上限 {media['max_audio_bitrate']}")
    if "max_audio_channels" in media and info.channels > media["max_audio_channels"]:
        fail("preflight.audio",
             f"声道数 {info.channels} 超过平台上限 {media['max_audio_channels']}")
    if "max_sample_rate" in media and info.sample_rate > media["max_sample_rate"]:
        fail("preflight.audio",
             f"采样率 {info.sample_rate} 超过平台上限 {media['max_sample_rate']}")
    if "require_video_codec" in media and info.video_codec != media["require_video_codec"]:
        fail("preflight.codec",
             f"视频编码 {info.video_codec!r}，平台要求 {media['require_video_codec']!r}。"
             f"修复：ffmpeg -i <成片> -c:v libx264 -preset medium -crf 18 "
             f"-c:a aac -b:a 192k -ar 48000 -ac 2 -movflags +faststart <输出>")
    if "require_faststart" in media and media["require_faststart"] and not info.faststart:
        fail("preflight.faststart",
             "moov 不在 mdat 之前（没有 faststart），平台要等整片下完才起播。"
             "修复：ffmpeg -i <成片> -c copy -movflags +faststart <输出>")
    if "max_video_bitrate" in media:
        bitrate = max(info.video_bitrate, info.avg_bitrate)
        if bitrate > media["max_video_bitrate"]:
            fail("preflight.video-bitrate",
                 f"视频码率 {bitrate} bps 超过平台上限 {media['max_video_bitrate']} bps")
    if "max_keyframe_gap_s" in media and info.max_keyframe_gap > media["max_keyframe_gap_s"]:
        fail("preflight.keyframe",
             f"关键帧最大间隔 {info.max_keyframe_gap:.3f}s 超过 "
             f"{media['max_keyframe_gap_s']}s。修复："
             f"ffmpeg -i <成片> -c:v libx264 -preset medium -crf 18 -g 240 "
             f"-c:a aac -b:a 192k -ar 48000 -ac 2 -movflags +faststart <输出>")
    return findings


def file_sha256(path: str | Path) -> str:
    """成片的指纹。成片变了就重新出包。"""
    digest = hashlib.sha256()
    with open(path, "rb") as handle:
        for chunk in iter(lambda: handle.read(1024 * 1024), b""):
            digest.update(chunk)
    return digest.hexdigest()
```

```python
def cmd_publish(args: argparse.Namespace) -> int:
    """检查一期的发布元数据与成片技术门槛。

    不发任何请求、不写任何文件——这是给作者看的体检报告。
    """
    from pyv import epmeta, preflight

    try:
        meta = epmeta.load_meta(args.episode)
    except epmeta.MetaError as exc:
        print(f"ERROR {exc}", file=sys.stderr)
        return 1

    contract_episode = ""
    contract_path = epmeta.AIV_ROOT / "contracts" / f"{args.episode}.json"
    if contract_path.is_file():
        from pyv import contract as contract_mod
        contract_episode = contract_mod.load_contract(contract_path).episode

    video = epmeta.AIV_ROOT / "out" / f"{args.episode}.mp4"
    info = None
    duration = None
    if video.is_file():
        info = preflight.probe(video)
        duration = info.duration
    else:
        print(f"WARNING preflight.video 成片不在本机（{video}），"
              f"跳过技术门槛检查")

    findings = epmeta.check_meta(
        meta, contract_episode=contract_episode, duration=duration)
    if info is not None:
        for platform in ("channels", "bilibili"):
            findings.extend(preflight.check_video(info, platform))

    for finding in findings:
        marker = "ERROR  " if finding.level == epmeta.ERROR else "WARNING"
        print(f"{marker} {finding.rule_id}  {finding.message}")
    print(f"元数据 {meta.path}；{len(findings)} 个问题")
    if any(f.level == epmeta.ERROR for f in findings):
        sys.stdout.flush()
        print("FAIL 有硬约束违规，发布前必须改", file=sys.stderr)
        return 1
    print("OK 发布前检查通过")
    return 0
```

```python
# 也就是间隔 ≤ 10 秒。我们的成片由分段渲染再拼成，段边界会拉长间隔

KEYFRAME_INTERVAL = FPS_BASE * 10   # 240 帧 = 10 秒

    """视频编码参数。两条编码路径共用它，别各写一份。"""
    return [
        "-c:v", "libx264", "-preset", "medium", "-crf", "18",
        "-pix_fmt", "yuv420p", "-r", str(fps),
```

```python
def _mux_cmd(silent: Path, out_path: Path, storyboard: Storyboard,
             sources: list[tuple[Path, float, str]]) -> list[str]:
    """拼出「视频 + 多路音频」的 ffmpeg 命令。

    sources 每项是 (音频文件, 延迟秒数, 滤波链)；滤波链是这一路的完整
    音频处理（音量也在里面）。所有音频都在同一个 filter_complex 里用
    adelay 对齐后 amix（同一路流不能同时用 -af 与 -filter_complex）。
    """
    fps = storyboard.video.fps
    duration = storyboard.duration
    cmd = ["ffmpeg", "-y", "-i", str(silent)]
    for path, _, _ in sources:
        cmd += ["-i", str(path)]

    chains = []
    labels = []
    for index, (_, delay, chain) in enumerate(sources):
        ms = int(round(delay * 1000))
        chains.append(
            f"[{index + 1}:a]aresample=48000,{chain},adelay={ms}:all=1[a{index}]"
        )
        labels.append(f"[a{index}]")
    chains.append(
        "".join(labels)
        + f"amix=inputs={len(sources)}:duration=longest:"
        "dropout_transition=0:normalize=0,apad[mix]"
    )

    cmd += [
        "-filter_complex", ";".join(chains),
        "-map", "0:v:0", "-map", "[mix]",
        *encode_args(fps),
    ]
    cmd += ["-c:a", "aac", "-b:a", "192k", "-ar", "48000", "-ac", "2"]
    cmd += ["-t", f"{duration:.3f}", "-movflags", "+faststart", str(out_path)]
    return cmd
```

```python
"""视频号版的文案。

元数据里已经写好了这一期在视频号上怎么自我介绍（`aiv/publish/<EP>.json`），
这里只做两件事：把它取出来、把它摆成发布包里的那几个文件。

不静默截断：超限由 `pyv.epmeta` 报错让作者改元数据，不在这里悄悄裁一刀。
"""
from __future__ import annotations

from dataclasses import dataclass

from pyv import epmeta


@dataclass(frozen=True)
class ChannelsCopy:
    """一期在视频号上的文案。"""

    title: str
    description: str
    topics: tuple[str, ...]
    cover_at: float
    url: str = ""


def slice_copy(meta: epmeta.EpisodeMeta) -> ChannelsCopy:
    """取出视频号版的文案。没配这一段就是配置错误。"""
    section = meta.platform("channels")
    if section is None:
        raise epmeta.MetaError(
            f"这一期没有配置视频号文案：{meta.episode}")
    return ChannelsCopy(
        title=str(section.get("title", "")),
        description=str(section.get("description", "")),
        topics=tuple(str(t) for t in (section.get("topics") or [])),
        cover_at=meta.cover_at,
        url=meta.url,
    )


def topics_line(topics: tuple[str, ...]) -> str:
    """话题拼成一行：#数据库 #内核"""
    return " ".join(f"#{topic}" for topic in topics)
```

```python
**为什么出两张。** 公开口径对「横版视频的封面会不会被裁」互相矛盾：
一说视频号封面比例是竖版 6:7（1080×1260）与横版 16:9（1080×608），
一说朋友圈卡片、聊天窗口、主页、发现页全部以 9:16 竖屏展示封面，
传 16:9 会被裁左右或加黑边。

既然是人工发布，两张都给、让人在真实界面上看一眼，
比赌哪个口径对更省事（规格 §6.1.2）。
"""
from __future__ import annotations

import subprocess
from pathlib import Path

from PIL import Image

# 视频号封面尺寸
COVER_16X9 = (1080, 608)
COVER_9X16 = (1080, 1920)
# 品牌背景是白色，留白就用白色，视觉上不突兀。
PADDING_COLOR = (255, 255, 255)


def extract_frame(video: str | Path, at: float, out_path: str | Path) -> Path:
    """抽出某一时刻的一帧。"""
    out = Path(out_path)
    out.parent.mkdir(parents=True, exist_ok=True)
    proc = subprocess.run([
        "ffmpeg", "-y", "-ss", f"{at:.3f}", "-i", str(video),
        "-frames:v", "1", str(out),
    ], capture_output=True, text=True)
    if proc.returncode != 0:
        raise RuntimeError(f"抽帧失败：{(proc.stderr or '')[-400:]}")
    return out


def make_covers(video: str | Path, at: float, out_dir: str | Path) -> dict[str, Path]:
    """抽一帧，裁成横版与竖框版两张封面。"""
    out_dir = Path(out_dir)
    out_dir.mkdir(parents=True, exist_ok=True)
    raw = extract_frame(video, at, out_dir / "_frame.png")
    with Image.open(raw) as frame:
        image = frame.convert("RGB")
        wide = image.resize(COVER_16X9, Image.LANCZOS)
        wide_path = out_dir / "cover-16x9.jpg"
        wide.save(wide_path, quality=92)

        canvas = Image.new("RGB", COVER_9X16, PADDING_COLOR)
        canvas.paste(wide, (0, (COVER_9X16[1] - COVER_16X9[1]) // 2))
        tall_path = out_dir / "cover-9x16.jpg"
        canvas.save(tall_path, quality=92)
    raw.unlink(missing_ok=True)
    return {"16x9": wide_path, "9x16": tall_path}
```

- [ ] **Step 6: 写 `channels/state.py`**

```python
"""视频号的幂等状态。

沿用 `weixin/wechat/state.py` 的形状，但键换成了视频的东西：

- 内容层键是**成片的 sha256**——成片重出了就得重新出包
  （文案没变但成片变了很常见：重混音、修关键帧）。
- 视频号没有 API，拿不到平台返回的 id，所以对象层是空的，
  发布靠 `mark published` 显式回填。

状态文件留在 `channels/out/` 下，永不入库。
"""
from __future__ import annotations

import json
from dataclasses import asdict, dataclass
from datetime import datetime, timezone
from pathlib import Path


@dataclass
class ChannelState:
    """一期在视频号上发到哪一步了。"""

    episode: str = ""
    video_sha256: str | None = None
    status: str = "packaged"     # packaged | published
    published_url: str | None = None
    updated_at: str | None = None


class StateStore:
    """一个 JSON 文件存着每一期的状态。"""

    def __init__(self, path: str | Path):
        self.path = Path(path)

    def _load(self) -> dict:
        if not self.path.is_file():
            return {}
        try:
            raw = json.loads(self.path.read_text(encoding="utf-8"))
        except (json.JSONDecodeError, OSError):
            return {}
        episodes = raw.get("episodes", {})
        return episodes if isinstance(episodes, dict) else {}

    def get(self, episode: str) -> ChannelState:
        entry = self._load().get(episode)
        if not isinstance(entry, dict):
            return ChannelState(episode=episode)
        known = {}
        for name, spec in ChannelState.__dataclass_fields__.items():
            known[name] = entry.get(name, spec.default)
        known["episode"] = episode
        return ChannelState(**known)

    def save(self, episode: str, state: ChannelState) -> None:
        episodes = self._load()
        state.episode = episode
        state.updated_at = datetime.now(timezone.utc).isoformat(timespec="seconds")
        episodes[episode] = asdict(state)
        self.path.parent.mkdir(parents=True, exist_ok=True)
        self.path.write_text(
            json.dumps({"episodes": episodes}, ensure_ascii=False, indent=2,
                       sort_keys=True),
            encoding="utf-8",
        )
```

- [ ] **Step 8: 写 `channels/package.py`**

```python
"""出包：把一期变成一个「照着做就能发完」的目录。

产物结构见规格 §6.1.2。幂等靠成片的 sha256——
成片没变就不重出，成片变了就重出。
"""
from __future__ import annotations

import json
from dataclasses import dataclass, field
from pathlib import Path

from pyv import epmeta, preflight

from channels import assets, contract, snapshot, state


@dataclass
class PackageResult:
    """一次出包的结果。"""

    episode: str
    dir: Path
    files: dict[str, Path] = field(default_factory=dict)
    video_sha256: str = ""
    status: str = "packaged"
    reason: str = ""
    reused: bool = False


def _checklist(copy: contract.ChannelsCopy, files: dict[str, Path]) -> str:
    topics = contract.topics_line(copy.topics)
    return "\n".join([
        f"# 待发布：{copy.title}",
        "",
        "| 项 | 值 |",
        "| --- | --- |",
        f"| 视频 | `video.mp4` |",
        f"| 标题 | {copy.title}（{len(copy.title)} 字） |",
        f"| 话题 | {topics or '（无）'} |",
        "| 封面 | `cover-16x9.jpg`（信息流若裁切则换 `cover-9x16.jpg`） |",
        "| 原创声明 | 勾选 |",
        "",
        "## 步骤",
        "",
        "- [ ] 打开视频号助手 → 发布视频",
        "- [ ] 上传 `video.mp4`",
        "- [ ] 粘贴标题与简介，补上 # 话题",
        "- [ ] 选封面（先试 `cover-16x9.jpg`，被裁就换 `cover-9x16.jpg`）",
        "- [ ] 勾选「原创声明」",
        "- [ ] 发布",
        "- [ ] 回填链接："
        "`python -m channels.cli mark published <期号> --url \"<链接>\"`",
        "",
        "> **待你上传。** 这一步没做完之前，状态一律是「待上传」，不是「已发布」。",
        "",
    ])


def build_package(episode: str, meta: epmeta.EpisodeMeta, video: str | Path,
                  out_root: str | Path,
                  capabilities_dir: str | Path | None = None) -> PackageResult:
    """出一期在视频号上的发布包。"""
    copy = contract.slice_copy(meta)
    video_path = Path(video)
    if not video_path.is_file():
        raise FileNotFoundError(f"成片不存在：{video_path}")

    out_root = Path(out_root)
    target = out_root / episode
    store = state.StateStore(out_root / "state.json")
    previous = store.get(episode)
    digest = preflight.file_sha256(video_path)

    files: dict[str, Path] = {}
    reused = False
    if previous.video_sha256 == digest and (target / "meta.json").is_file():
        # 成片没变，包还在：直接复用，不重抽帧。
        reused = True
        meta_file = json.loads((target / "meta.json").read_text(encoding="utf-8"))
        files = {name: target / name for name in meta_file["files"]}
    else:
        target.mkdir(parents=True, exist_ok=True)
        covers = assets.make_covers(video_path, copy.cover_at, target)
        link = target / "video.mp4"
        if link.exists() or link.is_symlink():
            link.unlink()
        link.symlink_to(video_path.resolve())

        (target / "title.txt").write_text(copy.title, encoding="utf-8")
        (target / "description.txt").write_text(copy.description, encoding="utf-8")
        (target / "topics.txt").write_text(
            contract.topics_line(copy.topics), encoding="utf-8")

        names = ("video.mp4", "cover-16x9.jpg", "cover-9x16.jpg",
                 "title.txt", "description.txt", "topics.txt")
        files = {name: target / name for name in names}
        checklist = _checklist(copy, files)
        (target / "publish.md").write_text(checklist, encoding="utf-8")
        files["publish.md"] = target / "publish.md"

        (target / "meta.json").write_text(
            json.dumps({
                "episode": episode,
                "video_sha256": digest,
                "files": sorted(files),
                "cover_at": copy.cover_at,
            }, ensure_ascii=False, indent=2, sort_keys=True),
            encoding="utf-8",
        )

    store.save(episode, state.ChannelState(
        episode=episode, video_sha256=digest, status="packaged",
        published_url=previous.published_url,
    ))

    reason = "视频号无公开发布接口，已出包待人工上传"
    snapshot.write_snapshot(
        snapshot.OUTBOX_DIR / f"{episode}__channels.json",
        episode=episode, status="packaged", title=copy.title,
        package_dir=str(target), published_url=previous.published_url,
        reason=reason,
    )
    return PackageResult(
        episode=episode, dir=target, files=files, video_sha256=digest,
        status="packaged", reason=reason, reused=reused,
    )
```

> **注意**：上面的 `_checklist` 里，标题栏写的是 `copy.title`（视频号版标题），
> 而期号要出现在回填命令里——所以 `_checklist` 多收一个 `episode` 参数。
> 把它改成 `def _checklist(episode: str, copy: contract.ChannelsCopy) -> str:`，
> 并把那一行改成：
> ```python

> f"`python -m channels.cli mark published {episode} --url \"<链接>\"`",
> ```
> 调用处相应改成 `_checklist(episode, copy)`。

```python
"""通知：措辞必须区分状态。

含糊地说「已发布」是发布场景里最贵的一种 bug——
用户以为发出去了，实际没有。
"""
from __future__ import annotations

import json
import urllib.request

# 状态 → 该怎么说
PHRASES = {
    "packaged": "发布包已生成，待你上传",
    "published": "已发布",
}


def phrase(status: str) -> str:
    return PHRASES.get(status, f"状态 {status}")


def notify(episode: str, status: str, title: str, package_dir: str,
           webhook: str | None = None) -> str:
    """写一条日志；配了 webhook 就再推一条。返回那句措辞。"""
    text = f"[视频号] {episode} {phrase(status)}：{title}（{package_dir}）"
    print(text)
    if webhook:
        body = json.dumps({"msgtype": "text",
                           "text": {"content": text}}).encode("utf-8")
        request = urllib.request.Request(
            webhook, data=body,
            headers={"Content-Type": "application/json"})
        try:
            with urllib.request.urlopen(request, timeout=10) as response:
                response.read()
        except Exception as error:   # noqa: BLE001
            # 通知失败不影响发布本身，但要让人看见。
            print(f"WARNING 通知推送失败：{error}")
    return text
```

- [ ] **Step 10: 写 `channels/cli.py`**

```python
"""视频号 adapter 的命令行入口。

    python -m channels.cli package <期号>
    python -m channels.cli status <期号>
    python -m channels.cli mark published <期号> --url <链接>
"""
from __future__ import annotations

import argparse
import os
import sys
from pathlib import Path

from pyv import epmeta

from channels import notify, package, snapshot, state

AIV_ROOT = Path(__file__).resolve().parents[2] / "aiv"
DEFAULT_OUT = Path(__file__).resolve().parents[1] / "out"
WEBHOOK_ENV = "CHANNELS_WEBHOOK"


def _video_path(episode: str) -> Path:
    return AIV_ROOT / "out" / f"{episode}.mp4"


def cmd_package(args: argparse.Namespace) -> int:
    try:
        meta = epmeta.load_meta(args.episode)
    except epmeta.MetaError as error:
        print(f"ERROR {error}", file=sys.stderr)
        return 1

    video = Path(args.video) if args.video else _video_path(args.episode)
    if not video.is_file():
        print(f"ERROR 成片不存在：{video}（先跑 make all 出片）", file=sys.stderr)
        return 1

    result = package.build_package(args.episode, meta, video, args.out)
    notify.notify(args.episode, result.status, meta.platform("channels")["title"],
                  str(result.dir), os.environ.get(WEBHOOK_ENV))
    print(f"OK 发布包 → {result.dir}"
          + ("（成片没变，复用已有的包）" if result.reused else ""))
    return 0


def cmd_status(args: argparse.Namespace) -> int:
    store = state.StateStore(Path(args.out) / "state.json")
    current = store.get(args.episode)
    print(f"{args.episode}  状态 {current.status}  "
          f"链接 {current.published_url or '（未回填）'}")
    print(f"通知措辞：{notify.phrase(current.status)}")
    return 0


def cmd_mark(args: argparse.Namespace) -> int:
    store = state.StateStore(Path(args.out) / "state.json")
    current = store.get(args.episode)
    current.status = "published"
    current.published_url = args.url
    store.save(args.episode, current)

    meta = epmeta.load_meta(args.episode)
    title = (meta.platform("channels") or {}).get("title", meta.title)
    snapshot.write_snapshot(
        snapshot.OUTBOX_DIR / f"{args.episode}__channels.json",
        episode=args.episode, status="published", title=title,
        package_dir=str(Path(args.out) / args.episode),
        published_url=args.url, reason="人工发布后回填",
    )
    notify.notify(args.episode, "published", title,
                  str(Path(args.out) / args.episode),
                  os.environ.get(WEBHOOK_ENV))
    print(f"OK {args.episode} 已回填发布链接")
    return 0


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(prog="channels")
    sub = parser.add_subparsers(dest="command", required=True)

    p_package = sub.add_parser("package")
    p_package.add_argument("episode")
    p_package.add_argument("--video", default=None, help="成片路径，默认 aiv/out/<期号>.mp4")
    p_package.add_argument("--out", default=str(DEFAULT_OUT))
    p_package.set_defaults(func=cmd_package)

    p_status = sub.add_parser("status")
    p_status.add_argument("episode")
    p_status.add_argument("--out", default=str(DEFAULT_OUT))
    p_status.set_defaults(func=cmd_status)

    p_mark = sub.add_parser("mark")
    p_mark.add_argument("state", choices=["published"])
    p_mark.add_argument("episode")
    p_mark.add_argument("--url", required=True)
    p_mark.add_argument("--out", default=str(DEFAULT_OUT))
    p_mark.set_defaults(func=cmd_mark)

    args = parser.parse_args(argv)
    return args.func(args)


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
"""B站版的文案。

标签是**英文逗号分隔**的一串（不是 # 井号），拼接时不要加井号。
转载（copyright = 2）必须给 source——平台会拒。
"""
from __future__ import annotations

from dataclasses import dataclass

from pyv import epmeta


@dataclass(frozen=True)
class BiliCopy:
    """一期在 B站上的文案。"""

    title: str
    description: str
    tags: tuple[str, ...]
    tid: int
    copyright: int
    no_reprint: int
    source: str = ""
    cover_at: float = 0.0
    url: str = ""


def slice_copy(meta: epmeta.EpisodeMeta) -> BiliCopy:
    section = meta.platform("bilibili")
    if section is None:
        raise epmeta.MetaError(f"这一期没有配置 B站文案：{meta.episode}")
    copyright = int(section.get("copyright", 1))
    source = str(section.get("source", ""))
    if copyright == 2 and not source:
        raise epmeta.MetaError(
            "copyright = 2（转载）必须给 source，平台会拒没有来源的转载")
    return BiliCopy(
        title=str(section.get("title", "")),
        description=str(section.get("description", "")),
        tags=tuple(str(t) for t in (section.get("tags") or [])),
        tid=int(section.get("tid", 0)),
        copyright=copyright,
        no_reprint=int(section.get("no_reprint", 0)),
        source=source,
        cover_at=meta.cover_at,
        url=meta.url,
    )


def tags_line(tags: tuple[str, ...]) -> str:
    """标签拼成平台要的那一串：数据库,源码"""
    return ",".join(tags)
```

```python
"""封面：B站要求 jpeg/png、≤ 5MB、建议 ≥ 1146×717。"""

from __future__ import annotations

import subprocess
from pathlib import Path

from PIL import Image

COVER_SIZE = (1146, 717)
COVER_MIN = (960, 600)


def make_cover(video: str | Path, at: float, out_path: str | Path) -> Path:
    """抽一帧并裁成 B站要的尺寸。"""
    out = Path(out_path)
    out.parent.mkdir(parents=True, exist_ok=True)
    raw = out.parent / "_frame.png"
    proc = subprocess.run([
        "ffmpeg", "-y", "-ss", f"{at:.3f}", "-i", str(video),
        "-frames:v", "1", str(raw),
    ], capture_output=True, text=True)
    if proc.returncode != 0:
        raise RuntimeError(f"抽帧失败：{(proc.stderr or '')[-400:]}")
    with Image.open(raw) as frame:
        image = frame.convert("RGB")
        # 16:9 的帧裁成 16:10 会切掉上下两条，切中间。
        target_ratio = COVER_SIZE[0] / COVER_SIZE[1]
        width, height = image.size
        crop_height = int(width / target_ratio)
        if crop_height <= height:
            top = (height - crop_height) // 2
            image = image.crop((0, top, width, top + crop_height))
        image = image.resize(COVER_SIZE, Image.LANCZOS)
        image.save(out, format="JPEG", quality=92)
    raw.unlink(missing_ok=True)
    return out
```

```python
"""字幕：storyboard 的字幕事件 → SRT。

时间轴是本机产物（跟着本机旁白走），所以字幕文件也是本地产物，不入库。
"""
from __future__ import annotations

from pyv.timeline import SubtitleEvent


def format_timestamp(seconds: float) -> str:
    """秒 → SRT 的 HH:MM:SS,mmm。"""
    total_ms = int(round(seconds * 1000))
    hours, remainder = divmod(total_ms, 3600_000)
    minutes, remainder = divmod(remainder, 60_000)
    secs, ms = divmod(remainder, 1000)
    return f"{hours:02d}:{minutes:02d}:{secs:02d},{ms:03d}"


def build_srt(events) -> str:
    """字幕事件 → SRT 文本。"""
    blocks = []
    for index, event in enumerate(events, start=1):
        blocks.append(
            f"{index}\n"
            f"{format_timestamp(event.start)} --> {format_timestamp(event.end)}\n"
            f"{event.text}\n"
        )
    return "\n".join(blocks)
```

```python
"""B站的幂等状态。

三层键沿用 `weixin/wechat/state.py` 的形状：

- 内容层：**成片的 sha256**——成片变了就得重新投稿。
- 对象层：`resource_id`（BV 号）——平台侧这篇稿件的 id。
- 发布层：`archive_state`——审核态（0 = 开放浏览）。

状态文件留在 `bilibili/out/` 下，永不入库。
"""
from __future__ import annotations

import json
from dataclasses import asdict, dataclass
from datetime import datetime, timezone
from pathlib import Path


@dataclass
class BiliState:
    """一期在 B站上发到哪一步了。"""

    episode: str = ""
    video_sha256: str | None = None
    resource_id: str | None = None
    archive_state: int | None = None
    reject_reason: str = ""
    status: str = "packaged"     # packaged | submitted | published | failed
    published_url: str | None = None
    updated_at: str | None = None


class StateStore:
    """一个 JSON 文件存着每一期的状态。"""

    def __init__(self, path: str | Path):
        self.path = Path(path)

    def _load(self) -> dict:
        if not self.path.is_file():
            return {}
        try:
            raw = json.loads(self.path.read_text(encoding="utf-8"))
        except (json.JSONDecodeError, OSError):
            return {}
        episodes = raw.get("episodes", {})
        return episodes if isinstance(episodes, dict) else {}

    def get(self, episode: str) -> BiliState:
        entry = self._load().get(episode)
        if not isinstance(entry, dict):
            return BiliState(episode=episode)
        known = {}
        for name, spec in BiliState.__dataclass_fields__.items():
            known[name] = entry.get(name, spec.default)
        known["episode"] = episode
        return BiliState(**known)

    def save(self, episode: str, state: BiliState) -> None:
        episodes = self._load()
        state.episode = episode
        state.updated_at = datetime.now(timezone.utc).isoformat(timespec="seconds")
        episodes[episode] = asdict(state)
        self.path.parent.mkdir(parents=True, exist_ok=True)
        self.path.write_text(
            json.dumps({"episodes": episodes}, ensure_ascii=False, indent=2,
                       sort_keys=True),
            encoding="utf-8",
        )
```

```python
    "packaged": "发布包已生成，待你上传",
    "submitted": "已投稿，审核中",
    "published": "已发布",
    "failed": "投稿失败",
}

def phrase(status: str) -> str:
    return PHRASES.get(status, f"状态 {status}")

           webhook: str | None = None) -> str:
    text = f"[B站] {episode} {phrase(status)}：{title}（{package_dir}）"
    print(text)
    if webhook:
        body = json.dumps({"msgtype": "text",
                           "text": {"content": text}}).encode("utf-8")
        request = urllib.request.Request(
            webhook, data=body,
            headers={"Content-Type": "application/json"})
        try:
            with urllib.request.urlopen(request, timeout=10) as response:
                response.read()
        except Exception as error:   # noqa: BLE001
            print(f"WARNING 通知推送失败：{error}")
    return text
```

```python
"""出包：把一期变成一个「照着做就能发完」的目录。

产物结构见规格 §6.3。幂等靠成片的 sha256。
"""
from __future__ import annotations

import json
from dataclasses import dataclass, field
from pathlib import Path

from pyv import epmeta, preflight

from bilibili import assets, contract, snapshot, state, subtitle


@dataclass
class PackageResult:
    episode: str
    dir: Path
    files: dict[str, Path] = field(default_factory=dict)
    video_sha256: str = ""
    status: str = "packaged"
    reason: str = ""
    reused: bool = False


def _checklist(copy: contract.BiliCopy) -> str:
    return "\n".join([
        f"# 待发布：{copy.title}",
        "",
        "| 项 | 值 |",
        "| --- | --- |",
        "| 视频 | `video.mp4` |",
        f"| 标题 | {copy.title}（{len(copy.title)} 字） |",
        f"| 分区 | tid = {copy.tid} |",
        f"| 标签 | {contract.tags_line(copy.tags)} |",
        "| 封面 | `cover.jpg` |",
        "| 字幕 | `subtitle.srt`（有的话一起传） |",
        f"| 原创 | {'原创' if copy.copyright == 1 else '转载'} |",
        f"| 允许转载 | {'否' if copy.no_reprint == 1 else '是'} |",
        "",
        "## 步骤",
        "",
        "- [ ] 打开 B站创作中心 → 投稿",
        "- [ ] 上传 `video.mp4`",
        "- [ ] 填标题、简介、标签，选对分区",
        "- [ ] 上传 `cover.jpg` 作封面",
        "- [ ] 有 `subtitle.srt` 的话传上字幕",
        "- [ ] 声明原创，确认不允许转载",
        "- [ ] 提交投稿",
        "",
        "> **待你上传。** 提交之前状态一律是「待上传」，不是「已发布」。",
        "",
    ])


def build_package(episode: str, meta: epmeta.EpisodeMeta, video: str | Path,
                  out_root: str | Path, storyboard=None,
                  capabilities_dir: str | Path | None = None) -> PackageResult:
    copy = contract.slice_copy(meta)
    video_path = Path(video)
    if not video_path.is_file():
        raise FileNotFoundError(f"成片不存在：{video_path}")

    out_root = Path(out_root)
    target = out_root / episode
    store = state.StateStore(out_root / "state.json")
    previous = store.get(episode)
    digest = preflight.file_sha256(video_path)

    files: dict[str, Path] = {}
    reused = False
    if previous.video_sha256 == digest and (target / "meta.json").is_file():
        reused = True
        meta_file = json.loads((target / "meta.json").read_text(encoding="utf-8"))
        files = {name: target / name for name in meta_file["files"]}
    else:
        target.mkdir(parents=True, exist_ok=True)
        cover = assets.make_cover(video_path, copy.cover_at, target / "cover.jpg")
        link = target / "video.mp4"
        if link.exists() or link.is_symlink():
            link.unlink()
        link.symlink_to(video_path.resolve())

        (target / "title.txt").write_text(copy.title, encoding="utf-8")
        (target / "description.txt").write_text(copy.description, encoding="utf-8")
        (target / "tags.txt").write_text(
            contract.tags_line(copy.tags), encoding="utf-8")
        (target / "publish.md").write_text(_checklist(copy), encoding="utf-8")

        names = ["video.mp4", "cover.jpg", "title.txt", "description.txt",
                 "tags.txt", "publish.md"]
        files = {name: target / name for name in names}

        if storyboard is not None:
            events = storyboard.subtitle_events()
            if events:
                srt_path = target / "subtitle.srt"
                srt_path.write_text(subtitle.build_srt(events), encoding="utf-8")
                files["subtitle.srt"] = srt_path

        (target / "meta.json").write_text(
            json.dumps({
                "episode": episode,
                "video_sha256": digest,
                "files": sorted(files),
                "cover_at": copy.cover_at,
            }, ensure_ascii=False, indent=2, sort_keys=True),
            encoding="utf-8",
        )

    store.save(episode, state.BiliState(
        episode=episode, video_sha256=digest, status="packaged",
        resource_id=previous.resource_id,
        published_url=previous.published_url,
    ))

    reason = "B站 ARC_BASE 权限未开通，已出包待人工上传"
    snapshot.write_snapshot(
        snapshot.OUTBOX_DIR / f"{episode}__bilibili.json",
        episode=episode, status="packaged", title=copy.title,
        package_dir=str(target), published_url=previous.published_url,
        reason=reason,
    )
    return PackageResult(
        episode=episode, dir=target, files=files, video_sha256=digest,
        status="packaged", reason=reason, reused=reused,
    )
```

```python
"""B站 adapter 的命令行入口。

    python -m bilibili.cli package <期号>
    python -m bilibili.cli status <期号>
"""
from __future__ import annotations

import argparse
import os
import sys
from pathlib import Path

from pyv import epmeta

from bilibili import notify, package, state

AIV_ROOT = Path(__file__).resolve().parents[2] / "aiv"
DEFAULT_OUT = Path(__file__).resolve().parents[1] / "out"


def _video_path(episode: str) -> Path:
    return AIV_ROOT / "out" / f"{episode}.mp4"


def _storyboard_path(episode: str) -> Path:
    return AIV_ROOT / f"storyboard_{episode}.json"


def cmd_package(args: argparse.Namespace) -> int:
    try:
        meta = epmeta.load_meta(args.episode)
    except epmeta.MetaError as error:
        print(f"ERROR {error}", file=sys.stderr)
        return 1

    video = Path(args.video) if args.video else _video_path(args.episode)
    if not video.is_file():
        print(f"ERROR 成片不存在：{video}（先跑 make all 出片）", file=sys.stderr)
        return 1

    storyboard = None
    storyboard_path = _storyboard_path(args.episode)
    if storyboard_path.is_file():
        from pyv.timeline import Storyboard

        storyboard = Storyboard.load(storyboard_path)

    result = package.build_package(args.episode, meta, video, args.out,
                                   storyboard=storyboard)
    notify.notify(args.episode, result.status,
                  meta.platform("bilibili")["title"], str(result.dir),
                  os.environ.get(notify.WEBHOOK_ENV))
    print(f"OK 发布包 → {result.dir}"
          + ("（成片没变，复用已有的包）" if result.reused else ""))
    return 0


def cmd_status(args: argparse.Namespace) -> int:
    store = state.StateStore(Path(args.out) / "state.json")
    current = store.get(args.episode)
    print(f"{args.episode}  状态 {current.status}  "
          f"稿件 {current.resource_id or '（未投稿）'}  "
          f"链接 {current.published_url or '（未回填）'}")
    print(f"通知措辞：{notify.phrase(current.status)}")
    return 0


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(prog="bilibili")
    sub = parser.add_subparsers(dest="command", required=True)

    p_package = sub.add_parser("package")
    p_package.add_argument("episode")
    p_package.add_argument("--video", default=None)
    p_package.add_argument("--out", default=str(DEFAULT_OUT))
    p_package.set_defaults(func=cmd_package)

    p_status = sub.add_parser("status")
    p_status.add_argument("episode")
    p_status.add_argument("--out", default=str(DEFAULT_OUT))
    p_status.set_defaults(func=cmd_status)

    args = parser.parse_args(argv)
    return args.func(args)


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
"""arcopen 签名 v2.0。

**待签名字符串**：抽取所有 `x-bili-` 前缀的自定义 header，按字典序拼接，
每行 `key:value`，行间 `\\n`，**末行不带换行**。

**签名**：`HMAC-SHA256(app_secret, 待签名字符串)` → 小写 hex → `Authorization`。

三条必须记牢的：

1. 空 body 的 md5 是**空字符串的 md5**（`d41d8cd9…`），不是空字符串本身；
2. `x-bili-signature-version: 2.0` 时 **`access-token` 必填**；
3. 时间戳超过当前 10 分钟 → 请求被丢弃。
"""
from __future__ import annotations

import hashlib
import hmac
import time
import uuid

EMPTY_BODY_MD5 = hashlib.md5(b"").hexdigest()
SIGN_VERSION = "2.0"
SIGN_METHOD = "HMAC-SHA256"


def body_md5(body: bytes | str | None) -> str:
    """请求体的 MD5（小写）。GET 或空 body 用空字符串的 MD5。"""
    if body is None:
        return EMPTY_BODY_MD5
    if isinstance(body, str):
        body = body.encode("utf-8")
    return hashlib.md5(body).hexdigest()


def signing_string(headers: dict[str, str]) -> str:
    """待签名字符串：x-bili- 前缀的头，按字典序，`key:value` 换行连接。"""
    items = sorted(
        (key.lower(), value)
        for key, value in headers.items()
        if key.lower().startswith("x-bili-")
    )
    return "\n".join(f"{key}:{value}" for key, value in items)


def sign(headers: dict[str, str], app_secret: str) -> str:
    """算出 Authorization 的值（小写 hex）。"""
    return hmac.new(
        app_secret.encode("utf-8"),
        signing_string(headers).encode("utf-8"),
        hashlib.sha256,
    ).hexdigest()


def common_headers(access_key_id: str, app_secret: str, access_token: str,
                   body: bytes | str | None = None,
                   timestamp: int | None = None,
                   nonce: str | None = None) -> dict[str, str]:
    """带签名的公共请求头。"""
    headers = {
        "Accept": "application/json",
        "Content-Type": "application/json",
        "x-bili-accesskeyid": access_key_id,
        "x-bili-content-md5": body_md5(body),
        "x-bili-signature-method": SIGN_METHOD,
        "x-bili-signature-nonce": nonce or uuid.uuid4().hex,
        "x-bili-signature-version": SIGN_VERSION,
        "x-bili-timestamp": str(
            timestamp if timestamp is not None else int(time.time())),
    }
    if access_token:
        headers["access-token"] = access_token
    headers["Authorization"] = sign(headers, app_secret)
    return headers
```

```python
"""arcopen HTTP 客户端。

只用标准库（urllib），形状照抄 `weixin/wechat/publish.py`。

**每个非零 `code` 都抛 `BiliError`**——把平台错误吞掉的流水线
会在什么都没发出去的时候报成功。
"""
from __future__ import annotations

import json
import mimetypes
import time
import urllib.error
import urllib.parse
import urllib.request
import uuid

from bilibili import sign

DEFAULT_BASE_URL = "https://member.bilibili.com"
DEFAULT_UPLOADER_URL = "https://openupos.bilivideo.com/video/v2"


class BiliError(RuntimeError):
    """arcopen 返回了非零 code。"""

    def __init__(self, code: int, message: str, endpoint: str):
        super().__init__("{} failed: [{}] {}".format(endpoint, code, message))
        self.code = code
        self.message = message
        self.endpoint = endpoint


class BiliClient:
    """只封装投稿这条链路需要的几个接口。"""

    def __init__(self, access_key_id: str, app_secret: str, access_token: str, *,
                 base_url: str = DEFAULT_BASE_URL,
                 uploader_url: str = DEFAULT_UPLOADER_URL,
                 timeout: int = 30):
        self.access_key_id = access_key_id
        self.app_secret = app_secret
        self.access_token = access_token
        self.base_url = base_url.rstrip("/")
        self.uploader_url = uploader_url.rstrip("/")
        self.timeout = timeout

    # -- transport ----------------------------------------------------

    def _request(self, method: str, url: str, *, data=None, headers=None,
                 retries: int = 3):
        request = urllib.request.Request(
            url, data=data, headers=headers or {}, method=method)
        raw = b""
        for attempt in range(retries):
            try:
                with urllib.request.urlopen(request, timeout=self.timeout) as response:
                    raw = response.read()
                break
            except urllib.error.HTTPError as error:
                # 平台答了，错误码在 body 里。
                raw = error.read()
                break
            except (urllib.error.URLError, OSError) as error:
                # 连接断了不是平台的答复。重试一次；不重试整批就塌了。
                if attempt == retries - 1:
                    raise BiliError(-1, "network error: {}".format(error),
                                    url) from error
                time.sleep(2 ** attempt)
        try:
            return json.loads(raw.decode("utf-8"))
        except (json.JSONDecodeError, UnicodeDecodeError) as error:
            raise BiliError(-1, "non-JSON response: {}".format(raw[:200]),
                            url) from error

    def _signed(self, method: str, path: str, *, body=None, query=None,
                headers=None, retries: int = 3):
        url = self.base_url + path
        if query:
            url += "?" + urllib.parse.urlencode(query)
        data = body
        if body is not None and isinstance(body, (dict, list)):
            data = json.dumps(body, ensure_ascii=False).encode("utf-8")
        signed = sign.common_headers(
            self.access_key_id, self.app_secret, self.access_token, body=data)
        signed.update(headers or {})
        return self._request(method, url, data=data, headers=signed,
                             retries=retries)

    def _post_json(self, path: str, payload: dict, *, query=None,
                   retries: int = 3) -> dict:
        """**retries 要当心**：不是所有 POST 都幂等。

        投稿（`add-by-utoken`）不是幂等的——重试一次就多一篇稿件。
        那一类调用必须传 `retries=1`，出错走「先查后发」而不是重投。
        """
        response = self._signed("POST", path, body=payload, query=query,
                                retries=retries)
        return self._check(response, path)

    def _get_json(self, path: str, query: dict | None = None) -> dict:
        response = self._signed("GET", path, query=query)
        return self._check(response, path)

    def _post_bytes(self, url: str, data: bytes) -> dict:
        """裸二进制上传。**不带签名头**——这个端点凭 upload_token 鉴权。"""
        headers = {"Content-Type": "application/octet-stream"}
        response = self._request("POST", url, data=data, headers=headers)
        return self._check(response, url)

    def _post_multipart(self, path: str, filename: str, data: bytes) -> dict:
        """multipart 上传（封面）。

        **md5 按官方文档的「除文件外」算**：请求体里的文件内容不参与，
        只把 multipart 的头部与尾部算进去。官方文档那句话有歧义
        （也可以理解成整个请求体都算），所以这里的行为由
        `test_the_multipart_md5_covers_the_body_but_not_the_file` 钉住，
        实测之后若要改，改的是这一处 + 那条测试。
        """
        boundary = "----bilibili{}".format(uuid.uuid4().hex)
        content_type = mimetypes.guess_type(filename)[0] or "application/octet-stream"
        head = b"".join([
            "--{}\r\n".format(boundary).encode(),
            'Content-Disposition: form-data; name="file"; filename="{}"\r\n'.format(
                filename).encode(),
            "Content-Type: {}\r\n\r\n".format(content_type).encode(),
        ])
        tail = "\r\n--{}--\r\n".format(boundary).encode()
        body = head + data + tail

        headers = {"Content-Type": "multipart/form-data; boundary={}".format(boundary)}
        url = self.base_url + path
        signed = sign.common_headers(self.access_key_id, self.app_secret,
                                    self.access_token, body=head + tail)
        signed.update(headers)
        response = self._request("POST", url, data=body, headers=signed)
        return self._check(response, path)

    @staticmethod
    def _check(response: dict, endpoint: str) -> dict:
        code = response.get("code", 0)
        if code:
            raise BiliError(code, response.get("message", ""), endpoint)
        return response
```

- [ ] **Step 5: 写 `bilibili/upload.py`**

```python
"""上传三步。

1. `archive/video/init` → upload_token
2. `openupos` 裸流上传视频
3. `archive/cover/upload` → 封面 URL

**第 2 步必须裸流。** 官方文档明确警告：用 multipart/form-data 上传时，
服务端**仍可能返回成功**，但落盘的文件不是纯净视频数据，
要等转码阶段才失败——排查成本极高。
"""
from __future__ import annotations

from pathlib import Path


def init_upload(client, name: str) -> str:
    """第一步：预处理，拿 upload_token。

    `utype=1` 是单个小文件（≤100MB），我们的成片 5MB 走这条；
    超过 100MB 就要走分片上传 + 合片。
    """
    response = client._post_json(
        "/arcopen/fn/archive/video/init", {"name": name, "utype": "1"})
    return response["data"]["upload_token"]


def upload_video(client, upload_token: str, path: str | Path) -> None:
    """第二步：裸流上传。"""
    data = Path(path).read_bytes()
    url = "{}/upload?upload_token={}".format(client.uploader_url, upload_token)
    client._post_bytes(url, data)


def upload_cover(client, path: str | Path) -> str:
    """第三步：上传封面，返回封面 URL。"""
    data = Path(path).read_bytes()
    response = client._post_multipart(
        "/arcopen/fn/archive/cover/upload", "cover.jpg", data)
    return response["data"]["url"]
```

- [ ] **Step 6: 写 `bilibili/publish.py`**

```python
"""投稿与审核状态查询。

投稿是异步的：提交后有审核过程，期间不对外开放。
`addit_info.state == 0` 才是「开放浏览」。

**超时不是失败。** 网络断了不代表平台没收下——直接重投可能发两遍。
所以超时之后先按标题去稿件列表里查一次：查到了就认它，查不到才让调用方重投
（规格 §7.4）。
"""
from __future__ import annotations

from bilibili import client as client_mod


def submit(client, upload_token: str, copy, cover_url: str) -> str:
    """投递稿件，返回 resource_id（BV 号）。"""
    payload = {
        "title": copy.title,
        "cover": cover_url,
        "tid": copy.tid,
        "no_reprint": copy.no_reprint,
        "desc": copy.description,
        "tag": ",".join(copy.tags),
        "copyright": copy.copyright,
    }
    if copy.copyright == 2 and copy.source:
        payload["source"] = copy.source
    try:
        # retries=1：投稿**不是幂等接口**，自动重试就会建出好几篇稿件。
        # 出错走下面的「先查后发」，不靠重投。
        response = client._post_json(
            "/arcopen/fn/archive/add-by-utoken", payload,
            query={"upload_token": upload_token}, retries=1)
    except client_mod.BiliError as error:
        if error.code != -1:
            # 平台明确拒了（限流、标题重复、参数错）——那是失败，不查。
            raise
        # 网络错误：结果未知。先查再决定，绝不盲目重投。
        found = find_recent(client, copy.title)
        if found:
            return found["resource_id"]
        raise
    return response["data"]["resource_id"]


def find_recent(client, title: str) -> dict | None:
    """按标题查最近的稿件。

    B站规定「短时间内标题不能相同」，所以标题足以定位刚投的那一篇。
    """
    response = client._get_json(
        "/arcopen/fn/archive/viewlist", {"pn": 1, "ps": 20})
    items = response.get("data", {}).get("list", []) or []
    for item in items:
        if item.get("title") == title:
            return item
    return None


def fetch_status(client, resource_id: str) -> dict:
    """查一篇稿件的审核状态。"""
    response = client._get_json(
        "/arcopen/fn/archive/view", {"resource_id": resource_id})
    data = response.get("data", {}) or {}
    addit = data.get("addit_info", {}) or {}
    video = data.get("video_info", {}) or {}
    state = addit.get("state")
    return {
        "resource_id": resource_id,
        "state": state,
        "published": state == 0,
        "state_desc": addit.get("state_desc", ""),
        "reject_reason": addit.get("reject_reason", ""),
        "share_url": video.get("share_url", ""),
        "iframe_url": video.get("iframe_url", ""),
    }


def list_types(client) -> list[dict]:
    """列分区。`tid` 的当前有效值从这里查，不在代码里硬编码。"""
    response = client._get_json("/arcopen/fn/archive/type/list")
    return response.get("data", {}).get("list", []) or []
```
