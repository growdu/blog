# weixin 实施计划：博客到公众号的转换与自动发布

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `source/_posts/` 下的博客文章转换成公众号可发布 HTML，自动推送到公众号草稿箱，全流程幂等。

**Architecture:** 单向流水线，7 段解耦——`discover → parse → assets → render → upload → draft → publish`。每个模块一个明确职责：`mdparse`/`render` 是纯函数，`publish` 只管网络，`state` 只管幂等，`assets`/`mermaid` 只管本地文件。输入复用 `tools/sync-hexo.py` 的产物，不重写图片改写与 permalink 逻辑。

**Tech Stack:** Python 3.11+（标准库 + pygments 2.20 + pillow 9.4）、pytest 7.3、node 25 + `@mermaid-js/mermaid-cli`（复用系统 Chrome）。

## 修订记录（试点后回填）

本计划写于实现之前。试点和官方文档核对推翻了几处假设，**下面的值才是最终的**，
本文档正文里与之冲突的旧值已同步改掉，但结论以本节为准：

| # | 计划里的旧值 | 最终值 | 为什么改 |
| --- | --- | --- | --- |
| 1 | 标题上限 64 字符 | **32 字符** | 官方 `draft/add` 字段表是 32；64 是编辑器 UI 的限制，二手资料常写错 |
| 2 | 无作者长度限制 | **作者 ≤ 16 字符**（`AUTHOR_LIMIT`） | 官方字段表明确限制 |
| 3 | 只检查原始正文字数 | 原始字数是**必要非充分**条件，渲染后还要再卡一次（`CONTENT_LIMIT = 20000` 字符 + `CONTENT_BYTES_LIMIT = 1 MB`） | 官方限制的是 **HTML 源码字符数**，标签和样式都算进去；全语料有 142 篇过了原始预检、渲染后仍超限 |
| 4 | 占位符 `{{img:N}}` | **`{{img:N:<8位随机token>}}`** | 固定语法会被正文误伤——本仓库的 `life/blog-to-wechat` 正文里就写着「占位符 `{{img:0}}`」 |
| 5 | 未规划 HTML 体积压缩 | **必须压缩**：样式串去可选空格 + 解包只含空白的 Pygments span + 高亮可降级 | 初始实现 45.6% 的文章超限；压缩后正文中位从 16276 降到 10970 字符，超限降到 38.1% |
| 6 | 未规划封面裁剪 | 用官方新格式 **`cover_info.crop_percent_list`**（`ratio` 只支持 `2.35_1` / `1_1`，坐标是 0–1 百分比字符串，六位小数） | 旧的 `pic_crop_235_1` / `pic_crop_1_1` 是像素坐标，已不推荐 |
| 7 | 封面缺失时传空串 | **明确报错**，不提交空 `thumb_media_id` | 空串会让微信返回一个费解的错误码 |
| 8 | 语料按 560 篇统计 | **564 篇** | `source/_posts/` 重新同步后的最终数字 |
| 9 | 试点文章 `postgresql-logical-replication-add-guc` | 换成 **`dpdk/vpp与dpdk的关系`** | 原定试点文章标题 41 字超限、渲染后 92368 字符，被两道闸门真实拦下——这本身就是有价值的结论，但成片验证要换一篇三道闸门都过的 |
| 10 | 未规划统计复算入口 | **新增 `wechat/audit.py` + `wechat.cli audit`** | 分析文档里每个数字都应该有可执行的出处；一条命令 4.5 秒算完全语料，博客长了重跑即可 |
| 11 | 原始 HTML 直接透传；`<hr>` 用硬编码样式串 | **透传前清洗**（删 script/style/iframe、去 class 与事件属性）；`<hr>` 改用 `HR_STYLE` | 硬约束「生成的 HTML 不得含 class 属性」此前有漏洞：原文里写 `<div class="x">` 就会被带出去；`HR_STYLE` 定义了却没接上，样式也因此少压缩了几个字符 |

## Global Constraints

以下约束**每个 task 都适用**，不再重复：

- **不引入 PyYAML / requests**：front-matter 用手写最小解析器（格式由 `tools/sync-hexo.py` 完全控制），HTTP 用标准库 `urllib`。
- **不修改 `tools/sync-hexo.py`**：转换器以 `importlib` 加载它并复用其函数，绝不复制其逻辑。
- **公众号正文只认 inline style**：生成的 HTML **不得包含 `class` 属性**，也不得引用外部 CSS/JS。
- **`errcode != 0` 一律抛 `WeChatError`**：不吞异常，不返回"看起来成功"的结果。
- **mermaid 渲染失败必须显式降级**为内联样式源码块 + 「图表渲染失败」标注，绝不静默丢图。
- **硬限制不合规就跳过并记录**，不做静默截断：正文 > 20000 字、标题 > 32 字符、作者 > 16 字符、渲染后 HTML > 20000 字符。
- **测试不依赖网络**：假 HTTP server 绑定 `127.0.0.1`。
- **每个 commit 自包含**：该 commit 引入的测试只能依赖该 commit 之前已存在的模块；提交后用干净检出独立跑通全部测试。
- **permalink 规则**（已用线上 sitemap 核实）：`/{date[:4]}/{date[5:7]}/{date[8:10]}/{quote(相对 source/_posts 的路径去掉 .md)}/`，date 取 front-matter 的 `date` 字段。
- 代码注释用英文，与仓库现有 `tools/*.py` 风格一致；文档与提交信息用中文。

### Step 4: 实现 `weixin/wechat/posts.py`

```python
"""Discover blog posts and validate them against WeChat's hard limits.

Input is ``source/_posts/``, the output of ``tools/sync-hexo.py``.  That
step already rewrote image paths, rewrote relative links into absolute
permalinks, stripped the leading H1 and rebuilt the front-matter, so this
module never re-implements any of that.  It only reads what sync produced
and adds the metadata WeChat needs (digest, permalink, eligibility).
"""

from __future__ import annotations

import hashlib
import re
from dataclasses import dataclass
from pathlib import Path
from urllib.parse import quote

BODY_LIMIT = 20000
TITLE_LIMIT = 32
DIGEST_LIMIT = 120
AUTHOR_LIMIT = 16

# The official limit applies to the rendered ``content`` field, i.e. the
# HTML source, so the authoritative check runs after rendering.
CONTENT_LIMIT = 20000
CONTENT_BYTES_LIMIT = 1024 * 1024

_FM_RE = re.compile(r"^---\n(.*?)\n---\n", re.DOTALL)
_FENCE_RE = re.compile(r"^\s*(```|~~~)")
_HEADING_RE = re.compile(r"^#{1,6}\s")
_TABLE_RE = re.compile(r"^\s*\|")
_LIST_RE = re.compile(r"^\s*([-*+]|\d+\.)\s")
_QUOTE_RE = re.compile(r"^\s*>")
_HR_RE = re.compile(r"^\s*(-{3,}|\*{3,}|_{3,})\s*$")
_INLINE_CODE_RE = re.compile(r"`([^`]+)`")
_BOLD_RE = re.compile(r"\*\*([^*]+)\*\*")
_ITALIC_RE = re.compile(r"(?<!\*)\*([^*\n]+)\*(?!\*)")
_LINK_RE = re.compile(r"\[([^\]]*)\]\(([^)\s]+)(?:\s+\"[^\"]*\")?\)")
_IMAGE_RE = re.compile(r"!\[([^\]]*)\]\(([^)\s]+)(?:\s+\"[^\"]*\")?\)")


@dataclass(frozen=True)
class Post:
    """A single blog post prepared for conversion."""

    path: Path
    slug: str
    title: str
    digest: str
    permalink: str
    body: str
    categories: tuple[str, ...]
    date: str

    @property
    def fingerprint(self) -> str:
        """Content hash of the body, used as the idempotency key."""
        return hashlib.sha256(self.body.encode("utf-8")).hexdigest()


@dataclass(frozen=True)
class Eligibility:
    """Whether a post may be published, and why not when it may not."""

    ok: bool
    reasons: tuple[str, ...]


def _unquote(value: str) -> str:
    value = value.strip()
    if len(value) >= 2 and value[0] == value[-1] and value[0] in "\"'":
        return value[1:-1]
    return value


def parse_front_matter(text: str) -> tuple[dict[str, str], str]:
    """Split YAML-ish front-matter from the body.

    ``tools/sync-hexo.py`` generates the front-matter itself, so the shape
    is known and fixed: ``key: value`` scalars plus ``key:`` followed by
    ``  - item`` lists.  A tiny hand-written parser avoids adding a YAML
    dependency for a format we control.
    """
    match = _FM_RE.match(text)
    if not match:
        return {}, text

    fields: dict[str, str] = {}
    current_key: str | None = None
    items: list[str] = []

    def flush() -> None:
        if current_key is not None:
            fields[current_key] = items[0] if len(items) == 1 else items

    for line in match.group(1).split("\n"):
        if not line.strip():
            continue
        if line.lstrip().startswith("- ") and current_key is not None:
            items.append(_unquote(line.lstrip()[2:]))
            continue
        flush()
        items = []
        if ":" in line:
            key, _, value = line.partition(":")
            current_key = key.strip()
            value = value.strip()
            fields[current_key] = _unquote(value) if value else ""
        else:
            current_key = None
    flush()

    body = text[match.end():]
    return fields, body


def _strip_inline(text: str) -> str:
    text = _IMAGE_RE.sub(lambda m: m.group(1), text)
    text = _LINK_RE.sub(lambda m: m.group(1), text)
    text = _INLINE_CODE_RE.sub(lambda m: m.group(1), text)
    text = _BOLD_RE.sub(lambda m: m.group(1), text)
    text = _ITALIC_RE.sub(lambda m: m.group(1), text)
    return text.strip()


def make_digest(body: str, limit: int = DIGEST_LIMIT) -> str:
    """Build a WeChat digest (<=120 chars) from the first real paragraph.

    Headings, code fences, tables, lists, quotes and images are skipped:
    they are not readable as a standalone summary.
    """
    in_fence = False
    paragraph: list[str] = []

    for raw in body.split("\n"):
        line = raw.rstrip()
        if _FENCE_RE.match(line):
            in_fence = not in_fence
            continue
        if in_fence:
            continue
        if not line.strip():
            if paragraph:
                break
            continue
        if (_HEADING_RE.match(line) or _TABLE_RE.match(line) or _LIST_RE.match(line)
                or _QUOTE_RE.match(line) or _HR_RE.match(line)):
            continue
        paragraph.append(line.strip())

    if not paragraph:
        return ""

    text = _strip_inline(" ".join(paragraph))
    text = re.sub(r"\s+", " ", text).strip()
    if len(text) <= limit:
        return text

    clipped = text[:limit]
    for mark in ("。", "！", "？", "；", ". ", "! ", "? "):
        index = clipped.rfind(mark)
        if index > limit // 2:
            return clipped[:index + len(mark)].strip()
    return clipped.strip()


def build_permalink(slug: str, date: str) -> str:
    """Build the canonical site URL of a post.

    Hexo's ``permalink: :year/:month/:day/:title/`` expands ``:title`` to
    the post path relative to ``source/_posts/`` (verified against the
    published sitemap), so the permalink mirrors that path exactly.
    """
    day = date[:10]
    parts = day.split("-")
    if len(parts) != 3:
        parts = ["2024", "01", "01"]
    return "/{}/{}/{}/{}/".format(parts[0], parts[1], parts[2], quote(slug))


def load_post(path: Path, posts_dir: Path) -> Post:
    """Load one post file into a :class:`Post`."""
    text = path.read_text(encoding="utf-8")
    fields, body = parse_front_matter(text)

    slug = path.relative_to(posts_dir).with_suffix("").as_posix()
    title = fields.get("title") or path.stem
    date = fields.get("date") or "2024-01-01 00:00:00"

    raw_categories = fields.get("categories", "")
    if isinstance(raw_categories, str):
        categories = (raw_categories,) if raw_categories else ()
    else:
        categories = tuple(raw_categories)

    return Post(
        path=path,
        slug=slug,
        title=title.strip(),
        digest=make_digest(body),
        permalink=build_permalink(slug, date),
        body=body,
        categories=categories,
        date=date,
    )


def discover(posts_dir: Path) -> list[Post]:
    """Load every markdown post under ``posts_dir``."""
    if not posts_dir.is_dir():
        raise FileNotFoundError(
            "source/_posts not found at {}. Run `python3 tools/sync-hexo.py` first "
            "(it takes about three minutes).".format(posts_dir)
        )

def check_eligibility(post: Post) -> Eligibility:
    """Check the post against WeChat's hard limits.

    Overlong posts are reported, never silently truncated: a truncated
    deep-dive article is worse than no article.
    """
    reasons: list[str] = []

    body_length = len(re.sub(r"\s", "", post.body))
    if body_length > BODY_LIMIT:
        reasons.append("正文 {} 字，超过上限 {} 字".format(body_length, BODY_LIMIT))

    if len(post.title) > TITLE_LIMIT:
        reasons.append("标题 {} 字符，超过上限 {} 字符".format(len(post.title), TITLE_LIMIT))

    return Eligibility(ok=not reasons, reasons=tuple(reasons))

```python
"""Markdown -> block AST.

Deliberately small: it covers exactly the constructs the blog corpus uses
(headings, paragraphs, fenced code, tables, lists, task lists, quotes,
thematic breaks, raw HTML, inline code, emphasis, links, images) and
nothing else.  Footnotes and LaTeX do not occur in the corpus, so they are
not implemented.

Pure module: no file access, no network.
"""

from __future__ import annotations

import re
from dataclasses import dataclass, field

__all__ = [
    "Text", "Bold", "Italic", "InlineCode", "Link", "Image",
    "Heading", "Paragraph", "CodeBlock", "Table", "ListItem", "ListBlock",
    "Quote", "ThematicBreak", "HtmlBlock",
    "parse", "parse_inline",
]


@dataclass(frozen=True)
class Text:
    value: str


@dataclass(frozen=True)
class Bold:
    children: list = field(default_factory=list)


@dataclass(frozen=True)
class Italic:
    children: list = field(default_factory=list)


@dataclass(frozen=True)
class InlineCode:
    value: str


@dataclass(frozen=True)
class Link:
    target: str
    children: list = field(default_factory=list)


@dataclass(frozen=True)
class Image:
    alt: str
    target: str


@dataclass(frozen=True)
class Heading:
    level: int
    children: list = field(default_factory=list)


@dataclass(frozen=True)
class Paragraph:
    children: list = field(default_factory=list)


@dataclass(frozen=True)
class CodeBlock:
    lang: str
    code: str


@dataclass(frozen=True)
class Table:
    header: list = field(default_factory=list)
    rows: list = field(default_factory=list)
    align: list = field(default_factory=list)


@dataclass(frozen=True)
class ListItem:
    blocks: list = field(default_factory=list)
    checked: bool | None = None


@dataclass(frozen=True)
class ListBlock:
    ordered: bool
    items: list = field(default_factory=list)


@dataclass(frozen=True)
class Quote:
    blocks: list = field(default_factory=list)


@dataclass(frozen=True)
class ThematicBreak:
    pass


@dataclass(frozen=True)
class HtmlBlock:
    html: str


_FENCE_RE = re.compile(r"^(\s*)(`{3,}|~{3,})\s*([A-Za-z0-9_+-]*)\s*$")
_HEADING_RE = re.compile(r"^(#{1,6})\s+(.*)$")
_HR_RE = re.compile(r"^\s*(-{3,}|\*{3,}|_{3,})\s*$")
_UL_RE = re.compile(r"^(\s*)[-*+]\s+(.*)$")
_OL_RE = re.compile(r"^(\s*)(\d+)\.\s+(.*)$")
_TASK_RE = re.compile(r"^\[([ xX])\]\s+(.*)$")
_QUOTE_RE = re.compile(r"^\s*>\s?(.*)$")
_HTML_RE = re.compile(r"^<(?:/?)(?:div|table|img|details|summary|br|p|span|section|video|iframe|ul|ol|li|h[1-6]|b|i|strong|em|code|pre|blockquote|figure|figcaption|hr|a)\b", re.I)

_IMAGE_RE = re.compile(r"!\[([^\]]*)\]\(([^)\s]+)(?:\s+\"[^\"]*\")?\)")
_LINK_RE = re.compile(r"\[([^\]]*)\]\(([^)\s]+)(?:\s+\"[^\"]*\")?\)")
_INLINE_CODE_RE = re.compile(r"`([^`]+)`")
_BOLD_RE = re.compile(r"\*\*([^*]+)\*\*")
_ITALIC_RE = re.compile(r"(?<!\*)\*([^*\n]+)\*(?!\*)")
_STRIKE_RE = re.compile(r"~~([^~]+)~~")


def parse_inline(text: str) -> list:
    """Parse inline markup into a flat list of inline nodes.

    Inline code is extracted first so that markup inside backticks is
    never re-interpreted.
    """
    tokens: list = []
    pattern = re.compile(
        r"(!\[[^\]]*\]\([^)\s]*(?:\s+\"[^\"]*\")?\))"
        r"|(\[[^\]]*\]\([^)\s]*(?:\s+\"[^\"]*\")?\))"
        r"|(`[^`]+`)"
        r"|(\*\*[^*]+\*\*)"
        r"|(~~[^~]+~~)"
        r"|((?<!\*)\*[^*\n]+\*(?!\*))"
    )
    position = 0
    for match in pattern.finditer(text):
        if match.start() > position:
            tokens.append(Text(text[position:match.start()]))
        token = match.group(0)
        if match.group(1):
            image = _IMAGE_RE.match(token)
            tokens.append(Image(image.group(1), image.group(2)))
        elif match.group(2):
            link = _LINK_RE.match(token)
            tokens.append(Link(link.group(2), parse_inline(link.group(1))))
        elif match.group(3):
            tokens.append(InlineCode(token[1:-1]))
        elif match.group(4):
            tokens.append(Bold(parse_inline(token[2:-2])))
        elif match.group(5):
            tokens.append(Text(token[2:-2]))
        else:
            tokens.append(Italic(parse_inline(token[1:-1])))
        position = match.end()
    if position < len(text):
        tokens.append(Text(text[position:]))
    return [token for token in tokens if not (isinstance(token, Text) and not token.value)]


def _split_table_row(line: str) -> list:
    line = line.strip()
    if line.startswith("|"):
        line = line[1:]
    if line.endswith("|"):
        line = line[:-1]
    cells = []
    current = []
    escaped = False
    for char in line:
        if escaped:
            current.append(char)
            escaped = False
            continue
        if char == "\\":
            escaped = True
            current.append(char)
            continue
        if char == "|":
            cells.append("".join(current).strip())
            current = []
            continue
        current.append(char)
    cells.append("".join(current).strip())
    return cells


def _alignment(cells: list) -> list:
    aligns = []
    for cell in cells:
        left, right = cell.startswith(":"), cell.endswith(":")
        if left and right:
            aligns.append("center")
        elif right:
            aligns.append("right")
        elif left:
            aligns.append("left")
        else:
            aligns.append("")
    return aligns


def _is_table_separator(line: str) -> bool:
    cells = _split_table_row(line)
    return bool(cells) and all(re.fullmatch(r":?-{1,}:?", cell.strip()) for cell in cells)


def _parse_blocks(lines: list) -> list:
    blocks: list = []
    index = 0
    total = len(lines)

    while index < total:
        line = lines[index]
        stripped = line.strip()

        if not stripped:
            index += 1
            continue

        fence = _FENCE_RE.match(line)
        if fence:
            marker = fence.group(2)
            lang = fence.group(3)
            body: list = []
            index += 1
            while index < total:
                closing = _FENCE_RE.match(lines[index])
                if closing and closing.group(2)[0] == marker[0] and len(closing.group(2)) >= len(marker):
                    index += 1
                    break
                body.append(lines[index])
                index += 1
            blocks.append(CodeBlock(lang=lang, code="\n".join(body)))
            continue

        if _HR_RE.match(line):
            blocks.append(ThematicBreak())
            index += 1
            continue

        heading = _HEADING_RE.match(stripped)
        if heading:
            blocks.append(Heading(level=len(heading.group(1)), children=parse_inline(heading.group(2).strip())))
            index += 1
            continue

        if _QUOTE_RE.match(line):
            inner: list = []
            while index < total and _QUOTE_RE.match(lines[index]):
                inner.append(_QUOTE_RE.match(lines[index]).group(1))
                index += 1
            blocks.append(Quote(blocks=_parse_blocks(inner)))
            continue

        if index + 1 < total and "|" in line and _is_table_separator(lines[index + 1]):
            header = _split_table_row(line)
            align = _alignment(_split_table_row(lines[index + 1]))
            index += 2
            rows: list = []
            while index < total and lines[index].strip().startswith("|"):
                rows.append([parse_inline(cell) for cell in _split_table_row(lines[index])])
                index += 1
            blocks.append(Table(
                header=[parse_inline(cell) for cell in header],
                rows=rows,
                align=align,
            ))
            continue

        unordered = _UL_RE.match(line)
        ordered = _OL_RE.match(line)
        if unordered or ordered:
            is_ordered = ordered is not None
            items: list = []
            base_indent = len((unordered or ordered).group(1))
            while index < total:
                current = _UL_RE.match(lines[index])
                current_ordered = _OL_RE.match(lines[index])
                match = current_ordered if is_ordered else current
                if not match:
                    other = current if is_ordered else current_ordered
                    if other and len(other.group(1)) > base_indent:
                        break
                    break
                indent = len(match.group(1))
                content = match.group(3) if is_ordered else match.group(2)
                if indent > base_indent and items:
                    items[-1].blocks.append(_parse_blocks([lines[index]])[0])
                    index += 1
                    continue
                task = _TASK_RE.match(content)
                checked = None
                if task:
                    checked = task.group(1).lower() == "x"
                    content = task.group(2)
                items.append(ListItem(blocks=_parse_blocks([content]), checked=checked))
                index += 1
            blocks.append(ListBlock(ordered=is_ordered, items=items))
            continue

        if _HTML_RE.match(stripped):
            html: list = []
            while index < total and lines[index].strip():
                html.append(lines[index])
                index += 1
            blocks.append(HtmlBlock(html="\n".join(html)))
            continue

        paragraph: list = []
        while index < total:
            candidate = lines[index]
            if not candidate.strip():
                break
            if (_HEADING_RE.match(candidate.strip()) or _FENCE_RE.match(candidate)
                    or _HR_RE.match(candidate) or _UL_RE.match(candidate)
                    or _OL_RE.match(candidate) or _QUOTE_RE.match(candidate)):
                break
            paragraph.append(candidate.strip())
            index += 1
        if paragraph:
            blocks.append(Paragraph(children=parse_inline(" ".join(paragraph))))

    return blocks


def parse(markdown: str) -> list:
    """Parse a markdown document into a list of block nodes."""
    return _parse_blocks(markdown.replace("\r\n", "\n").split("\n"))
```

### Step 7: 实现 `weixin/wechat/render.py`

```python
"""Block AST -> WeChat official account HTML.

WeChat's editor accepts inline styles only: ``class`` attributes are
dropped, external CSS and JavaScript never run.  Every style in this
module is therefore written into ``style="..."``.

Two conversions happen here:

1. Styles are inlined so the article survives WeChat's sanitiser.
2. Links degrade: WeChat blocks outbound H5 links inside the body, so
   external links lose their anchor and are collected into a
   "reference links" block at the end of the article.
"""

from __future__ import annotations

import hashlib
import html as html_lib
from dataclasses import dataclass, field

from .mdparse import (
    Block, Bold, CodeBlock, Heading, HtmlBlock, Image, InlineCode, Italic,
    Link, ListBlock, ListItem, Paragraph, Quote, Table, Text, ThematicBreak,
)

__all__ = ["RenderResult", "Resolver", "render", "mermaid_key"]

BODY_FONT = "font-size:15px; line-height:1.75; margin:0 0 16px; word-break:break-word;"
H2_STYLE = "font-size:18px; font-weight:700; margin:28px 0 14px; border-left:4px solid #3d7ea6; padding-left:10px;"
H3_STYLE = "font-size:16px; font-weight:700; margin:24px 0 12px;"
H4_STYLE = "font-size:15px; font-weight:700; margin:20px 0 10px;"
CODE_BLOCK_STYLE = (
    "background:#f6f8fa; padding:12px; border-radius:4px; overflow-x:auto; "
    "font-size:13px; line-height:1.5; margin:0 0 16px; "
    "font-family:Menlo,Consolas,'Courier New',monospace;"
)
INLINE_CODE_STYLE = "background:#f6f8fa; padding:2px 5px; border-radius:3px; font-size:14px;"
TABLE_STYLE = "border-collapse:collapse; width:100%; font-size:13px;"
TABLE_CELL_STYLE = "border:1px solid #dfe2e5; padding:7px 9px; text-align:left;"
QUOTE_STYLE = "border-left:3px solid #d0d0d0; padding-left:12px; color:#666; margin:0 0 16px;"
IMAGE_STYLE = "max-width:100%; height:auto; display:block; margin:0 auto 16px;"
MUTED_STYLE = "color:#888; font-size:13px; margin:0 0 8px;"


@dataclass(frozen=True)
class RenderResult:
    """Rendered HTML plus the assets that still need uploading."""

    html: str
    assets: tuple = ()
    external_links: tuple = ()


class Resolver:
    """Resolves a mermaid diagram to a rendered PNG on disk.

    The default resolver never finds anything, so mermaid blocks fall
    back to their source.  The CLI passes a resolver backed by the
    mermaid renderer.
    """

    def mermaid_path(self, key: str):
        return None


def mermaid_key(source: str) -> str:
    """Stable key for a mermaid diagram, independent of its position."""
    return hashlib.sha1(source.encode("utf-8")).hexdigest()[:16]


def _escape(text: str) -> str:
    return html_lib.escape(text, quote=False)


class _Renderer:
    def __init__(self, resolver=None):
        self.resolver = resolver or Resolver()
        self.assets: list = []
        self.asset_index: dict = {}
        self.external_links: list = []

    def register(self, path: str) -> str:
        """Return the placeholder token for a local asset, uploading once."""
        if path not in self.asset_index:
            self.asset_index[path] = len(self.assets)
            self.assets.append(path)
        return "{{img:%d}}" % self.asset_index[path]

    def inline(self, nodes) -> str:
        parts = []
        for node in nodes:
            parts.append(self._inline_one(node))
        return "".join(parts)

    def _inline_one(self, node) -> str:
        if isinstance(node, Text):
            return _escape(node.value)
        if isinstance(node, Bold):
            return "<strong>%s</strong>" % self.inline(node.children)
        if isinstance(node, Italic):
            return "<em>%s</em>" % self.inline(node.children)
        if isinstance(node, InlineCode):
            return "<code style=\"%s\">%s</code>" % (INLINE_CODE_STYLE, _escape(node.value))
        if isinstance(node, Link):
            text = self.inline(node.children)
            if node.target.startswith(("http://", "https://")):
                self.external_links.append((_strip_tags(text), node.target))
            return text
        if isinstance(node, Image):
            target = node.target
            if target.startswith(("http://", "https://", "data:")):
                return "<img src=\"%s\" alt=\"%s\" style=\"%s\" />" % (
                    _escape(target), _escape(node.alt), IMAGE_STYLE)
            return "<img src=\"%s\" alt=\"%s\" style=\"%s\" />" % (
                self.register(target), _escape(node.alt), IMAGE_STYLE)
        return ""

    def block(self, node) -> str:
        if isinstance(node, Heading):
            style = {2: H2_STYLE, 3: H3_STYLE}.get(node.level, H4_STYLE)
            return "<h{level} style=\"{style}\">{content}</h{level}>".format(
                level=node.level, style=style, content=self.inline(node.children))
        if isinstance(node, Paragraph):
            return "<p style=\"%s\">%s</p>" % (BODY_FONT, self.inline(node.children))
        if isinstance(node, CodeBlock):
            if node.lang.lower() == "mermaid":
                return self._mermaid(node)
            return "<pre style=\"%s\"><code style=\"font-family:Menlo,Consolas,monospace;\">%s</code></pre>" % (
                CODE_BLOCK_STYLE, _escape(node.code))
        if isinstance(node, Table):
            return self._table(node)
        if isinstance(node, ListBlock):
            return self._list(node)
        if isinstance(node, Quote):
            inner = "".join(self.block(child) for child in node.blocks)
            return "<section style=\"%s\">%s</section>" % (QUOTE_STYLE, inner)
        if isinstance(node, ThematicBreak):
            return "<hr style=\"border:none; border-top:1px solid #e5e5e5; margin:24px 0;\" />"
        if isinstance(node, HtmlBlock):
            return node.html
        return ""

    def _mermaid(self, node) -> str:
        key = mermaid_key(node.code)
        path = self.resolver.mermaid_path(key)
        if path is not None:
            return "<img src=\"%s\" alt=\"mermaid diagram\" style=\"%s\" />" % (
                self.register(str(path)), IMAGE_STYLE)
        return (
            "<p style=\"%s\">图表渲染失败，以下为图表源码：</p>"
            "<pre style=\"%s\"><code style=\"font-family:Menlo,Consolas,monospace;\">%s</code></pre>"
        ) % (MUTED_STYLE, CODE_BLOCK_STYLE, _escape(node.code))

    def _table(self, node) -> str:
        aligns = node.align or [""] * len(node.header)
        head = "".join(
            "<th style=\"%s\">%s</th>" % (TABLE_CELL_STYLE, self.inline(cell))
            for cell in node.header
        )
        rows = []
        for row in node.rows:
            cells = []
            for index, cell in enumerate(row):
                align = aligns[index] if index < len(aligns) else ""
                style = TABLE_CELL_STYLE + (" text-align:%s;" % align if align else "")
                cells.append("<td style=\"%s\">%s</td>" % (style, self.inline(cell)))
            rows.append("<tr>%s</tr>" % "".join(cells))
        table = "<table style=\"%s\"><thead><tr>%s</tr></thead><tbody>%s</tbody></table>" % (
            TABLE_STYLE, head, "".join(rows))
        return "<section style=\"overflow-x:auto; margin:0 0 16px;\">%s</section>" % table

    def _list(self, node) -> str:
        items = []
        for item in node.items:
            marker = ""
            if item.checked is True:
                marker = "<span style=\"color:#3d7ea6;\">☑ </span>"
            elif item.checked is False:
                marker = "<span style=\"color:#999;\">☐ </span>"
            inner = "".join(self.block(child) for child in item.blocks)
            items.append("<li style=\"margin:0 0 6px;\">%s%s</li>" % (marker, inner))
        tag = "ol" if node.ordered else "ul"
        return "<{tag} style=\"padding-left:22px; margin:0 0 16px;\">{items}</{tag}>".format(
            tag=tag, items="".join(items))


def _strip_tags(text: str) -> str:
    import re
    return re.sub(r"<[^>]+>", "", text)


def render(blocks: list, *, resolver=None) -> RenderResult:
    """Render a block AST into WeChat-ready HTML."""
    renderer = _Renderer(resolver)
    body = "".join(renderer.block(block) for block in blocks)

    if renderer.external_links:
        items = "".join(
            "<li style=\"margin:0 0 6px;\">%s：%s</li>" % (_escape(text), _escape(url))
            for text, url in renderer.external_links
        )
        body += (
            "<section style=\"margin:24px 0 0; padding-top:12px; border-top:1px solid #e5e5e5;\">"
            "<p style=\"%s\">参考链接</p><ul style=\"padding-left:22px;\">%s</ul></section>"
        ) % (MUTED_STYLE, items)

    return RenderResult(
        html=body,
        assets=tuple(renderer.assets),
        external_links=tuple(renderer.external_links),
    )
```

"""Server-side code highlighting.

The site highlights code in the browser with Prism; WeChat has no
JavaScript, so the same treatment has to happen here and be inlined into
the HTML.  Pygments' ``nowrap=True`` formatter emits only inline styles,
which is exactly what WeChat accepts.
"""

from __future__ import annotations

import html as html_lib

from pygments import highlight as pygments_highlight
from pygments.formatters import HtmlFormatter
from pygments.lexers import get_lexer_by_name
from pygments.util import ClassNotFound

__all__ = ["highlight_code"]

_PLAIN_LANGUAGES = {"", "text", "plain", "plaintext", "txt"}
_FORMATTER = HtmlFormatter(nowrap=True, noclasses=True, style="default")


def highlight_code(code: str, lang: str) -> str:
    """Return inline-styled HTML for a code block.

    Unknown languages fall back to escaped plain text rather than
    raising: a blog post with an exotic fence should still publish.
    """
    if lang.lower() in _PLAIN_LANGUAGES:
        return html_lib.escape(code, quote=False)
    try:
        lexer = get_lexer_by_name(lang, stripall=False)
    except ClassNotFound:
        return html_lib.escape(code, quote=False)
    return pygments_highlight(code, lexer, _FORMATTER)

### Step 5: 实现 `weixin/wechat/mermaid.py`

```python
"""Render mermaid diagrams to PNG.

WeChat cannot run JavaScript, so a ``<div class="mermaid">`` copied from
the site would arrive as an empty div and the diagram would vanish
silently.  This module renders each diagram to a PNG with mermaid-cli.

A diagram that fails to render must not disappear: the caller receives
an asset with ``png=None`` and an error message, and the renderer falls
back to showing the diagram source.

Roughly 8% of the diagrams in this repository fail to parse (see
``tools/mermaid-audit.md``), so the failure path is a normal path.
"""

from __future__ import annotations

import hashlib
import os
import shutil
import subprocess
from dataclasses import dataclass
from pathlib import Path

__all__ = ["MermaidAsset", "mermaid_key", "render_mermaid", "default_runner"]

MERMAID_CLI_VERSION = "10.9.1"
DEFAULT_WIDTH = 1080
DEFAULT_BACKGROUND = "white"

_CHROME_CANDIDATES = (
    "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome",
    "/Applications/Chromium.app/Contents/MacOS/Chromium",
    "/usr/bin/google-chrome",
    "/usr/bin/chromium",
    "/usr/bin/chromium-browser",
)


@dataclass(frozen=True)
class MermaidAsset:
    """One mermaid diagram and its rendered PNG (if rendering worked)."""

    key: str
    source: str
    png: Path | None = None
    error: str | None = None


def mermaid_key(source: str) -> str:
    """Stable key for a diagram, independent of its position in the post."""
    return hashlib.sha1(source.encode("utf-8")).hexdigest()[:16]


def _find_chrome() -> str | None:
    for candidate in _CHROME_CANDIDATES:
        if Path(candidate).exists():
            return candidate
    return None


def default_runner(source: str, out_file: Path) -> tuple:
    """Render a diagram with mermaid-cli.

    Returns ``(ok, error_message)``.  Uses the system Chrome when one is
    installed so that puppeteer does not download its own Chromium.
    """
    out_file.parent.mkdir(parents=True, exist_ok=True)
    source_file = out_file.with_suffix(".mmd")
    source_file.write_text(source, encoding="utf-8")

    env = dict(os.environ)
    chrome = _find_chrome()
    if chrome:
        env["PUPPETEER_EXECUTABLE_PATH"] = chrome

    command = [
        "npx", "-y", "@mermaid-js/mermaid-cli@{}".format(MERMAID_CLI_VERSION),
        "-i", str(source_file),
        "-o", str(out_file),
        "-w", str(DEFAULT_WIDTH),
        "-b", DEFAULT_BACKGROUND,
    ]
    try:
        result = subprocess.run(command, capture_output=True, text=True, env=env, timeout=180)
    except FileNotFoundError:
        return False, "npx not found: install Node.js to render mermaid diagrams"
    except subprocess.TimeoutExpired:
        return False, "mermaid-cli timed out after 180s"

    if result.returncode != 0 or not out_file.exists():
        message = (result.stderr or result.stdout or "").strip()
        return False, message[-800:] or "mermaid-cli failed with code {}".format(result.returncode)
    return True, ""


def render_mermaid(blocks: list, out_dir: Path, *, runner=None) -> dict:
    """Render every mermaid block in ``blocks`` to a PNG.

    Returns a mapping from diagram key to :class:`MermaidAsset`.  Results
    are cached on disk by source hash, so re-running a conversion does not
    re-render diagrams that have not changed.
    """
    run = runner or default_runner
    out_dir = Path(out_dir)
    out_dir.mkdir(parents=True, exist_ok=True)

    assets: dict = {}
    for block in blocks:
        if getattr(block, "lang", "").lower() != "mermaid":
            continue
        source = block.code
        key = mermaid_key(source)
        if key in assets:
            continue

        png = out_dir / "{}.png".format(key)
        if png.exists() and png.stat().st_size > 0:
            assets[key] = MermaidAsset(key=key, source=source, png=png)
            continue

        ok, error = run(source, png)
        if ok and png.exists():
            assets[key] = MermaidAsset(key=key, source=source, png=png)
        else:
            if png.exists():
                png.unlink()
            assets[key] = MermaidAsset(key=key, source=source, png=None, error=error)

    return assets
```

```python
"""Prepare local images for WeChat.

WeChat's body-image endpoint accepts JPG/PNG only and caps a file at
1 MB; anything larger is rejected outright.  Screenshots in this blog
routinely exceed that, so every image is measured and compressed before
it is uploaded.

Images wider than the WeChat body width (1080 logical pixels) are
scaled down: WeChat would scale them anyway, and downscaling here keeps
text in screenshots legible.
"""

from __future__ import annotations

import io
from dataclasses import dataclass
from pathlib import Path

from PIL import Image

__all__ = ["PreparedImage", "prepare_image"]

DEFAULT_LIMIT_BYTES = 1024 * 1024
DEFAULT_MAX_WIDTH = 1080


@dataclass(frozen=True)
class PreparedImage:
    """An image ready to be uploaded to WeChat."""

    source: Path
    data: bytes
    filename: str
    content_type: str
    width: int
    height: int


def _encode_png(image: Image.Image) -> bytes:
    buffer = io.BytesIO()
    image.save(buffer, format="PNG", optimize=True)
    return buffer.getvalue()


def _encode_jpeg(image: Image.Image, quality: int) -> bytes:
    buffer = io.BytesIO()
    image.convert("RGB").save(buffer, format="JPEG", quality=quality)
    return buffer.getvalue()


def prepare_image(path: Path, *, limit_bytes: int = DEFAULT_LIMIT_BYTES,
                  max_width: int = DEFAULT_MAX_WIDTH) -> PreparedImage:
    """Read, shrink and compress one image so WeChat accepts it."""
    path = Path(path)
    if not path.is_file():
        raise FileNotFoundError("image not found: {}".format(path))

    with Image.open(path) as raw:
        raw.load()
        image = raw.copy()

    if image.width > max_width:
        ratio = max_width / float(image.width)
        image = image.resize((max_width, max(1, int(image.height * ratio))), Image.LANCZOS)

    data = _encode_png(image)
    content_type = "image/png"
    filename = path.stem + ".png"

    if len(data) > limit_bytes:
        for quality in (90, 80, 70, 60, 50, 40):
            data = _encode_jpeg(image, quality)
            content_type = "image/jpeg"
            filename = path.stem + ".jpg"
            if len(data) <= limit_bytes:
                break

    return PreparedImage(
        source=path,
        data=data,
        filename=filename,
        content_type=content_type,
        width=image.width,
        height=image.height,
    )
```

### Step 6: 实现 `weixin/wechat/state.py`

```python
"""Idempotency bookkeeping for WeChat publishing.

Publishing the same article twice is the worst failure mode of an
automated pipeline, so state is kept in three layers:

- the body fingerprint decides whether the content changed at all
- ``media_id`` records that a draft already exists
- ``publish_id`` records that a publish is already in flight

The state file lives next to the other build output and is never
committed.
"""

from __future__ import annotations

import json
from dataclasses import asdict, dataclass
from datetime import datetime, timezone
from pathlib import Path

__all__ = ["PublishState", "StateStore", "needs_draft", "needs_submit"]


@dataclass
class PublishState:
    """What we already did with one post."""

    fingerprint: str | None = None
    media_id: str | None = None
    publish_id: str | None = None
    publish_status: int | None = None
    updated_at: str | None = None


class StateStore:
    """A JSON file holding the state of every post we have published."""

    def __init__(self, path: Path):
        self.path = Path(path)

    def _load_all(self) -> dict:
        if not self.path.is_file():
            return {}
        try:
            raw = json.loads(self.path.read_text(encoding="utf-8"))
        except (json.JSONDecodeError, OSError):
            return {}
        return raw.get("posts", {}) if isinstance(raw, dict) else {}

    def all(self) -> dict:
        return self._load_all()

    def get(self, slug: str) -> PublishState:
        entry = self._load_all().get(slug)
        if not isinstance(entry, dict):
            return PublishState()
        known = {field: entry.get(field) for field in PublishState.__dataclass_fields__}
        return PublishState(**known)

    def save(self, slug: str, state: PublishState) -> None:
        posts = self._load_all()
        state.updated_at = datetime.now(timezone.utc).isoformat(timespec="seconds")
        posts[slug] = asdict(state)
        self.path.parent.mkdir(parents=True, exist_ok=True)
        self.path.write_text(
            json.dumps({"posts": posts}, ensure_ascii=False, indent=2, sort_keys=True),
            encoding="utf-8",
        )


def needs_draft(fingerprint: str, state: PublishState) -> bool:
    """True when a fresh draft has to be created for this content."""
    if not state.media_id:
        return True
    return state.fingerprint != fingerprint


def needs_submit(state: PublishState) -> bool:
    """True when the article still has to be submitted for publishing."""
    return not state.publish_id
```

### Step 7: 实现 `weixin/wechat/publish.py`

```python
"""WeChat official account API client.

Only the standard library is used: ``urllib`` for HTTP and a hand-written
multipart encoder for the two upload endpoints.  Every non-zero
``errcode`` is raised as :class:`WeChatError` — a pipeline that swallows
API errors reports success while nothing was published.

Note on tokens: ``/cgi-bin/stable_token`` is used rather than
``/cgi-bin/token`` because the legacy endpoint invalidates the previous
token on every call, which breaks two jobs that overlap.
"""

from __future__ import annotations

import json
import mimetypes
import time
import urllib.error
import urllib.parse
import urllib.request
import uuid

__all__ = ["WeChatClient", "WeChatError"]

DEFAULT_BASE_URL = "https://api.weixin.qq.com"
PUBLISH_STATUS = {
    0: "发布成功",
    1: "发布中",
    2: "原创失败",
    3: "常规失败",
    4: "平台审核不通过",
}


class WeChatError(RuntimeError):
    """A WeChat API call returned a non-zero errcode."""

    def __init__(self, errcode: int, errmsg: str, endpoint: str):
        super().__init__("{} failed: [{}] {}".format(endpoint, errcode, errmsg))
        self.errcode = errcode
        self.errmsg = errmsg
        self.endpoint = endpoint


class WeChatClient:
    """Thin, explicit wrapper over the endpoints the pipeline needs."""

    def __init__(self, appid: str, appsecret: str, *, base_url: str = DEFAULT_BASE_URL,
                 timeout: int = 30):
        self.appid = appid
        self.appsecret = appsecret
        self.base_url = base_url.rstrip("/")
        self.timeout = timeout
        self._token: str | None = None

    # -- transport ---------------------------------------------------

    def _request(self, path: str, *, data=None, headers=None, params=None, method="POST"):
        url = self.base_url + path
        if params:
            url += "?" + urllib.parse.urlencode(params)
        request = urllib.request.Request(url, data=data, headers=headers or {}, method=method)
        try:
            with urllib.request.urlopen(request, timeout=self.timeout) as response:
                raw = response.read()
        except urllib.error.HTTPError as error:
            raw = error.read()
        except urllib.error.URLError as error:
            raise WeChatError(-1, "network error: {}".format(error), path) from error
        try:
            return json.loads(raw.decode("utf-8"))
        except (json.JSONDecodeError, UnicodeDecodeError) as error:
            raise WeChatError(-1, "non-JSON response: {}".format(raw[:200]), path) from error

    def _post_json(self, path: str, payload: dict, *, with_token: bool = True):
        body = json.dumps(payload, ensure_ascii=False).encode("utf-8")
        headers = {"Content-Type": "application/json; charset=utf-8"}
        params = None
        if with_token:
            headers["Authorization"] = "Bearer {}".format(self.stable_token())
        response = self._request(path, data=body, headers=headers, params=params)
        errcode = response.get("errcode", 0)
        if errcode:
            raise WeChatError(errcode, response.get("errmsg", ""), path)
        return response

    def _post_multipart(self, path: str, filename: str, data: bytes, *, params=None):
        boundary = "----mavisweixin{}".format(uuid.uuid4().hex)
        content_type = mimetypes.guess_type(filename)[0] or "application/octet-stream"
        parts = [
            "--{}\r\n".format(boundary).encode(),
            'Content-Disposition: form-data; name="media"; filename="{}"\r\n'.format(filename).encode("utf-8"),
            "Content-Type: {}\r\n\r\n".format(content_type).encode(),
            data,
            "\r\n--{}--\r\n".format(boundary).encode(),
        ]
        body = b"".join(parts)
        headers = {
            "Content-Type": "multipart/form-data; boundary={}".format(boundary),
            "Authorization": "Bearer {}".format(self.stable_token()),
        }
        response = self._request(path, data=body, headers=headers, params=params)
        errcode = response.get("errcode", 0)
        if errcode:
            raise WeChatError(errcode, response.get("errmsg", ""), path)
        return response

    # -- endpoints ----------------------------------------------------

    def stable_token(self) -> str:
        """Fetch (and cache) an access token."""
        if self._token:
            return self._token
        payload = {
            "grant_type": "client_credential",
            "appid": self.appid,
            "appsecret": self.appsecret,
            "force_refresh": False,
        }
        response = self._post_json("/cgi-bin/stable_token", payload, with_token=False)
        token = response.get("access_token")
        if not token:
            raise WeChatError(-1, "no access_token in response", "/cgi-bin/stable_token")
        self._token = token
        return token

    def upload_body_image(self, data: bytes, filename: str) -> str:
        """Upload an inline image and return its mmbiz URL."""
        response = self._post_multipart("/cgi-bin/media/uploadimg", filename, data)
        url = response.get("url")
        if not url:
            raise WeChatError(-1, "no url in response", "/cgi-bin/media/uploadimg")
        return url

    def upload_cover(self, data: bytes, filename: str) -> str:
        """Upload the cover image and return its material media_id."""
        response = self._post_multipart(
            "/cgi-bin/material/add_material", filename, data,
            params={"type": "image"},
        )
        media_id = response.get("media_id")
        if not media_id:
            raise WeChatError(-1, "no media_id in response", "/cgi-bin/material/add_material")
        return media_id

    def add_draft(self, article: dict) -> str:
        """Create a draft and return its media_id."""
        response = self._post_json("/cgi-bin/draft/add", {"articles": [article]})
        media_id = response.get("media_id")
        if not media_id:
            raise WeChatError(-1, "no media_id in response", "/cgi-bin/draft/add")
        return media_id

    def freepublish_submit(self, media_id: str) -> str:
        """Submit a draft for publishing; returns the asynchronous publish_id."""
        response = self._post_json("/cgi-bin/freepublish/submit", {"media_id": media_id})
        publish_id = response.get("publish_id")
        if not publish_id:
            raise WeChatError(-1, "no publish_id in response", "/cgi-bin/freepublish/submit")
        return publish_id

    def freepublish_get(self, publish_id: str) -> tuple:
        """Poll a publish; returns ``(publish_status, article_id)``."""
        response = self._post_json("/cgi-bin/freepublish/get", {"publish_id": publish_id})
        return response.get("publish_status", -1), response.get("article_id")
```

```python
"""Command line entry point for the WeChat publishing pipeline.

Commands:

    scan                  list every post and whether it may be published
    convert <slug>        convert one post, write the HTML, touch no network
    publish <slug>        convert, upload, and create a draft
    publish <slug> --publish   also submit the draft for publishing
    status                show the recorded state of every post

The default target is the draft box on purpose.  WeChat revoked the
freepublish endpoint for some account types in July 2025, and the draft
box is a useful human review gate either way.
"""

from __future__ import annotations

import argparse
import json
import os
import sys
from pathlib import Path

from . import assets as assets_module
from . import mermaid as mermaid_module
from . import publish as publish_module
from . import render as render_module
from .mdparse import parse
from .posts import check_eligibility, discover, load_post
from .state import PublishState, StateStore, needs_draft, needs_submit

DEFAULT_POSTS_DIR = Path("source/_posts")
DEFAULT_OUT_DIR = Path("out")
DEFAULT_SOURCE_URL = "https://growdu.cn"


def _resolve_post(posts_dir: Path, slug: str):
    path = posts_dir / (slug + ".md")
    if not path.is_file():
        matches = sorted(posts_dir.rglob(slug + ".md"))
        if not matches:
            return None
        path = matches[0]
    return load_post(path, posts_dir)


def cmd_scan(args) -> int:
    posts = discover(args.posts_dir)
    eligible = 0
    print("共 {} 篇文章\n".format(len(posts)))
    for post in posts:
        result = check_eligibility(post)
        if result.ok:
            eligible += 1
            print("  [OK]   {}  ({} 字)".format(post.slug, len(post.body)))
        else:
            print("  [跳过] {}  -> {}".format(post.slug, "; ".join(result.reasons)))
    print("\n可发布 {} 篇，跳过 {} 篇".format(eligible, len(posts) - eligible))
    return 0


def _build_html(post, out_dir: Path, resolver=None):
    blocks = parse(post.body)
    result = render_module.render(blocks, resolver=resolver)
    target_dir = out_dir / post.slug
    target_dir.mkdir(parents=True, exist_ok=True)
    (target_dir / "article.html").write_text(result.html, encoding="utf-8")
    return result


def cmd_convert(args) -> int:
    post = _resolve_post(args.posts_dir, args.slug)
    if post is None:
        print("找不到文章: {}".format(args.slug), file=sys.stderr)
        return 1

    eligibility = check_eligibility(post)
    if not eligibility.ok:
        print("文章不合规: {}".format("; ".join(eligibility.reasons)), file=sys.stderr)
        return 2

    blocks = parse(post.body)
    mermaid_assets = mermaid_module.render_mermaid(blocks, args.out_dir / "mermaid")
    failures = [asset for asset in mermaid_assets.values() if asset.png is None]

    class _Resolver:
        def mermaid_path(self, key):
            asset = mermaid_assets.get(key)
            return asset.png if asset else None

    result = _build_html(post, args.out_dir, resolver=_Resolver())

    print("已转换: {}".format(post.slug))
    print("  标题: {} ({} 字符)".format(post.title, len(post.title)))
    print("  摘要: {}".format(post.digest))
    print("  阅读原文: {}{}".format(args.source_url, post.permalink))
    print("  HTML: {}".format((args.out_dir / post.slug / "article.html").as_posix()))
    print("  待上传图片: {}".format(len(result.assets)))
    print("  mermaid: {} 个 (渲染失败 {} 个)".format(len(mermaid_assets), len(failures)))
    for asset in failures:
        print("    ! {} -> {}".format(asset.key, asset.error))
    return 0


def _upload_and_draft(post, result, args, store: StateStore) -> PublishState:
    client = publish_module.WeChatClient(
        args.appid, args.appsecret, base_url=args.api_base)
    state = store.get(post.slug)

    html = result.html
    urls = []
    for index, asset_path in enumerate(result.assets):
        prepared = assets_module.prepare_image(Path(asset_path))
        url = client.upload_body_image(prepared.data, prepared.filename)
        urls.append(url)
        html = html.replace("{{img:%d}}" % index, url)

    cover_media_id = ""
    cover_path = args.cover
    if not cover_path:
        cover_path = result.assets[0] if result.assets else None
    if cover_path:
        prepared = assets_module.prepare_image(Path(cover_path))
        cover_media_id = client.upload_cover(prepared.data, prepared.filename)

    article = {
        "title": post.title,
        "author": args.author,
        "digest": post.digest,
        "content": html,
        "content_source_url": args.source_url.rstrip("/") + post.permalink,
        "thumb_media_id": cover_media_id,
        "need_open_comment": 0,
        "only_fans_can_comment": 0,
    }

    if needs_draft(post.fingerprint, state):
        state.media_id = client.add_draft(article)
        state.fingerprint = post.fingerprint
        state.publish_id = None
        state.publish_status = None
        store.save(post.slug, state)

    if args.publish and needs_submit(state):
        state.publish_id = client.freepublish_submit(state.media_id)
        store.save(post.slug, state)

    return state


def cmd_publish(args) -> int:
    post = _resolve_post(args.posts_dir, args.slug)
    if post is None:
        print("找不到文章: {}".format(args.slug), file=sys.stderr)
        return 1

    eligibility = check_eligibility(post)
    if not eligibility.ok:
        print("文章不合规: {}".format("; ".join(eligibility.reasons)), file=sys.stderr)
        return 2

    if not args.appid or not args.appsecret:
        print("缺少 WX_APPID / WX_APPSECRET 环境变量", file=sys.stderr)
        return 2

    blocks = parse(post.body)
    mermaid_assets = mermaid_module.render_mermaid(blocks, args.out_dir / "mermaid")

    class _Resolver:
        def mermaid_path(self, key):
            asset = mermaid_assets.get(key)
            return asset.png if asset else None

    result = _build_html(post, args.out_dir, resolver=_Resolver())

    store = StateStore(args.out_dir / "state.json")
    state = _upload_and_draft(post, result, args, store)

    print("已建草稿: {}".format(post.slug))
    print("  media_id: {}".format(state.media_id))
    print("  阅读原文: {}{}".format(args.source_url.rstrip("/"), post.permalink))
    if state.publish_id:
        print("  publish_id: {}".format(state.publish_id))
    else:
        print("  未提交发表（如需自动发表请加 --publish）")
    return 0


def cmd_status(args) -> int:
    store = StateStore(args.out_dir / "state.json")
    entries = store.all()
    if not entries:
        print("没有已发布的记录")
        return 0
    for slug in sorted(entries):
        state = store.get(slug)
        print("  {}".format(slug))
        print("    media_id:  {}".format(state.media_id))
        print("    publish_id: {}".format(state.publish_id))
        print("    status:    {}".format(state.publish_status))
    return 0


def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(prog="wechat", description="博客到公众号的转换与发布")
    parser.add_argument("--posts-dir", type=Path, default=DEFAULT_POSTS_DIR)
    parser.add_argument("--out-dir", type=Path, default=DEFAULT_OUT_DIR)
    parser.add_argument("--source-url", default=DEFAULT_SOURCE_URL)
    parser.add_argument("--api-base", default=publish_module.DEFAULT_BASE_URL)
    parser.add_argument("--appid", default="")
    parser.add_argument("--appsecret", default="")
    parser.add_argument("--author", default="growdu")
    parser.add_argument("--cover", default="")

    sub = parser.add_subparsers(dest="command", required=True)

    scan = sub.add_parser("scan", help="盘点文章")
    scan.set_defaults(func=cmd_scan)

    convert = sub.add_parser("convert", help="转换一篇（不调接口）")
    convert.add_argument("slug")
    convert.set_defaults(func=cmd_convert)

    publish = sub.add_parser("publish", help="转换并推到草稿箱")
    publish.add_argument("slug")
    publish.add_argument("--publish", action="store_true", help="额外提交发表")
    publish.set_defaults(func=cmd_publish)

    status = sub.add_parser("status", help="查看发布状态")
    status.set_defaults(func=cmd_status)

    return parser


def main(argv=None) -> int:
    parser = build_parser()
    args = parser.parse_args(argv)
    args.appid = args.appid or os.environ.get("WX_APPID", "")
    args.appsecret = args.appsecret or os.environ.get("WX_APPSECRET", "")
    args.source_url = os.environ.get("WX_SOURCE_URL", args.source_url)
    args.cover = args.cover or os.environ.get("WX_COVER", "")
    try:
        return args.func(args)
    except publish_module.WeChatError as error:
        print("微信接口报错: {}".format(error), file=sys.stderr)
        return 3


if __name__ == "__main__":
    raise SystemExit(main())
```
